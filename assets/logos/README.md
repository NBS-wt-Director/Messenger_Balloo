**Медиа-ресурсы Balloo**  
Здесь хранятся все медиа-файлы проекта: логотипы, маскот, иконки.  
**Файлы для загрузки**  
| | |  
|-|-|  
| **Файл** | **Описание** |   
| product-logo.png | Логотип продукта (мессенджер Balloo) |   
| mascot.png | Маскот (персонаж Balloo) |   
| company-logo.png | Логотип компании |   
| qr_helpus.png | Код поддержки через сбп |   
   
**Требования к файлам**  
- Формат: PNG  
- Минимум 512×512 px для основного логотипа  
- Маскот: 256×256 px достаточно  
**Использование**  
Все пути к медиа ссылаются на эту папку через относительные пути ../../assets/logos/.
