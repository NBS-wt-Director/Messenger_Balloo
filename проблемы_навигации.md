# Проблемы навигации и функционала — Balloo Messenger

Полный аудит всех макетов. Для каждой проблемы — 2-4 варианта решения.

---

## 1. Экраны без навигации к ним

### 1.1. Сторис — нет кнопки входа из чатов

Где: chats.html -> stories.tray есть, но нет кнопки в topbar
Проблема: кнопка circle есть только на stories.html, а не на chats.html. Пользователь не может открыть сторис из основного чата.

Вариант А (рекомендуется): добавить кнопку circle в topbar chats.html
  - Рядом с кнопками новый/видео/аудио
  - Бейдж с количеством непрочитанных сторис
  - Клик -> scroll к stories.tray или открытие viewer

Вариант Б: stories.tray всегда над списком чатов
  - Перенести stories.tray из stories.html в chats.html
  - Как в Instagram, трей всегда виден над чатами

Вариант В: 5-й элемент в mobile tabbar
  - Добавить Сторис между Звонки и Настройки
  - Клик -> stories.html

---

### 1.2. Мои донаты — нет кнопки входа

Где: my-donates.html существует, но ссылки нет нигде
Проблема: settings.html, profile.html, donate.html -> ни одна не ведёт на my-donates.html

Вариант А: кнопка Мои донаты в donate.html
  - Под кнопкой Поддержать добавить Мои донаты
  - Ведёт на my-donates.html

Вариант Б: tab Донаты в settings.html
  - Новый пункт sidebar: Донаты
  - Между Yandex Disk и О Balloo
  - Внутри: Мои донаты + Поддержать

Вариант В: карточка в profile.html
  - Карточка Поддержка проекта
  - Две кнопки: Поддержать и Мои донаты

---

### 1.3. О компании — нет кнопки входа

Где: about-company.html существует, ссылки нет
Проблема: dropdown topbar имеет пункт, но он не кликабельный. О Balloo в settings это версия, а не компания.

Вариант А: сделать dropdown-пункт кликабельным
  - onclick=window.location.href=about-company.html
  - Добавить во все экраны с dropdown

Вариант Б: два пункта в settings.html
  - О Balloo (версия) + О компании (разработчик)
  - Два разных tab

Вариант В: кнопка на about-balloo.html
  - Секция Разработчик -> кнопка О компании

---

### 1.4. Звонки (история) — нет кнопки входа

Где: calls.html существует, dropdown есть но не кликабельный
Проблема: dropdown topbar Звонки это текст без перехода

Вариант А: сделать dropdown-пункт кликабельным
  - onclick=window.location.href=calls.html
  - Добавить во все экраны

Вариант Б: отдельная кнопка в topbar
  - Всегда видимая, не в dropdown
  - Рядом с лого или поиском

---

### 1.5. Чат с поддержкой — нет кнопки входа

Где: support.html существует, но нет кнопки
Проблема: ни один экран не содержит ссылки на support.html

Вариант А: dropdown-пункт Поддержка
  - Перед О Balloo в dropdown
  - onclick=window.location.href=support.html

Вариант Б: tab Поддержка в settings.html
  - Встроенный чат поддержки в настройках
  - Отдельный sidebar пункт

Вариант В: карточка в profile.html
  - Помощь -> Поддержка + FAQ
