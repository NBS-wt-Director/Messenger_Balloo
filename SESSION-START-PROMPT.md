## 1. Протокол против выдумок (нарушение = работа не засчитывается)

1. Факт — только то, что прочитано **терминалом** в текущей сессии (`cat -n`, `sed -n`, `grep -n`).
   Перед правкой файла его содержимое сверить с `cat -n <файл>`: в этом проекте `read_file`
   возвращал текст, которого на диске нет.
2. Ссылка только `путь:строка`, где строка подтверждена `grep -n` и не превышает длину файла.
3. «Сделано / исправлено / проходит» — только с выводом команды. Нет вывода — нет утверждения.
4. Коммит существует после `git log`. Хеш из памяти не существует.
5. Ошибка инструмента или пустой результат — факт, а не повод додумывать: сообщить и остановиться.
6. Если мои слова противоречат коду — сказать о противоречии, не подгонять код под них.
7. Одна задача за раз, затем diff + вывод тестов + остаток. Не коммитить без слова «закоммить».
8. Один раз за сессию — самокопка: взять 2 своих прошлых утверждения и подтвердить командами;
   при расхождении признать вслух и исправить тикет.

## 4. Подтверждённые реальные находки (стартовать отсюда)

1. **`trust proxy` не включён в продуктовом коде.** Ключ лимитера — `req.ip`
   (`packages/server/src/middleware/rateLimit.ts:7-11`), а `trust proxy` стоит только в тесте
   (`packages/server/src/__tests__/middleware-ratelimit.test.ts:24`). Конфиги nginx
   (`docker/nginx.conf`, `docker/prod/nginx-production.conf`, `docker/prod/nginx/balloo-docker.conf`)
   добавляют `X-Forwarded-For`. Риск: за прокси все анонимные запросы в одном бакете —
   блокировка входа чужим трафиком. Проверить эмпирически через прокси.
2. **Refresh-токен хранится и сравнивается как секрет в открытом виде, не constant-time** (п.3).
3. **Строгий `authLimiter` (5/мин) общий для login, register, refresh, logout** — logout/refresh
   дают self-DoS сессии. Значения смотреть в `packages/server/src/middleware/rateLimit.ts`.
4. **Раздача загрузок.** В `packages/server/src` нет `express.static` (проверить
   `grep -rn "express.static" packages/server/src`), значит файлы отдаёт nginx/MinIO: проверить
   `X-Content-Type-Options`, `Content-Disposition`, кэш и то, что SVG/HTML из бакета не исполняется.
5. **REST-матрица доступа** по всем `packages/server/src/routes/*.ts`: 200/401/403/404, IDOR,
   утечки чужих сущностей.
6. **Frontend**: `packages/web/src/**/ErrorBoundary.tsx`, `packages/web/vite.config.ts` —
   ранее не читались, утверждений по ним нет.
