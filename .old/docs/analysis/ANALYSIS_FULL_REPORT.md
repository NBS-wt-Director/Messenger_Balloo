## 2. КРИТИЧЕСКИЕ ОШИБКИ И НЕДОРАБОТКИ

### 🔴 КРИТИЧЕСКИЕ (блокируют деплой)

#### 2.1 Безопасность — Пароли

**Файл:** `packages/server/src/services/authService.ts`, строка 91

```typescript
const hashPassword = (password: string): string =>
  crypto.createHash('sha256').update(password + 'balloo-salt-2024').digest('hex');
```

**Проблема:** SHA-256 с хардкод-солью — это НЕ хеширование паролей.
- SHA-256 — быстрый хеш, уязвим к rainbow tables и brute force
- Соль `'balloo-salt-2024'` захардкожена — если код утечёт, все пароли взломаны
- Не используется bcrypt, argon2, или scrypt

**Решение:** Заменить на `bcrypt` (cost factor 12+) или `argon2id`.
