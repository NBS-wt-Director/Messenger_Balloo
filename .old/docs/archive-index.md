# 🗄 Индекс архива документации (`.old/docs/`)

Создан 30.09.2026 по ответу владельца **В-90 (а)** (тикеты
`tickets/active/1790479490-08.md` и `tickets/active/ВОПРОСЫ_ВЛАДЕЛЬЦУ.md`, блок C).

черновики и листы проблем, у которых есть живой replacement. `mockups/` остаётся в
корне: он — единственный источник правды по `AGENTS.md` (главный принцип), на него
ссылаются реестры экранов и три темы оформления. Варианты (б) «перенести `mockups/`»
и (в) «копия `mockups/`» владельцем отклонены.

Даты в таблице — `mtime` файла (`date -r`), не дата коммита: в истории git эти файлы
появились одним массовым переносом, `git log --follow` по ним пуст.

## Чего в этом архиве нет (и не будет)

- `mockups/` — по ответу владельца В-90 (а) остаётся в корне.
- `ticket-68-themes-demo.html` — демо тем из тикета `1790479352`, упомянуто в списке
  кандидатов `1790479490-08.md`, но тикет `-08` требует «`status.html` и живые файлы
  не трогать»; демо тем связано с `mockups/assets/common.css` → оставлено в корне,
  вопрос открыт (мелочь, не блокер).
- `directory_tree.txt` — в архиве лежат только `.md`-снимки; `.txt`-версия (4,3 МБ
  по описи из самого снимка) в репозитории отсутствует как файл.

## Как вернуть файл из архива

Файлы отслеживаются git (`.old/` в `.gitignore`, но перенос сделан `git mv` —
записи в индексе сохранены):

```bash
git mv .old/docs/analysis/<файл> ./<файл>
```
