# Экран: Запись голосового сообщения — Mobile

**ID:** `1_08_23` · **Узел:** `у_08` — mobile  
**Файл макета:** `mockups/mobile/voice-record.html`  
**Функция:** `0_08_04` — Мобильный чат (запись голосового)  
**Формат:** Полный экран записи

---

## 📋 Описание

Мобильный экран записи голосового сообщения: таймер, визуализация звуковой волны, управление записью (пауза/продолжить), отправка или отмена.

## 🏗️ Структура

### Topbar (обязательный)
- Логотип Balloo с dropdown
- Заголовок: «Запись голосового»
- Аватар пользователя + переключатели языка/темы

### Заголовок чата (контекст)
- Кнопка «Назад» ←
- Имя контакта: «Мария Андреева»
- Статус: «в сети»

### Основной экран записи
- **Таймер:** крупный, 32px, tabular-nums (формат `m:ss`)
- **Визуализация волны:** 40 полосок, анимация в реальном времени
- **Кнопки управления:**
  - ✕ Отмена (серая)
  - ⏸ Пауза / ▶ Продолжить (серая)
  - ➤ Отправить (зелёная, accent)

### Tabbar
- Стандартная навигация (чаты активен, но скрыт за оверлеем)

## 🎨 Дизайн-требования
- Таймер: крупный, жирный, моноширинные цифры
- Waveform: 40 баров, accent-цвет, рандомная высота 4–64px
- Кнопки: 56×56px, круглые
- Отправить: accent-фон, белая иконка
- Пауза: тёмный фон, белая иконка

## 🧩 Компоненты
| Компонент | Назначение |
|-----------|-----------|
| `VoiceRecordScreen` | Экран записи голосового |
| `VoiceTimer` | Таймер записи |
| `VoiceWaveform` | Визуализация звуковой волны |
| `VoiceRecordControls` | Кнопки управления |
| `VoiceRecordButton` | Кнопка отправки/паузы/отмены |

## ⚡ Интерактивность
- **Запись:** волны анимируются каждые 50ms
- **Таймер:** обновляется каждую секунду
- **Пауза:** останавливает таймер и волны, меняет иконку ▶/⏸
- **Отмена:** закрывает экран, возвращает в чат
- **Отправка:** показывает toast, закрывает экран

## 📱 Адаптация под mobile
- Полноэкранный layout в phone-frame
- Touch-friendly кнопки (56px)
- Центрированный контент
- Waveform на всю ширину (max 280px)
