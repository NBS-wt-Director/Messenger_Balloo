## Описание

Мобильная версия экрана настроек с адаптацией под phone-frame. Содержит всю бизнес-логику web-версии: 13 табов настроек, switch-компоненты, приватность, устройства, 2FA (email-код, не TOTP), кэш, Yandex Disk, донаты, поддержка.

## Бизнес-логика (из web)

### JavaScript функции
- `switchTab(tabName)` — переключение табов (13 шт.)
- `toggleGeoDND(el)` — показ/скрытие опций геолокации DND
- `togglePrivacyComboBox(select, comboId)` — показ/скрытие списка контактов для приватности
- `unblockUser(name)` — разблокировка пользователя (confirm)
- `toggle2FA(el)` — показ/скрытие секции настройки 2FA
- `send2FACode()` — отправка email-кода
- `disable2FA()` — отключение 2FA (подтверждение email-кодом)
- `setTheme(theme)` — переключение темы

### API (2FA — email-код, не TOTP)
- `POST /api/auth/2fa/send-code` — отправить email-код
- `POST /api/auth/2fa/verify` — подтвердить код
- `DELETE /api/auth/2fa` — отключить 2FA
- **Нет** `POST /api/auth/2fa/setup` (TOTP)
- **Нет** backup-кодов
