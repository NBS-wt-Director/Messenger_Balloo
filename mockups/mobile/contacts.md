# Экран: Контакты (Mobile)

**ID:** `1_08_02`
**Узел:** `у_08` — mobile (сборные мобильные макеты)
**Web-источник:** `balloo-su/contacts.html` (`1_01_18`)

## Описание

Мобильная версия экрана контактов с адаптацией под phone-frame. Содержит всю бизнес-логику web-версии: список контактов, поиск, табы (контакты/группы/чёрный список), карточка контакта с действиями (написать, позвонить).

## Структура

### Topbar
- Логотип Balloo с dropdown навигацией (14 пунктов кликабельных)
- Название экрана: «Контакты»
- Аватар пользователя (кликабельный → `profile.html`)
- Переключатель языка (🇷🇺 RU, `data-lang-toggle`)
- Переключатель темы (🌙 Тёмная, `data-theme-toggle`)

### Контент (single-column, phone-frame)
1. **Поиск** — input «🔍 Поиск контактов...»
2. **Табы** — Контакты / 👥 Группы / 🚫 Чёрный список
3. **Карточка контакта** (Мария Андреева):
   - Аватар (lg, онлайн, контакт)
   - Имя, профессия, город, статус
   - Кнопки: 💬 Написать (→ `chat.html`), 📞 Аудиозвонок (`openCall('audio')`), 📹 Видеозвонок (`openCall('video')`)
   - Био, дата рождения, регистрация
   - Чипы: 3 новых сообщения, 2 пропущенных звонка
4. **Список контактов** (5 строк):
   - Мария Андреева (онлайн, 3 сообщения, 2 звонка)
   - Семья ❤️ (онлайн, группа, 5 сообщений)
   - Алексей Козлов (офлайн, кнопка 💬)
   - Дмитрий Петров (DND, 1 звонок)
   - Ольга Смирнова (занята, кнопка 💬)
5. **Кнопка** «📨 Пригласить друга» → `../balloo-su/invites.html`

### Tabbar (нижняя навигация)
- 💬 Чаты
- 👥 Контакты (активный)
- 📷 Сторис
- 📞 Звонки
- ⚙ Настройки

### Call overlay
- Модальное окно с аватаром, типом звонка, кнопками (микрофон, завершить, динамик)

## Бизнес-логика (из web)

### JavaScript функции
- `switchContactsTab(tab)` — переключение табов (контакты/группы/заблокированные)
- `openCall(type)` — открытие call-overlay (audio/video)
- `closeCall()` — закрытие call-overlay

### Навигация
- Список контактов → `chat.html` (открыть чат)
- Кнопка 💬 → `chat.html`
- «📨 Пригласить друга» → `../balloo-su/invites.html`
- Аватар topbar → `profile.html`

## API
- `GET /api/contacts` — список контактов
- `GET /api/contacts/:id` — детали контакта
- `POST /api/calls` — инициация звонка
- WebSocket: `call:invite`, `call:join`, `call:leave`

## Адаптация под mobile

| Web | Mobile |
|---|---|
| sidebar + content | single-column (phone-frame) |
| topbar с dropdown | topbar с dropdown |
| large detail card | compact card |
| — | tabbar внизу (Контакты активна) |

- 3 темы: dark, light, russian (через `data-theme-toggle`)
