# Экран: Профиль (Mobile)

**ID:** `1_08_01`  
**Узел:** `у_08` — mobile (сборные мобильные макеты)  
**Web-источник:** `balloo-su/profile.html` (`1_01_19`)

## Описание

Мобильная версия профиля пользователя с адаптацией под phone-frame. Содержит всю бизнес-логику web-версии: редактирование профиля, мультиаккаунт, настройки приватности, устройства, донаты.

## Структура

### Topbar
- Логотип Balloo с dropdown навигацией (все пункты кликабельные)
- Название экрана: «Профиль»
- Аватар пользователя (кликабельный → `profile.html`)
- Переключатель языка (🇷🇺 RU, `data-lang-toggle`)
- Переключатель темы (🌙 Тёмная, `data-theme-toggle`)

### Контент (single-column, phone-frame)
1. **Аватар** — большой восьмигранник + кнопка «Изменить аватар»
2. **Аккаунты** — 3 аккаунта (Иван, Мария, Рабочий) + slide-panel управления
3. **Основная информация** — имя, био, статус, дата рождения, дата регистрации
4. **Оформление** — выбор темы (3 шт.), выбор языка (20 языков)
5. **Yandex Disk** — подключение/отключение
6. **Поддержка проекта** — кнопки «Поддержать» и «Мои донаты»
7. **Помощь** — чат с поддержкой, FAQ
8. **Устройства** — список устройств + ссылка на my-devices
9. **Приватность** — видимость «в сети», превью уведомлений, заблокированные
10. **Опасная зона** — удаление аккаунта

### Tabbar (нижняя навигация)
- 💬 Чаты
- 👥 Контакты
- 📷 Сторис
- 📞 Звонки
- ⚙ Настройки (активный)

## Компоненты

### Slide Panels
- **avatar-panel** — изменение аватара (загрузить/камера/AI)
- **accounts-panel** — управление аккаунтами (переключение, выход)
- **blocked-panel** — заблокированные пользователи (разблокировать)

## Бизнес-логика (из web)

### JavaScript функции
- `openAvatarPanel()` / `closeAvatarPanel()` — открытие/закрытие панели аватара
- `openAccountsPanel()` / `closeAccountsPanel()` — открытие/закрытие панели аккаунтов
- `openBlockedPanel()` / `closeBlockedPanel()` — открытие/закрытие панели заблокированных
- `setTheme(theme)` — переключение темы (dark/light/russian)
- Закрытие по клику на фон — `slide-panel--visible`

### Навигация
- Аватар topbar → `profile.html` (локальный)
- Кнопка «Изменить аватар» → `openAvatarPanel()`
- Кнопка «Управлять» → `openAccountsPanel()`
- Кнопка «3 чел.» → `openBlockedPanel()`
- «💰 Поддержать» → `donate.html` (локальный)
- «📋 Мои донаты» → `my-donates.html` (локальный)
- «Написать» → `showToast('Чат поддержки','info')`
- «📱 Мои устройства →» → `../balloo-su/my-devices.html`
- «➕ Добавить устройство» → `../balloo-su/add-device.html`

## Адаптация под mobile

| Web | Mobile |
|---|---|
| sidebar + content | single-column (phone-frame) |
| topbar с dropdown | topbar с dropdown |
| large cards | compact cards (mb-3, smaller fonts) |
| — | tabbar внизу |

## Темы
- 3 темы: dark, light, russian (через `setTheme()`)

## Языки
- 20 языков в select (3 группы: Русские, Дружественные, Остальные)

## API
- `PATCH /api/users/me` — обновление профиля
- `POST /api/users/me/avatar` — загрузка аватарки
- `GET /api/devices` — список устройств
- `DELETE /api/devices/:id` — выход из устройства
