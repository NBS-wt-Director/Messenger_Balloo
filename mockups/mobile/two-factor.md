# Экран: 2FA (email-код) — Mobile

**ID:** `1_08_04`  
**Узел:** `у_08` — mobile (сборные мобильные макеты)  
**Web-источник:** `balloo-su/two-factor.html`  
**ВАЖНО:** 2FA через **email-код** (не TOTP, без QR-кода, без backup-кодов)

## Описание

Мобильная версия экрана двухфакторной аутентификации. Вместо TOTP с QR-кодом — отправка 6-значного кода на email. Отключение 2FA — через подтверждение email-кодом.

## Структура

### Topbar
- Логотип Balloo с dropdown навигацией (7 пунктов + divider)
- Название экрана: «Двухфакторная аутентификация»
- Аватар пользователя (`avatar--sm avatar--bordered`)
- Переключатель языка (🇷🇺 RU, `data-lang-toggle`)
- Переключатель темы (🌙 Тёмная, `data-theme-toggle`)

### Контент (single-column, phone-frame)
1. **Статус-карточка** — иконка 🔐, статус «2FA включена», chip «Активна»
2. **Шаг 1: Отправить код** — поле email, кнопка «Отправить код»
3. **Шаг 2: Подтвердить код** (скрыт изначально) — поле для 6-значного кода, кнопка «Подтвердить», ссылка «Отправить снова» (cooldown 60 сек)
4. **Отключение 2FA** — поле для кода из email, кнопка «Отключить 2FA» (danger)

## Бизнес-логика

### JavaScript
- `sendCode()` — отправка кода на email, показ шага 2, запуск cooldown 60 сек
- `verifyCode()` — подтверждение кода

### Cooldown
- После отправки кода ссылка «Отправить снова» блокируется на 60 секунд
- Обратный отсчёт отображается в тексте ссылки

## API-зависимости (email-code, НЕ TOTP)

| Метод | Эндпоинт | Описание |
|---|---|---|
| `POST` | `/auth/2fa/send-code` | Отправить 6-значный код на email |
| `POST` | `/auth/2fa/verify` | Подтвердить код (email + code) |
| `DELETE` | `/auth/2fa` | Отключить 2FA (подтверждение email-кодом) |

**Удалено (не используется):**
- ~~`POST /auth/2fa/setup`~~ — TOTP setup удалён
- ~~`POST /auth/2fa/backup-codes/regenerate`~~ — backup-коды не нужны
- ~~QR-код аутентификатора~~ — удалён
- ~~Backup-коды (6×2 сетка)~~ — удалён

## Навигация
- Аватар в topbar → `profile.html`
- Ссылка «Отправить снова» → повторный вызов `sendCode()`

## Адаптация под mobile

| Web | Mobile |
|---|---|
| sidebar + content layout | single-column в phone-frame |
| TOTP setup с QR | email-код (без QR, без backup) |
| 3 шага (QR → код → backup) | 2 шага (email → код) |
| отключение по паролю | отключение по email-коду |
