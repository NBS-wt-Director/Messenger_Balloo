# Экран: Создание группы (Mobile)

**ID:** `1_08_04`
**Узел:** `у_08` — mobile (сборные мобильные макеты)
**Web-источник:** `balloo-su/group-create.html` (`1_01_20`)

## Описание

Мобильная версия формы создания группы с адаптацией под phone-frame. Содержит всю бизнес-логику web-версии: обложка, автогенерация аватарки, базовая информация, тип группы (выпадающий список), настройки приватности.

## Структура

### Topbar
- Логотип Balloo с dropdown навигацией (14 пунктов кликабельных)
- Название экрана: «Создание группы»
- Аватар пользователя (кликабельный → `profile.html`)
- Переключатель языка (🇷🇺 RU, `data-lang-toggle`)
- Переключатель темы (🌙 Тёмная, `data-theme-toggle`)

### Контент (single-column, phone-frame)
1. **Обложка** (необязательно) — preview + кнопка «Загрузить обложку»
2. **Аватар группы**:
   - Октагон с автогенерацией (случайный градиент + случайный символ)
   - Кнопка 🔄 перегенерации (на аватаре и рядом)
   - Кнопка «📷 Своя» — загрузка своей аватарки
3. **Базовая информация**:
   - Название группы * (input)
   - Описание (textarea)
4. **Тип группы** (выпадающий список, НЕ радио):
   - 👥 Обычная — закрытая группа
   - 📢 Публичная — открытая, подписка
   - 📰 СМИ — канал с комментариями
   - 🏢 Корпоративная — чат + витрина
   - corp-note (показывается для корпоративной)
   - type-specific (опции для каждого типа)
5. **Настройки приватности**:
   - Ознакомление с правилами (switch)
   - История для новых (select)
   - Разрешить вложения (switch, вкл)
   - **Без поля «срок действия ссылки»**
6. **Кнопки**:
   - «📨 Пригласить участников» → `../balloo-su/invites.html`
   - «Создать группу» → `chat.html`

### Tabbar (нижняя навигация)
- 💬 Чаты (активный)
- 👥 Контакты
- 📷 Сторис
- 📞 Звонки
- ⚙ Настройки

## Бизнес-логика (из web)

### JavaScript функции
- `regenerateAvatar()` — случайный градиент + символ из массивов `gradients` и `symbols`
- `onGroupTypeChange()` — обработка выбора типа группы (corp-note, type-specific)

### Автогенерация аватарки
- 10 градиентов (3 цвета каждый)
- 20 символов (эмодзи)
- При загрузке — случайный выбор
- Кнопка 🔄 — перегенерация

### Тип группы = выпадающий список
- `ordinary` → закрытая группа
- `public` → открытая, подписка
- `media` → канал, нужна верификация
- `corporate` → чат клиентов + сотрудников + витрина + расписание

### Навигация
- «Создать группу» → `chat.html`
- «📨 Пригласить участников» → `../balloo-su/invites.html`
- Аватар topbar → `profile.html`

## API
- `POST /api/groups` — создание группы
- `POST /api/attachments/upload` — загрузка обложки/аватара (лимит 15 МБ)
- `POST /api/attachments/cloud` — загрузка на Yandex Disk / Mail.ru Cloud
