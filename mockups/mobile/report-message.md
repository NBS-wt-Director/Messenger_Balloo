## Описание

Мобильная версия формы подачи жалобы на сообщение. Открывается по кнопке 🚩 на сообщении. Выбор причины (7 категорий), комментарий, отправка, экран успеха. Бизнес-логика 1:1 с web-версией.

## Структура

- **Phone-frame** (360×760px) с notch, statusbar, home-bar
- **Topbar** (обязательный) — логотип Balloo с dropdown, заголовок «Пожаловаться», аватар, lang/theme toggle
- **Цитируемое сообщение** — аватар (октагон), имя, текст, время (border-left danger)
- **Причины жалобы** (7 категорий — из web):
  - 📢 Спам / Реклама
  - 🤬 Оскорбления / Травля
  - 🔞 Неприемлемый контент
  - ⚠️ Дезинформация
  - 🔐 Нарушение приватности
  - ⚖️ Нарушение закона
  - 📋 Другое
- **Комментарий** — необязательное textarea
- **Footer** — «Отмена» / «🚩 Отправить жалобу»
- **Экран успеха** — ✅, «Жалоба отправлена», ID жалобы, «Вернуться в чат»

## Бизнес-логика (из web)

- `selectReason(el)` — выбор причины (radio, только одна)
- `submitReport()` — валидация (нужна причина), показать экран успеха, сменить footer
