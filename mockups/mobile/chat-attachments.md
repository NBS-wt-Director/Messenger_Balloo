## Описание

Мобильная версия экрана «Вложения чата». Открывается по кнопке 📎 в заголовке чата или через dropdown-меню. Все вложения сгруппированы по вкладкам: Медиа, Аудио, Файлы, Ссылки, Опросы. Бизнес-логика 1:1 с web-версией.

## Структура

- **Phone-frame** (360×760px) с notch, statusbar, home-bar
- **Topbar** (обязательный) — логотип Balloo с dropdown, заголовок «Вложения — Мария», аватар, lang/theme toggle
- **Поиск** — строка поиска во вложениях
- **Вкладки** (горизонтальный скролл) — 📷 Медиа (14), 🎵 Аудио (5), 📄 Файлы (8), 🔗 Ссылки (11), 📊 Опросы (3)
- **Контент** (scrollable) — секции:
  - Фото и видео — сетка 3 колонки (градиентные превью, длительность видео)
  - Аудио — список файлов (иконка, имя, мета: длительность/размер/отправитель, ▶/⬇)
  - Файлы — список (📄📊📝🗜, имя, размер, отправитель, ⬇)
  - Ссылки — список (URL accent-цвет, заголовок, мета)
  - Опросы — карточки (вопрос, голоса, проценты, отправитель)
- **Tabbar** — Чаты активна

## Бизнес-логика (из web)

- Переключение вкладок (фильтрация по типу)
- Поиск по вложениям
- Скачать файл (⬇)
- Воспроизвести аудио (▶)
- Клик по медиа — просмотр

## Компоненты (React Native / Expo)

| Компонент | Описание |
|---|---|
| `MobileAttachmentsScreen` | Экран вложений |
| `AttachmentTabs` | Горизонтальные вкладки (ScrollView) |
| `MediaGrid` | Сетка 3 колонки с lazy-load |
| `FileListItem` | Элемент файла |
| `LinkListItem` | Элемент ссылки |
| `PollListItem` | Элемент опроса |
