## Описание

Сворачиваемое правое меню шапки в мобильной раскладке. Один и тот же состав
пунктов, что на десктопе (язык, тема, юр. ссылки, аккаунт), но панель
открывается **внутри экрана телефона** справа, со шторой под шапкой.

Экран закрыл дефект: раньше панель append'илась в `document.body` и имела
`position: fixed`, из-за чего на мобильном макете открывалась у правого края
окна браузера — то есть справа от «телефона», вне зоны экрана.

## Исправленный дефект (замеры живым браузером)

| Состояние | Рамка телефона | Панель | Вывод |
|---|---|---|---|
| До | `left 540 … right 900` | `left 1160 … right 1440` | вне экрана (на 540 px правее рамки) |
| После | `left 540 … right 900` | `left 577 … right 897`, `width 320` | внутри экрана |

Команда повторной проверки: `node scripts/p38-mobile-menu-check.cjs`
(живой макет `mobile/calls-history.html`) и
`node scripts/p38-mobile-menu-check.cjs --static --page mockups/mobile/right-menu.html`
(сториборд состояний).

## Структура

- **Phone-frame** 360×760 (как остальные мобильные экраны), notch, statusbar, home-bar
- **Topbar** (56px) — лого-меню слева, заголовок раздела, справа триггер:
  - гость → маскот 🐻 (`.topbar__menu-btn`)
  - авторизован → октагон-аватар с инициалами
- **Панель `.right-menu`** — absolutely внутри `.phone-frame__screen`:
  - `top: 56px` (под шапкой), `right: 0`, `bottom: 0`
  - ширина **320px**, `max-width: 100%` (в узкой рамке не вылезает)
  - съезд `translateX(100%) → 0`, 0.3s ease
  - `overflow-y: auto` — страховка на случай длинного списка; по замеру
    живым браузером контент влезает целиком (панель 655px, прокрутки нет)
  - фон/glassmorphism — те же переменные, что на десктопе
- **Штора `.right-menu__overlay`** — `top:56px`, закрывает только содержимое,
  шапка с триггером остаётся кликабельной; `rgba(0,0,0,0.45)`

## Состояния сториборда

1. Гость, панель закрыта (только триггер)
2. Гость, панель открыта (штора + «Вход/Регистрация»)
3. Авторизован, панель открыта (аватар-триггер + пункты аккаунта)
4. Подменю языка открыто (▴, активный язык с ✓)
5. Подменю темы открыто (▴, активная тема с ✓)

## Поведение / бизнес-логика

- Клик по триггеру — toggle; повторный клик — закрыть
- Клик по шторе — закрыть
- Клик вне панели (по документу) — закрыть
- `Escape` — закрыть (было отсутствием и на десктопе, добавлено)
- Клик по пункту языка/темы — применить и обновить ✓, панель НЕ закрывается
  (как на десктопе: выбранное видно)
- Клик по переходному пункту (Профиль/Приватность/…) — закрыть и перейти
- Подменю: ▾ → ▴, повторный клик по родительскому пункту — свернуть
- Скролл основного контента под шторой блокируется, когда панель открыта

## API

См. `mockups/balloo-su/` — тот же состав, отдельных эндпоинтов не требуется.
Язык/тема применяются на клиенте (`setLanguage`, `setTheme`), выход — `POST /api/auth/logout`.

## Дизайн-требования

- Ширина панели 320px, скруглений нет, glassmorphism (`--bg-glass`, `--blur`)
- Штора не закрывает шапку: `top: 56px`
- Иконки пунктов — как в десктопном эталоне (🌐 🎨 🛠️ 🔒 📋 👤 ⚙️ 👥 🚪)
- 3 темы (dark / light / russian) наследуются от `common.css`
- Аватар-триггер — октагон с двойной рамкой (контекст + статус)
