# Задание: Mobile — Обзор (сториборд)

## Макет
`mobile/overview.html`

## Описание
Сборный (композитный) макет мобильного приложения Balloo. Сториборд с 5 ключевыми экранами в рамках телефона.

## Экраны в сториборде

### 01 — Онбординг
- Иллюстрация-октагон с эмодзи 💬
- Заголовок «Добро пожаловать в Balloo»
- Описание
- Точки прогресса (3 шт., активна первая)
- Кнопка «Далее»

### 02 — Список чатов
- Mini-topbar «Чаты» + кнопка ✏
- Список из 4 чатов с аватарами-октагонами
- Бейдж непрочитанных (3)
- Tab bar снизу: Чаты / Контакты / Звонки / Настройки

### 03 — Чат
- Mini-topbar с аватаром, именем, кнопками 📞 📹
- Сообщения: sent (зелёные, octagon-bubble-sender) и recv (серые, octagon-bubble-receiver)
- Поле ввода + кнопка отправки

### 04 — Звонок
- Видео-блок с PiP (картинка-в-картинке)
- Имя, таймер, качество
- Контролы: mute / video / hangup (октагон-кнопки)

### 05 — Настройки
- Профиль-хедер с аватаром, именем, bio
- Список настроек по секциям
- Tab bar (активна «Настройки»)

## Дизайн телефонной рамки
- Ширина: 320px, высота: 640px
- Радиус: 32px
- Notch (вырез) сверху по центру
- Status bar (9:41, 📶 🔋)
- Home bar снизу

## Технологии
- Expo (React Native) — единая кодовая база iOS/Android
- Компоненты из `@balloo/shared` адаптированные для mobile
- SafeAreaView для notch
- TouchableWithoutFeedback для long-press меню
- React Navigation для tab bar

## Дизайн-требования
- Дизайн-система: `@balloo/shared` (адаптированная)
- Аватарки-октагоны на всех экранах
- Пузыри сообщений с угловыми срезами (clip-path)
- 3 темы: dark, light, russian
- Tab bar: 4 вкладки, активная — accent-цвет
