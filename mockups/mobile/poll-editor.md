# Экран: Редактор опроса (Mobile)

**ID:** `1_08_05`
**Узел:** `у_08` — mobile (сборные мобильные макеты)
**Web-источник:** `balloo-su/poll-editor.html` (`1_01_21`)

## Описание

Мобильная версия редактора интерактивов (опрос/квиз/списки/персонали) с адаптацией под phone-frame. Содержит всю бизнес-логику web-версии: 5 типов интерактивов, варианты ответа, настройки голосования, срок действия.

## Структура

### Topbar
- Логотип Balloo с dropdown навигацией (14 пунктов кликабельных)
- Название экрана: «Создание опроса»
- Аватар пользователя (кликабельный → `profile.html`)
- Переключатель языка (🇷🇺 RU, `data-lang-toggle`)
- Переключатель темы (🌙 Тёмная, `data-theme-toggle`)

### Контент (single-column, phone-frame)
1. **Заголовок** — «📊 Создать интерактив»
2. **Типы интерактивов** (5 табов, scrollable):
   - 📊 Опрос
   - 🎯 Квиз
   - ✅ Активный список
   - 📋 Пассивный список
   - 👤 Персонали
3. **Вопрос / заголовок** — input
4. **Варианты ответа**:
   - 3 предзаполненных (Зелёный, Мятный, Бирюзовый)
   - Кнопка удаления (🗑) для каждого
   - Кнопка «+ Добавить вариант»
5. **Правильный ответ** (только для квиза) — select
6. **Настройки**:
   - Анонимное голосование (checkbox, вкл)
   - Множественный выбор (checkbox)
   - Можно переслать (checkbox, вкл)
   - Срок действия (select: 24ч, 12ч, 1ч, без ограничений)
7. **Кнопки**:
   - «Отмена» → `chat.html`
   - «Создать» → `chat.html`

### Tabbar (нижняя навигация)
- 💬 Чаты (активный)
- 👥 Контакты
- 📷 Сторис
- 📞 Звонки
- ⚙ Настройки

## Бизнес-логика (из web)

### JavaScript функции
- `selectPollType(el, type)` — переключение типа интерактива (5 типов), показывает/скрывает блок «правильный ответ» для квиза

### 5 типов интерактивов
| Тип | Описание | Правильный ответ |
|---|---|---|
| 📊 Опрос | Голосование за варианты | Нет |
| 🎯 Квиз | Тест с правильным ответом | Да (select) |
| ✅ Активный список | Список с отметками | Нет |
| 📋 Пассивный список | Список без отметок | Нет |
| 👤 Персонали | Выбор персоны | Нет |

### Навигация
- «Отмена» → `chat.html`
- «Создать» → `chat.html`
- Аватар topbar → `profile.html`

## API
- `POST /api/groups/:id/polls` — создание опроса/квиза/списка/персонали
- WebSocket: `poll:created`, `poll:vote`

## Адаптация под mobile

| Web | Mobile |
|---|---|
| overlay поверх чата | отдельный экран |
| tabs в одну строку | tabs scrollable |
| large card | compact cards |
| — | tabbar внизу (Чаты активна) |

## Темы
- 3 темы: dark, light, russian (через `data-theme-toggle`)

## Технологии
- Expo (React Native)
- `@react-navigation/native-stack`
- `react-native-tabs` или кастомные табы
