## Описание

Мобильная версия экрана «История звонков». Список всех звонков (входящие/исходящие/пропущенные) с типом, длительностью и статусом. Кнопки быстрого звонка. Бизнес-логика 1:1 с web-версией.

## Структура

- **Phone-frame** (360×760px) с notch, statusbar, home-bar
- **Topbar** (обязательный) — логотип Balloo с dropdown, заголовок «Звонки», аватар, lang/theme toggle
- **Заголовок** — «Звонки», подзаголовок «История всех звонков»
- **Кнопки звонка** — 📞 (аудио) и 📹 (видео) → `openCall()`
- **Список звонков** — карточки с:
  - Аватар-октагон (sm)
  - Имя / название группы
  - Подзаголовок: тип (📹 Видео / 📞 Аудио), направление (Принятый/Пропущенный/Исходящий), время, длительность
  - Chip статуса: ✅ Принят (accent) / ❌ Пропущен (danger)
- **Tabbar** — Звонки активна

## Call Overlay (из web)

- Header: аватар, имя, таймер, кнопка «Свернуть»
- Participants: видео-тайлы с индикатором говорящего
- Controls: 🎤 Mute, 📹 Video, 🖥 Screen, 📞 Hangup

## Бизнес-логика (из web)

- `openCall(type)` — открыть оверлей звонка (audio/video)
- `closeCall()` — закрыть
- `toggleMute()` / `toggleVideo()` / `toggleScreen()`
- Клик по элементу списка → открыть чат с этим контактом

## Компоненты (React Native / Expo)

| Компонент | Описание |
|---|---|
| `MobileCallsHistoryScreen` | Экран истории звонков |
| `CallListItem` | Карточка звонка |
| `CallOverlay` | Оверлей активного звонка |

## API

См. `mockups/balloo-su/calls.html` — те же эндпоинты.

## Дизайн-требования

- Аватары — октагон, двойная рамка
- Chip: accent (принят) / danger (пропущен)
- Без border-radius
- 3 темы: dark, light, russian
