# Экран: Добавить устройство — Mobile

**ID:** `1_08_06`  
**Узел:** `у_08` — mobile (сборные мобильные макеты)  
**Web-источник:** `balloo-su/add-device.html`

## Описание

Мобильная версия экрана добавления устройства через QR-код. QR-код с таймером (60 сек), инструкция, описание «как это работает», раздел безопасности.

## Структура

### Topbar
- Логотип Balloo с dropdown навигацией (7 пунктов + divider)
- Название экрана: «Добавить устройство»
- Аватар пользователя (`avatar--sm avatar--bordered avatar--status-online avatar--ctx-contact`)
- Переключатель языка (🇷🇺 RU, `data-lang-toggle`)
- Переключатель темы (🌙 Тёмная, `data-theme-toggle`)

### Контент (single-column, phone-frame)
1. **Ссылка «Назад»** → `my-devices.html`
2. **Заголовок** — «➕ Добавить устройство»
3. **Подзаголовок** — «Отсканируйте QR-код камерой мобильного устройства»
4. **QR-карточка:**
   - Таймер: «QR-код действует **60** сек.» (accent → danger при ≤10 сек)
   - QR-код (160×160px) на белом фоне с октагон-логотипом B в центре
   - Deep link: `balloo://pair/<token>`
   - Кнопки «🔄 Обновить код» и «Отмена»
5. **Карточка «📋 Инструкция»** — 5 шагов привязки устройства
6. **Карточка «🔄 Как это работает»** — двусторонний QR, объяснение
7. **Карточка «🔒 Безопасность»** — 5 пунктов безопасности

## Двусторонний QR-поток

1. **Это устройство → мобильное:** показывает QR, мобильное сканирует камерой
2. **Мобильное → это устройство:** на мобильном «Мои устройства → Добавить», сканирует QR с экрана

### API привязки

| Метод | Эндпоинт | Описание |
|---|---|---|
| `POST` | `/devices/pair-token` | Получить токен привязки (TTL 60 сек) |
| `POST` | `/devices/pair/confirm` | Подтвердить привязку на обоих устройствах |

## Бизнес-логика

### JavaScript
- `startQRTimer()` — запуск обратного отсчёта 60 сек, цвет accent → danger при ≤10
- `refreshQR()` — перегенерация QR-кода, сброс таймера на 60 сек
- API: `POST /devices/pair-token` при каждом обновлении

## Навигация
- «Назад к устройствам» → `my-devices.html`
- «Отмена» → `my-devices.html`
