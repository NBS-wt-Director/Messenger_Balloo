## Описание

Мобильная версия экрана «Архив чатов». Список архивированных чатов с поиском, восстановлением и удалением. Бизнес-логика 1:1 с web-версией.

## Структура

- **Phone-frame** (360×760px) с notch, statusbar, home-bar
- **Topbar** (обязательный) — логотип Balloo с dropdown навигацией, заголовок «Архив», аватар, переключатель языка (🇷🇺 RU), переключатель темы (🌙 Тёмная)
- **Заголовок** — «Архив чатов», подзаголовок «N архивированных чатов»
- **Поиск** — строка поиска по архиву
- **Список чатов** — карточки с аватаром (октагон), названием, датой архивации, кнопками «↩ Восстановить» и «🗑»
- **Empty state** — «Нет архивированных чатов» (скрыт, когда есть чаты)
- **Tabbar** — нижняя навигация (Чаты активна, Контакты, Сторис, Звонки, Настройки)

## Бизнес-логика (из web)

- Восстановление чата → toast «Чат восстановлен»
- Удаление чата → toast «Чат удалён»
- Поиск по архивным чатам
- Архивирование через меню чата (⋮ → «В архив»)

## Компоненты (React Native / Expo)

| Компонент | Описание |
|---|---|
| `MobileArchiveScreen` | Экран архива |
| `ArchiveChatListItem` | Карточка архивного чата |
| `ArchiveSearchBar` | Строка поиска |

## Дизайн-требования

- Дизайн-система: `mockups/assets/common.css`
- Аватары — октагон (clip-path), двойная рамка
- Без border-radius (кроме switch и аватарок)
- 3 темы: dark, light, russian
- Tabbar: активный элемент — accent-цвет
