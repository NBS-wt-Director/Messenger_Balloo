## 📋 Описание

Мобильный полноэкранный просмотрщик изображений и видео из вложений чата. Поддерживает свайп-навигацию между медиа и pinch-zoom.

## 🏗️ Структура

### Статусбар просмотрщика
- Кнопка «Назад» (✕)
- Счётчик: «1 / 3»
- Действия: ⬇️ Скачать · 📤 Поделиться · ⋮ Ещё

### Лента миниатюр
- Горизонтально скроллящаяся лента превью
- Активная миниатюра подсвечена рамкой accent
- Иконки: 🖼 (изображение), 🎥 (видео)

### Область просмотра (swipe)
- **Swipe-left / swipe-right** — навигация между медиа
- **Pinch-zoom** — масштабирование от 1x до 5x
- Стрелки навигации по бокам
- Бейдж масштабирования: «100%»

### Нижний бар
- **Подпись:** текст описания медиа
- **Мета:** ❤️ Реакции · 💬 Комментарии · 📎 Имя файла и размер

## 🎨 Дизайн-требования
- Полноэкранный оверлей на тёмном фоне (#000)
- Свайп-анимация: 300ms ease
- Pinch-zoom: индикатор в центре снизу
- Миниатюры: 48×48px, скруглённые 8px

## 🧩 Компоненты
| Компонент | Назначение |
|-----------|-----------|
| `MediaViewer` | Полноэкранный просмотрщик |
| `MediaSwipeTrack` | Свайп-трек с анимацией |
| `MediaThumbnailStrip` | Лента миниатюр |
| `MediaZoomBadge` | Индикатор масштабирования |
| `MediaFooter` | Подпись + мета |

## ⚡ Интерактивность
- **Swipe:** touchstart → touchend, delta > 50px
- **Pinch-zoom:** два касания, ratio 1–5x
- **Tap-назад:** по клику на ✕
- **Переход к слайду:** по клику на миниатюру

## 📱 Адаптация под mobile
- Полноэкранный оверлей с fixed inset
- Touch-события для свайпа и pinch-zoom
- Миниатюры горизонтально скроллятся
- Кнопки действий в статусбаре
