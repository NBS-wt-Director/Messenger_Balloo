# Экран: Мои устройства — Mobile

**ID:** `1_08_07`  
**Узел:** `у_08` — mobile (сборные мобильные макеты)  
**Web-источник:** `balloo-su/my-devices.html`

## Описание

Мобильная версия страницы «Мои устройства». Список активных сессий с метаданными, переименование, разворачиваемые детали с полной информацией сессии, завершение сессий.

## Структура

### Topbar
- Логотип Balloo с dropdown навигацией (7 пунктов + divider)
- Название экрана: «Мои устройства»
- Аватар пользователя (`avatar--sm avatar--bordered avatar--status-online avatar--ctx-contact`)
- Переключатель языка (🇷🇺 RU, `data-lang-toggle`)
- Переключатель темы (🌙 Тёмная, `data-theme-toggle`)

### Контент (single-column, phone-frame)
1. **Заголовок** — «📱 Мои устройства»
2. **Подзаголовок** — «Активные сессии на ваших устройствах»
3. **Статистика** (3 карточки в ряд):
   - Всего устройств: 4
   - Активных сейчас: 2
   - Узлов подключено: 3
4. **Карточка текущего устройства** (accent border):
   - Chip «Это устройство» + «Сейчас активно»
   - Иконка 💻, название «Windows Desktop»
   - Методанные: узлы, браузер/ОС, активность, IP
   - Кнопки: ✏ Переименовать, 📋 Подробнее
   - Раскрываемые детали: Session ID, создана, истекает, tokens, WebSocket
5. **Карточки других устройств** (3 шт.):
   - iPhone 15 Pro, Chrome (Web PWA), Android (Samsung S24)
   - Каждая: иконка, название, подзаголовок с метаданными
   - Кнопки: ✏ (переименовать), 📋 (детали), «Остановить» (danger)
   - Раскрываемые детали с Session ID, timestamps, tokens
6. **Кнопка «➕ Добавить устройство»** → `add-device.html`
7. **Карточка «Завершить все другие сессии»** (danger border)

## Бизнес-логика

### JavaScript
- `toggleDetails(btn)` — раскрытие/скрытие деталей устройства
- `renameDevice(btn)` — prompt для переименования, обновление названия

### Навигация
- Аватар в topbar → `profile.html`
- «Добавить устройство» → `add-device.html`
- «Остановить» — confirmation dialog, затем alert

## API

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/devices` | Список всех устройств/сессий |
| `GET` | `/devices/:id` | Информация об устройстве |
| `PATCH` | `/devices/:id` | Переименовать устройство |
| `DELETE` | `/devices/:id` | Завершить сессию |
| `GET` | `/sessions/:id` | Информация о сессии |
| `DELETE` | `/sessions/:id` | Завершить сессию |
| `DELETE` | `/sessions` | Завершить все другие сессии |
