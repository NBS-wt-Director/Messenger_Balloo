# Экран: Пустой чат — Mobile

**Функция:** `0_08_04` — Мобильный чат (первый экран)

---

## 📋 Описание

Мобильный экран первого экрана чата — показывает пользователю, что чат пуст, и предлагает действия для начала общения.

## 🏗️ Структура

### Topbar (обязательный)
- Логотип Balloo с dropdown
- Заголовок: «Пустой чат»
- Аватар пользователя + переключатели языка/темы

### Основной контент
- **Иконка** 💬 (большая, в центре)
- **Заголовок:** «Чат пуст»
- **Подсказка:** «Начните общение! Отправьте первое сообщение или прикрепить файл.»
- **Действия:**
  - 📎 Прикрепить файл
  - 🎤 Голосовое сообщение
  - 📊 Опрос / Квиз
- **Совет:** «Удерживайте кнопку микрофона для быстрой записи голосового сообщения»

### Input area (disabled)
- Визуально показан, но отключён (opacity: 0.4) — для контекста

### Tabbar
- Чаты (активен) · Контакты · Сторис · Звонки · Настройки

## 🎨 Дизайн-требования
- Phone-frame с notch и home-bar
- Пустое состояние: центрированный контент, крупная иконка
- Кнопки: primary + secondary в вертикальном стеке
- Совет внизу в карточке с тёмным фоном

## 🧩 Компоненты
| Компонент | Назначение |
|-----------|-----------|
| `PhoneEmptyChatScreen` | Экран пустого чата |
| `PhoneEmptyChatIcon` | Большая иконка-заглушка |
| `PhoneEmptyChatActions` | Стек кнопок действий |
| `PhoneEmptyChatHint` | Карточка с советом |
| `PhoneTabbar` | Нижняя навигация |

## 📱 Адаптация под mobile
- Полноэкранный phone-frame
- Touch-friendly кнопки (min 44px)
- Вертикальный стек кнопок
