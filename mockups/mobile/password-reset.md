# Экран: Восстановление пароля — Mobile

**ID:** `1_08_05`  
**Узел:** `у_08` — mobile (сборные мобильные макеты)  
**Web-источник:** `balloo-su/password-reset.html`

## Описание

Мобильная версия экрана восстановления пароля. Многошаговая форма: email → кириллическая капча → проверка email → новый пароль.

## Структура

### Topbar
- Логотип Balloo с dropdown навигацией (7 пунктов + divider)
- Название экрана: «Восстановление пароля»
- Аватар пользователя (`avatar--sm avatar--bordered`)
- Переключатель языка (🇷🇺 RU, `data-lang-toggle`)
- Переключатель темы (🌙 Тёмная, `data-theme-toggle`)

### Контент (single-column, phone-frame, 4 шага)
1. **Шаг 1 — Запрос:** иконка 🔑, заголовок, поле email, кнопка «Далее», кнопка «Вернуться ко входу»
2. **Шаг 2 — Капча:** кириллическая капча (6 символов, наклон до 45°, градиент), поле ввода, кнопка «Другой», кнопка «Отправить ссылку»
3. **Шаг 3 — Проверка email:** сообщение о письме, адрес email, ссылка действительна 1 час, кнопка «Я перешёл по ссылке», кнопка «Отправить повторно»
4. **Шаг 4 — Новый пароль:** поле «Новый пароль», поле «Повторите пароль», кнопка «Сбросить пароль»

### Email verify notice
- Баннер о подтверждении email с ссылкой «Отправить письмо подтверждения»

## Капча (кириллическая, JS-генерация)

| Параметр | Значение |
|---|---|
| Символы | 6 кириллических из «АБВГДЕЖЗИКЛМНОПРСТУФХЦЧШЭ» |
| Наклон | Случайный от -45° до +45° |
| Фон | Градиент (10 вариантов пар цветов) |
| Символы | Градиент (10 вариантов), первый цвет совпадает с фоном |
| Шрифт | JetBrains Mono, font-weight: 800 |
| Кнопка | «Другой» — перегенерация |

### JS-функции
- `regenerateCaptcha()` — случайный фон, случайные символы, случайный наклон
- `goStep(n)` — переключение между шагами 1→2→3→4

## Бизнес-логика

### JavaScript
- `goStep(n)` — скрыть все `.onboarding__step`, показать `step-n`
- `regenerateCaptcha()` — генерация новой кириллической капчи

### Навигация
- «Вернуться ко входу» → `login.html`
- Шаг 4 «Сбросить пароль» → `login.html`
- «Отправить повторно» → повторная отправка

## API
- `POST /auth/password-reset/request` — запрос ссылки на сброс
- `POST /auth/password-reset/confirm` — подтверждение кода/ссылки
- `POST /auth/email-verify/send` — повторная отправка письма подтверждения
- `GET /auth/email-verify/:token` — верификация токеном
