# Экран: Регистрация — Mobile

**ID:** `1_08_02`  
**Узел:** `у_08` — mobile (сборные мобильные макеты)  
**Web-источник:** `balloo-su/register.html`

## Описание

Мобильная версия страницы регистрации нового аккаунта. Форма с OAuth, email, автоаватар из имени, captcha, чекбокс согласия с правилами, шаг подтверждения email-кодом.

## Структура

### Topbar
- Логотип Balloo с dropdown навигацией (7 пунктов + divider)
- Название экрана: «Регистрация»
- Аватар пользователя (`avatar--sm avatar--bordered avatar--status-online avatar--ctx-contact`)
- Переключатель языка (🇷🇺 RU, `data-lang-toggle`)
- Переключатель темы (🌙 Тёмная, `data-theme-toggle`)

### Контент (single-column, phone-frame)
1. **Заголовок** — «Создать аккаунт»
2. **Подзаголовок** — «Зарегистрируйтесь в Balloo Messenger»
3. **OAuth-кнопки** — Яндекс, Mail.ru, Rambler
4. **Разделитель** — «или email»
5. **Имя** — текстовое поле (с автогенерацией аватара)
6. **Аватарка** — превью автоаватара (октагон, градиент) + кнопка «Загрузить свою»
7. **Email** — текстовое поле
8. **Пароль** — с подсказкой о требованиях (латиница, кириллица, цифры, спецсимволы)
9. **Чекбокс** — согласие с правилами и политикой конфиденциальности
10. **Captcha** — картинка с кодом + поле ввода + кнопка обновления
11. **Кнопка «Зарегистрироваться»**
12. **Шаг подтверждения email** (скрыт по умолчанию) — 6-значный код
13. **Ссылка на вход** — «Войти»

### Автоаватар
- Генерируется из имени пользователя: первые буквы имени и фамилии
- Случайный градиент фона (6 вариантов)
- Загрузка своего аватара через file input (png/jpeg/svg)

### Шаг подтверждения email (скрыт изначально)
- Карточка с border-left: var(--accent)
- Поле для 6-значного кода (monospace, letter-spacing: 8px)
- Кнопка «Подтвердить»
- Ссылка «Отправить снова» (cooldown 60 сек)

## Бизнес-логика

### JavaScript
- `updateAvatarPreview()` — автогенерация аватара из имени (инициалы + градиент)
- `showCodeStep()` — показ шага email-кода, скрытие кнопки регистрации

### Навигация
- «Войти» → `login.html`
- OAuth — placeholder (Яндекс/Mail.ru/Rambler)

## API
- `POST /auth/register` — регистрация
- `POST /auth/register/verify` — подтверждение email-кода
- Rate limiting: 3 регистрации/час с одного IP
