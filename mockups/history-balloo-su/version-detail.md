# Детали версии (history-balloo-su/version-detail.html)

## Описание
Страница с подробной информацией о конкретной версии. Включает полный changelog, статистику релиза и навигацию к соседним версиям (предыдущая/следующая).

## Структура
- **Topbar**: логотип History, заголовок с номером версии
- **Content** (page-container):
  - Навигация: «← Все версии» + ссылки на соседние версии
  - Карточка заголовка версии: номер (chip), тип, статус, дата, название
  - Секция «Новое» (список)
  - Секция «Улучшения» (список)
  - Секция «Известные проблемы» (список)
  - Секция «Статистика релиза» (карточки с цифрами)
  - Кнопка «Скачать»
  - Навигация снизу: предыдущая/следующая версия

## Дизайн-требования
- Соседние версии: кнопки btn--secondary btn--sm
- Статистика: карточки с крупными цифрами
- Списки: `<ul style="list-style:disc">`

## Компоненты (React)
- `VersionDetail` — основная карточка с деталями
- `VersionChangelog` — список изменений (новое/улучшения/проблемы)
- `VersionStats` — статистика релиза
- `VersionNavigation` — навигация между соседними версиями

## API
- `GET /api/versions/:version` — детали конкретной версии
- `GET /api/versions/:version/neighbors` — соседние версии (prev/next)

## Адаптивность
- Desktop: полная ширина
- Mobile: вертикальный стек, навигация сворачивается

## Технологии
- React 19 / Next.js 15 (SSR, generateStaticParams для каждой версии)
