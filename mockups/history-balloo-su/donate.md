# Донат (history-balloo-su/donate.html)

## Описание
Страница доната на узле истории версий. Контекст: пользователь видит развитие проекта и может поддержать.

## Структура
- **Topbar**: логотип History, заголовок «Поддержать проект»
- **Content**: hero, прогресс цели, уровни поддержки, способы оплаты, ссылка на version-list.html

## API
- Единое API для всех узлов

## Технологии
- React 19 / Next.js 15 (SSR для SEO)
