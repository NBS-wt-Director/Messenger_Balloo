# Задание: command.balloo.su — Вход

## Макет
`command-balloo-su/login.html`

## Описание страницы
Экран входа в портал сотрудников. Корпоративный SSO через Balloo. Поддерживает OAuth (Яндекс корпоративный), Balloo SSO и email+пароль. Вход через другое устройство (QR).

## Структура страницы

### Topbar
- Логотип Command (иконка C на info-цвете)
- Заголовок «Вход для сотрудников»

### Auth-card (info border)
1. Иконка-октагон C
2. Заголовок «Портал сотрудников»
3. Подзаголовок «Вход для сотрудников компании Balloo»
4. OAuth:
   - Войти через Яндекс (корпоративный)
   - Войти через Balloo SSO
5. Email + пароль
6. Кнопка «Войти» (info-цвет)
7. **Вход через другое устройство (QR)**
   - Корпоративный SSO — единая сессия для всех узлов
8. Предупреждение: доступ только для действующих сотрудников

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Auth-card с info border
- Кнопка входа — info-цвет
- OAuth кнопки с цветными логотипами

## Компоненты
- `EmployeeLoginForm` — форма входа
- `OAuthButtons` — OAuth кнопки (Яндекс, Balloo SSO)
- `QRLoginButton` — кнопка входа через QR

## API
- `POST /api/v1/auth/command/login` — вход сотрудника
- `POST /api/v1/auth/oauth/yandex` — OAuth Яндекс
- `POST /api/v1/auth/sso` — Balloo SSO
- `POST /api/v1/devices/pair-token` — QR-токен

## Безопасность
- Доступ только для действующих сотрудников
- При увольнении — доступ аннулируется автоматически (HR sync)
- Корпоративный SSO — единая сессия для всех узлов
- Сессия сотрудника — TTL 8 часов
