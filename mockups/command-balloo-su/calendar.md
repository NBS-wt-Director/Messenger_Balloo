# Календарь (command-balloo-su/calendar.html)

## Описание
Календарь встреч и событий сотрудника. Режимы месяц/неделя. Отображает встречи (из модуля совещаний) и дедлайны задач. Навигация по месяцам, создание событий, список ближайших событий.

## Структура
- **Topbar**: логотип Command, заголовок «Календарь», навигация ‹ Месяц ›
- **Sidebar**: навигация портала (Календарь активно)
- **Content**:
  - Переключатель Месяц/Неделя + кнопка «+ Событие»
  - Сетка месяца (7 колонок, дни с событиями — chip по типу)
  - Сегодня — выделено accent-рамкой
  - Список ближайших событий (таблица: дата, время, событие, тип, участники)

## Типы событий
- Встреча (info/accent/warning) — из модуля совещаний
- Дедлайн задачи (danger) — из TODO/спринтов

## Дизайн-требования
- Дизайн-система: common.css
- Сетка 7 колонок, min-height ячеек
- Цвета событий: accent (релиз/ретро), info (стендап), danger (дедлайн), warning (1:1)
- Темы: dark, light, russian

## Компоненты (React)
- `CalendarView` — месяц/неделя с событиями (встречи + дедлайны задач)

## API
- `GET /api/command/me/calendar?month=YYYY-MM` — события месяца
- `POST /api/command/me/calendar/events` — создать событие
- Источники данных: `meetings` (встречи) + `tasks` (дедлайны)

## Технологии
- React 19 / Next.js 15
- Интеграция с модулями совещаний и задач
