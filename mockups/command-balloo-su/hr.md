# Задание: command.balloo.su — HR-модуль

## Макет
`command-balloo-su/hr.html`

## Описание страницы
HR-модуль: статистика (сотрудники, вакансии, кандидаты, онбординг), заявки на работу, онбординг новых сотрудников, команда, рассылки.

## Структура страницы

### Topbar
- Логотип Command (C на info-цвете)
- Заголовок «HR-модуль»
- Кнопка 📢 → модалка рассылки
- Аватар сотрудника, язык, тема

### Sidebar (narrow)
- 🏠 Дашборд
- 📋 Задачи
- 👥 HR (active)
- 📚 База знаний
- 🎯 Найм
- 📊 Мониторинг

### Content
1. Заголовок «HR-модуль» + подзаголовок «Заявки на работу • Онбординг • Рассылки»
2. **Карточки статистики** (4):
   - Сотрудников: 24 (accent)
   - Открытых вакансий: 6 (info)
   - Кандидатов: 18 (warning)
   - На онбординге: 2 (text-primary)
3. **Карточка «Заявки на работу»**:
   - Таблица: кандидат, должность, дата, статус (Скрининг / Собеседование / Оффер / Новая), кнопка «Открыть»
4. **Карточка «Онбординг (новые сотрудники)»**:
   - Список: аватар, имя, должность, «День N из 14», chip статуса
5. **Карточка «Команда»**:
   - Список: аватар, имя, должность, chip Lead, статус (в отпуске)

### Modal: Рассылка сотрудникам
- Тема (input)
- Сообщение (textarea)
- Получатели (select: Все / Отдел разработки / Дизайн / DevOps)
- Кнопки: Отмена / Отправить

## Функционал
- **Статистика** — сотрудники, вакансии, кандидаты, онбординг
- **Заявки** — просмотр, открытие, изменение статуса
- **Онбординг** — отслеживание прогресса (День N из 14)
- **Команда** — список сотрудников с ролями
- **Рассылка** — модалка отправки сообщений сотрудникам

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Логотип Command — info-цвет
- Аватары-октагоны
- Статусы заявок: chip (Скрининг=info, Собеседование=warning, Оффер=accent, Новая=default)
- Онбординг: chip (В процессе=warning, Старт=info)

## Компоненты
- `CommandSidebar` — sidebar навигации
- `HRStats` — сетка статистики (4 карточки)
- `JobApplicationsTable` — таблица заявок
- `OnboardingList` — список онбординга (аватар, имя, день N/14, статус)
- `TeamList` — список команды
- `BroadcastModal` — модалка рассылки сотрудникам

## API
- `GET /api/v1/command/hr/stats` — статистика HR
- `GET /api/v1/command/hr/applications` — заявки на работу
- `PATCH /api/v1/command/hr/applications/:id` — изменение статуса
- `GET /api/v1/command/hr/onboarding` — сотрудники на онбординге
- `GET /api/v1/command/team` — список команды
- `POST /api/v1/command/broadcast` — рассылка сотрудникам

## Безопасность
- SSO / OAuth для входа
- Доступ только для сотрудников
- Рассылки — только HR / Lead

## Адаптивность
- Desktop: sidebar + content, таблицы
- Mobile: sidebar → drawer, карточки

## Технологии
- React 19 + Next.js
- Zustand: `commandStore` (hrStats, applications, onboarding, team)
- Рассылки: email + in-app уведомления
