# Подразделения (command-balloo-su/departments.html)

## Описание
Структура компании: все отделы с сотрудниками и вакансиями. Сотрудник может просматривать другие отделы.

## Структура
- **Topbar**: логотип Command, заголовок «Подразделения»
- **Sidebar**: навигация портала (с активным «Подразделения»)
- **Content**:
  - Статистика (отделов, сотрудников, вакансий)
  - Карточки отделов: иконка, chip «Мой отдел» (если свой), название, описание, аватарки сотрудников, количество

## Компоненты (React)
- `DepartmentList` — список отделов
- `DepartmentCard` — карточка отдела с превью сотрудников

## API
- `GET /api/departments` — все отделы
- `GET /api/departments/:id/members` — участники отдела (для превью)

## Технологии
- React 19
