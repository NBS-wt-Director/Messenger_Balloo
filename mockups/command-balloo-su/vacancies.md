# Вакансии (command-balloo-su/vacancies.html)

## Описание
Публичная страница вакансий для не-сотрудников и неавторизованных пользователей. Доступна без входа в корпоративный портал. При попытке залогиниться без прав сотрудника — редирект сюда.

## Структура
- **Topbar**: логотип Command, заголовок «Вакансии» (без аватара — публичная страница)
- **Content** (page-container):
  - Заголовок и подзаголовок
  - Статистика (вакансий, отделов, сотрудников)
  - Tabs по отделам: Все / Разработка / Дизайн / Инфраструктура / Документация
  - Список карточек вакансий: иконка, chip статуса, должность, описание, зарплатная вилка, количество кандидатов, стрелка →
  - Ссылка «Почему именно наша команда?»

## Дизайн-требования
- Публичная страница: без sidebar, без аватара в topbar
- Card--hover для вакансий
- Chips: accent (активна), warning (почти закрыта), default (новая)

## Компоненты (React)
- `VacancyList` — список вакансий
- `VacancyCard` — карточка вакансии (минимальная инфо)
- `DepartmentTabs` — фильтр по отделам

## API
- `GET /api/vacancies` — список публичных вакансий
- `GET /api/vacancies?department=dev` — фильтр по отделу
- `GET /api/vacancies/stats` — статистика (вакансий, отделов, сотрудников)

## Технологии
- React 19 / Next.js 15 (SSR для SEO)
