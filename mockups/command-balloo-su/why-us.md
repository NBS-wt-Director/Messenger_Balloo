# Почему наша команда (command-balloo-su/why-us.html)

## Описание
Публичная страница «Почему именно наша команда — твоя работа мечты». Рассказывает о миссии, преимуществах, стеке и команде.

## Структура
- **Topbar**: логотип Command, заголовок «Почему мы» (публичная страница)
- **Content** (page-container):
  - Hero-блок
  - 2 ряда карточек преимуществ (по 3 карточки): миссия, remote, свобода, зарплата, ДМС, рост
  - Секция «Наш стек» (chips с технологиями)
  - Секция «Наша команда» (аватарки сотрудников)
  - CTA: ссылка на вакансии

## Компоненты (React)
- `WhyUsHero` — заголовок
- `BenefitCard` — карточка преимущества
- `TechStack` — список технологий (chips)
- `TeamPreview` — аватарки команды

## API
- `GET /api/team/members` — список сотрудников (для превью)
- `GET /api/company/stack` — стек технологий

## Технологии
- React 19 / Next.js 15 (SSR для SEO)
