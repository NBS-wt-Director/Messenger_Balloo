# Задачи / TODO (command-balloo-su/todo.html)

## Описание
Управление задачами: личные задачи и задачи отдела. Спринты, приоритеты, дедлайны. Чекбоксы для завершения.

## Структура
- **Topbar**: логотип Command, заголовок «Задачи», кнопка новой задачи, аватар
- **Sidebar**: мои задачи, задачи отдела, срочные, завершённые, спринт, бэклог
- **Content**:
  - Tabs: Личные / Отдел
  - Статистика (активных, сегодня, спринт, завершено)
  - Секции: Срочные / В работе / Бэклог / Недавно завершённые
  - Каждая задача: чекбокс, chip приоритета, название, дедлайн

## Компоненты (React)
- `TodoList` — список задач
- `TodoItem` — элемент задачи с чекбоксом
- `SprintProgress` — прогресс спринта
- `TodoTabs` — переключение личные/отдел

## API
- `GET /api/tasks?scope=personal` — личные задачи
- `GET /api/tasks?scope=department` — задачи отдела
- `POST /api/tasks` — создание задачи
- `PATCH /api/tasks/:id` — обновление статуса
- `GET /api/sprints/current` — текущий спринт

## Технологии
- React 19
- WebSocket для real-time обновлений
