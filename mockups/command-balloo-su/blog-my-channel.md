# Задание: command.balloo.su — Мой канал

## Макет
`command-balloo-su/blog-my-channel.html`

## Описание страницы
Дашборд личного канала сотрудника. Сотрудник — автор и модератор. Статьи канала, модерация комментариев (оставить/скрыть), статистика просмотров/реакций. Компания не может удалять посты.

## Структура страницы

### Topbar
- Логотип Command, заголовок «Мой канал»

### Sidebar (narrow)
- Навигация портала, Мой канал (active), Настройки канала

### Content (page-container)
1. **Заголовок** + подзаголовок (вы автор и модератор)
2. **Статистика** — 4 карточки: статей, просмотров, реакций, комментариев
3. **Tabs** — Статьи / Модерация комментариев / Статистика
4. **Tab: Статьи** — таблица статей канала
5. **Tab: Модерация** — список комментариев на модерацию: автор, статья, текст, кнопки «Оставить» / «Скрыть»
6. **Tab: Статистика** — график просмотров, топ статей

## Функционал
- **Модерация комментариев** — оставить / скрыть (только в своём канале)
- **Просмотр статистики** — графики, топ статей
- **Управление статьями** — переход к редактору

## Дизайн-требования
- Tabs — `tabs` + `tab-panel` компоненты
- График — bar chart (CSS bars)
- Комментарии — отступы, аватары

## Компоненты
- `MyChannelPage` — страница канала владельца
- `CommentModerationList` — список комментариев на модерацию
- `ChannelStats` — статистика канала

## API
- `GET /api/blog/my-channel` — данные личного канала + статьи
- `GET /api/blog/my-channel/comments` — комментарии для модерации
- `DELETE /api/blog/my-channel/comments/:id` — скрыть комментарий
- `GET /api/blog/my-channel/stats` — статистика

## Адаптивность
- Desktop: sidebar + content
- Mobile: tabs скроллятся

## Технологии
- React 19 + Next.js
- Графики: CSS bars / recharts
