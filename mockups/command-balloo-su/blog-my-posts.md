# Задание: command.balloo.su — Мои статьи

## Макет
`command-balloo-su/blog-my-posts.html`

## Описание страницы
Список статей сотрудника во всех каналах, где он автор. Статусы: черновик, на ревью, опубликован, отклонён, нужны правки. Создание новой статьи. Комментарий ревьюера при статусе «нужны правки».

## Структура страницы

### Topbar
- Логотип Command, заголовок «Мои статьи», кнопка ✏ (новая статья)

### Sidebar (narrow)
- Навигация портала + новая секция «Блог»: Мои статьи (active), Мой канал, Настройки канала

### Content (page-container)
1. **Заголовок** + подзаголовок
2. **Фильтр по статусам** — Все / Черновики / На ревью / Опубликованы / Нужны правки
3. **Таблица статей** — заголовок, канал, статус, дата, просмотры, действия (👁, ✏, 🗑)
4. **Карточка «Нужны правки»** — комментарий ревьюера + кнопка «Внести правки»

## Функционал
- **Создать статью** — кнопка ✏ → `blog-editor.html`
- **Редактировать** — только если `draft` или `changes_requested`
- **Удалить** — только если `draft`
- **Фильтр по статусам**

## Дизайн-требования
- Sidebar с новой секцией «Блог»
- Таблица — `table` компонент
- Статусы — chips: accent (опубликован), warning (на ревью), danger (нужны правки), default (черновик)

## Компоненты
- `MyPostsPage` — страница моих статей
- `PostStatusBadge` — бейдж статуса статьи
- `ReviewerFeedbackCard` — карточка с комментарием ревьюера

## API
- `GET /api/blog/my-posts` — статьи сотрудника (все каналы, где автор)
- `DELETE /api/blog/posts/:id` — удалить черновик

## Адаптивность
- Desktop: sidebar + content
- Mobile: sidebar скрывается, таблица скроллится

## Технологии
- React 19 + Next.js
- Авторизация сотрудника (SSO/OAuth)
