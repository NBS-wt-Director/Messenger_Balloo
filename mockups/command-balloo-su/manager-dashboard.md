# Дашборд руководителя — `1_03_25`

**Узел:** `у_03` — command.balloo.su  
**Функция:** `0_03_16` — Управление командой  
**Формат:** Отдельный экран

---

## Описание

Главный экран руководителя команды. Показывает метрики спринта, burndown chart, статус команды, срочные задачи и ближайшие дедлайны. Позволяет переключаться между командами и временными периодами.

---

## Структура

### Topbar
- Логотип Command
- Заголовок: «Дашборд руководителя»
- Селектор команды (выбор команды для просмотра)
- Кнопка «Отчёт» (экспорт)
- Переключатель периодов (Спринт / Месяц / Квартал)

### Sidebar (левая колонка, ~25%)
- Список навигации: Дашборд, Профиль, Задачи, Календарь, Чат, Совещания, Мой отдел, HR, Найм, База знаний
- Активный пункт: «Дашборд»

### Content
1. **Заголовок страницы**
   - Название + период спринта
   - Табы: Спринт / Месяц / Квартал

2. **KPI-карточки (4 шт., в ряд)**
   - Активные задачи (из N)
   - Задачи завершены (за спринт, % в срок)
   - Просрочено (↑ к прошлой неделе)
   - Burndown осталось (стори-пойнтов)

3. **Burndown Chart + Статус команды (2 колонки)**
   - **Burndown Chart** (SVG):
     - Идеальная линия (зелёная, dashed)
     - Фактическая линия (синяя, solid)
     - Область под фактической линией (полупрозрачная)
     - Маркер «Сегодня» (жёлтая вертикальная линия)
     - Подписи дней недели, оси SP
   - **Статус команды** (вертикальный список):
     - Аватар, имя, кол-во задач, статус
     - Цветной индикатор: ● зелёный (в работе), красный (блок), жёлтый (инфо), серый (в отпуске)

4. **Срочные задачи + Дедлайны (2 колонки)**
   - **Срочные задачи** (карточки с цветовой индикацией):
     - 🔥 Критично (красная рамка)
     - ⏰ Скоро (жёлтая рамка)
     - 📋 Нормально (серая)
   - **Ближайшие дедлайны** (таблица):
     - Задача, дедлайн, осталось (chip с цветом)

## Дизайн-требования

- **Тема:** dark (по умолчанию), light, russian
- **KPI-карточки:** grid 4 колонки, glassmorphism
- **Burndown Chart:** SVG inline, без библиотек
- **Статус команды:** flex-col, аватары octagon
- **Срочные задачи:** карточки с цветной левой рамкой
- **Дедлайны:** таблица с chip-статусами

## API

### GET `/api/command/dashboard?teamId={id}&period={sprint|month|quarter}`
- **Авторизация:** JWT (руководитель)
- **Ответ:** `{ kpis, burndown: [{ day, ideal, actual }], team: [...], urgentTasks: [...], deadlines: [...] }`

### GET `/api/command/teams`
- **Авторизация:** JWT (руководитель)
- **Ответ:** список команд руководителя

### WebSocket `dashboard:team:{id}:update`
- Направление: server → client
- Payload: `{ kpis, burndown, urgentTasks }`
- Описание: обновление метрик в реальном времени

## Адаптивность

- **Desktop (>1024px):** полная сетка, 4 KPI-карточки, 2 колонки для chart/team, 2 колонки для tasks
- **Tablet (768–1024px):** 2 KPI-карточки в ряд, chart и team в колонку
- **Mobile (<768px):** 1 KPI-карточка, все секции в вертикальном стеке
