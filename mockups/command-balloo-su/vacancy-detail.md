# Детали вакансии (command-balloo-su/vacancy-detail.html)

## Описание
Страница конкретной вакансии с полным описанием. Содержит ссылку на анкету заявки с подгрузкой ID вакансии.

## Структура
- **Topbar**: логотип Command, заголовок «Вакансия»
- **Content** (page-container):
  - Ссылка «← Все вакансии»
  - Карточка вакансии: иконка, должность, отдел, chips (статус, удалённо, занятость, зарплата)
  - Секция «О позиции»
  - Секция «Что делать» (список обязанностей)
  - Секция «Что ожидаем» (список требований)
  - Секция «Что предлагаем» (список условий)
  - Карточка с кнопкой «Откликнуться» → application-form.html?vacancy_id=ID

## Компоненты (React)
- `VacancyDetail` — основная карточка
- `VacancyRequirements` — список требований
- `VacancyBenefits` — список условий
- `ApplyButton` — кнопка отклика с передачей ID

## API
- `GET /api/vacancies/:id` — детали вакансии
- ID вакансии передается в URL: `?vacancy_id=ID`

## Технологии
- React 19 / Next.js 15 (SSR для SEO)
