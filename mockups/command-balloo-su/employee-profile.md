# Профиль сотрудника (command-balloo-su/employee-profile.html)

## Описание
Профиль сотрудника с корпоративными данными: должность, дата найма, корпоративный email, отдел, руководитель, контакты, метрики.

## Структура
- **Topbar**: логотип Command, заголовок «Профиль сотрудника»
- **Sidebar**: навигация портала (Профиль активно)
- **Content**:
  - Карточка профиля (аватар XL, имя, должность, чипы статуса/отдела)
  - Сетка деталей: должность, отдел, дата найма, корпоративный email, руководитель, стаж
  - Контакты (Telegram, внутренний чат, рабочее место)
  - Метрики (активные задачи, завершено за квартал, встреч на неделе)

## Дизайн-требования
- Дизайн-система: common.css
- Октагон-аватар XL
- Темы: dark, light, russian

## Компоненты (React)
- `EmployeeProfileCard` — карточка профиля сотрудника

## API
- `GET /api/command/me/profile` — профиль текущего сотрудника
- `GET /api/command/employees/:id` — профиль сотрудника по ID

## Технологии
- React 19 / Next.js 15
- SSO-авторизация сотрудников
