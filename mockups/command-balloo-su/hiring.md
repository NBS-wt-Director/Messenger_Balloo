# Задание: command.balloo.su — Найм

## Макет
`command-balloo-su/hiring.html`

## Описание страницы
Модуль найма: воронка найма (отклики → скрининг → собеседование → оффер → приняты), открытые вакансии, кандидаты на собеседовании. Модалка создания вакансии.

## Структура страницы

### Topbar
- Логотип Command (C на info-цвете)
- Заголовок «Найм»
- Кнопка ✏ → модалка новой вакансии
- Аватар сотрудника, язык, тема

### Sidebar (narrow)
- 🏠 Дашборд
- 📋 Задачи
- 👥 HR
- 📚 База знаний
- 🎯 Найм (active)
- 📊 Мониторинг

### Content
1. Заголовок «Найм» + подзаголовок «Вакансии • Кандидаты • Этапы собеседований»
2. **Карточка «Воронка найма»** (5 этапов):
   - Откликов: 45 (info)
   - Скрининг: 18 (warning)
   - Собеседование: 8 (accent)
   - Оффер: 3 (text-primary)
   - Приняты: 2 (accent)
3. **Карточка «Открытые вакансии»**:
   - Таблица: должность, отдел, кандидатов, статус (Активна / Почти закрыта / Новая)
   - Senior Frontend, Backend, DevOps, UI/UX, QA, Technical Writer
4. **Карточка «Кандидаты на собеседовании»**:
   - Список: аватар, имя, должность, этап, chip статуса
   - Алексей Морозов — Техническое собеседование (Назначено)
   - Елена Волкова — Тестовое задание (В работе)
   - Дмитрий Соколов — Оффер (Оффер)

### Modal: Новая вакансия
- Должность (input)
- Отдел (select: Разработка / Дизайн / Инфраструктура / Документация)
- Описание (textarea)
- Зарплатная вилка (От / До)
- Кнопки: Отмена / Опубликовать

## Функционал
- **Воронка найма** — визуализация этапов (отклики → приняты)
- **Вакансии** — таблица, статусы, кол-во кандидатов
- **Кандидаты** — список с этапами собеседований
- **Создать вакансию** — модалка (должность, отдел, описание, зарплата)
- **Открыть кандидата** — детальная карточка (v2)

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Логотип Command — info-цвет
- Воронка — 5 карточек с крупными цифрами (24px, 800 weight)
- Вакансии: chip статуса (Активна=accent, Почти закрыта=warning, Новая=default)
- Кандидаты: chip (Назначено=warning, В работе=info, Оффер=accent)
- Аватары-октагоны

## Компоненты
- `CommandSidebar` — sidebar навигации
- `HiringFunnel` — воронка найма (5 этапов)
- `VacanciesTable` — таблица вакансий
- `CandidatesList` — список кандидатов с этапами
- `CandidateItem` — элемент (аватар, имя, должность, этап, статус)
- `NewVacancyModal` — модалка создания вакансии

## API
- `GET /api/v1/command/hiring/funnel` — данные воронки
- `GET /api/v1/command/hiring/vacancies` — список вакансий
- `POST /api/v1/command/hiring/vacancies` — создание вакансии
- `GET /api/v1/command/hiring/candidates` — кандидаты на собеседовании
- `PATCH /api/v1/command/hiring/candidates/:id/stage` — изменение этапа

## Адаптивность
- Desktop: sidebar + content, таблицы
- Mobile: sidebar → drawer, воронка подряд

## Технологии
- React 19 + Next.js
- Zustand: `commandStore` (funnel, vacancies, candidates)
- Интеграция: ATS-система (v2)
