# 1_03_23 — Кандидат (детальный экран)

## Описание
Экран детального просмотра конкретного кандидата в HR-модуле command.balloo.su. Содержит информацию о кандидате, текущий этап в воронке найма, резюме, заметки команды и историю действий.

## Структура
- **Topbar**: название кандидата, кнопка экспорта резюме
- **Sidebar**: навигация по узлу Command (Найм выделен активным)
- **Content**:
  - Карточка кандидата (аватар, ФИО, контакты, вакансия, этап)
  - Индикатор воронки (6 этапов с визуальным статусом)
  - Левая колонка: резюме, действия, заметки
  - Правая колонка: история действий, информация о вакансии

## Дизайн-требования
- common.css, glassmorphism, темы
- Аватар — октагон с двойной рамкой
- Этапы воронки: ✅ (пройден), 🔵 (текущий), ⬜ (будущий)
- Timeline для истории действий

## Компоненты
- `CandidateHeader` — аватар + ФИО + контакты + этап
- `StageFunnel` — индикатор воронки (6 шагов)
- `ResumeCard` — информация из резюме
- `ActionButtons` — смена этапа, заметка, оффер, отклонение
- `NotesList` — список заметок команды
- `ActivityTimeline` — хронология действий

## API
- `GET /api/v1/hiring/candidates/:id` — данные кандидата
- `PATCH /api/v1/hiring/candidates/:id/stage` — смена этапа
- `POST /api/v1/hiring/candidates/:id/notes` — добавить заметку
- `POST /api/v1/hiring/candidates/:id/offer` — отправить оффер
- `POST /api/v1/hiring/candidates/:id/reject` — отклонить
- `GET /api/v1/hiring/candidates/:id/history` — история действий
- `GET /api/v1/hiring/candidates/:id/resume` — скачать резюме
