# Совещания (command-balloo-su/meetings.html)

## Описание
Страница корпоративных совещаний и звонков. Расписание встреч, подключение к звонку (WebRTC), записи и протоколы.

## Структура
- **Topbar**: логотип Command, заголовок «Совещания», кнопка нового совещания, аватар
- **Sidebar**: предстоящие, прошедшие, повторяющиеся, повестки
- **Content**:
  - Баннер активного совещания (если идёт) с кнопкой «Присоединиться»
  - Список предстоящих встреч: дата, название, время, участники, кнопка «Принять»
  - Список прошедших встреч: записи, протоколы

## Компоненты (React)
- `MeetingBanner` — баннер активного совещания
- `MeetingCard` — карточка встречи
- `MeetingRecording` — ссылка на запись
- `MeetingProtocol` — протокол встречи

## API
- `GET /api/meetings` — список встреч
- `GET /api/meetings/upcoming` — предстоящие
- `GET /api/meetings/past` — прошедшие (с записями)
- `POST /api/meetings` — создание встречи
- `WS: meeting:join` — подключение к звонку (WebRTC)

## Технологии
- WebRTC (корпоративные звонки)
- React 19
- Запись звонков (media server)
