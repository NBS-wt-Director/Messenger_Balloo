# Задание: command.balloo.su — Настройки канала

## Макет
`command-balloo-su/blog-channel-settings.html`

## Описание страницы
Настройки оформления личного канала. Сотрудник меняет как ему хочется: название, описание, аватар, баннер, акцентный цвет, URL-слаг, видимость, локализация описания.

## Структура страницы

### Topbar
- Логотип Command, заголовок «Настройки канала»

### Sidebar (narrow)
- Навигация портала, Настройки канала (active)

### Content (page-container)
1. **Заголовок** + подзаголовок
2. **Название канала** — input
3. **Описание** — textarea
4. **Аватар** — октагон-превью + загрузить/удалить
5. **Баннер** — gradient-превью + изменить
6. **Акцентный цвет** — палитра из 6 цветов
7. **URL-слаг** — `blog.balloo.su/` + input
8. **Видимость** — чекбоксы: виден в ленте, комментарии от гостей, реакции от гостей
9. **Локализация** — таблица переводов названия и описания (6 языков)
10. **Кнопки** — сохранить / назад

## Функционал
- **Загрузка аватара/баннера** — MinIO/Yandex Disk
- **Акцентный цвет** — применяется к аватару, баннеру, акцентам канала
- **URL-слаг** — уникальный, проверка доступности
- **Локализация** — добавить переводы для 6 языков

## Дизайн-требования
- Октагон-аватар с двойной рамкой
- Палитра цветов — 6 квадратов, выбранный с border
- Баннер — gradient preview

## Компоненты
- `ChannelSettingsPage` — страница настроек
- `AvatarUploader` — загрузка аватара (октагон)
- `BannerUploader` — загрузка баннера
- `ColorPalette` — палитра акцентных цветов
- `TranslationTable` — таблица локализаций

## API
- `GET /api/blog/my-channel` — текущие настройки
- `PUT /api/blog/my-channel` — обновить настройки (название, описание, цвет, слаг, видимость)
- `POST /api/blog/my-channel/avatar` — загрузить аватар
- `POST /api/blog/my-channel/banner` — загрузить баннер

## Адаптивность
- Desktop: sidebar + content
- Mobile: форма на весь экран

## Технологии
- React 19 + Next.js
- Загрузка файлов: MinIO / Yandex Disk
