# Карточка кандидата (интервью) — `1_03_24`

**Узел:** `у_03` — command.balloo.su  
**Функция:** `0_03_05` — Управление наймом  
**Формат:** Отдельный экран

---

## Описание

Экран технического интервью с кандидатом. Интервьюер проводит собеседование, оценивает кандидата по критериям, записывает заметки и принимает решение (принять / отклонить / предложить другую роль).

---

## Структура

### Topbar
- Логотип Command (как у всех экранов узла)
- Заголовок: «Интервью — [Имя кандидата]»
- Таймер интервью (обратный отсчёт, 60 мин)
- Кнопка «Заметки» (свернуть/развернуть область заметок)

### Sidebar (левая колонка, ~33%)
1. **Профиль кандидата**
   - Аватар, имя, должность
   - Дата отклика, вакансия, этап, интервьюер, дата/время, длительность
2. **Этапы найма**
   - Список этапов с чекмарками (✓ — пройдено, ● — текущий, ○ — будущий)
3. **Статистика**
   - Средний балл
   - Процент совпадения с вакансией

### Content (правая колонка, ~67%)
1. **Заголовок интервью**
   - Название этапа, уровень, длительность
   - Кнопки: «Видеозвонок», «Решение»
2. **Критерии оценки** (5 критериев)
   - Каждый: название + описание + кнопки 1–5
   - Итоговая строка: сумма баллов + процент
   - Цветовая индикация: ≤2 — красный, 3 — жёлтый, ≥4 — зелёный
3. **Заметки интервьюера**
   - Текстовая область для записи наблюдений
   - Сворачивается по кнопке

## Дизайн-требования

- **Тема:** dark (по умолчанию), light, russian
- **Sidebar:** `--bg-secondary`, border-right
- **Content:** `--bg-primary`, overflow-y-auto
- **Карточки:** glassmorphism (backdrop-filter: blur)
- **Кнопки оценки:** secondary по умолчанию, primary при выборе
- **Таймер:** monospace, предупреждение при < 5 мин
- **Модалки:** backdrop-blur, border-color по статусу

## API

### GET `/api/command/interviews/{id}`
- **Авторизация:** JWT (руководитель/HK)
- **Ответ:** объект интервью с кандидатом, этапами, критериями

### POST `/api/command/interviews/{id}/evaluate`
- **Тело:** `{ criteria: [{ id, score }], notes: string }`
- **Авторизация:** JWT (интервьюер)

### POST `/api/command/interviews/{id}/decision`
- **Тело:** `{ type: 'accept'|'reject'|'other_role', comment: string, otherRole?: string }`
- **Авторизация:** JWT (интервьюер)

### WebSocket `interview:{id}:timer`
- Направление: server → client
- Payload: `{ elapsed: number, total: number }`
- Описание: обновление таймера в реальном времени
