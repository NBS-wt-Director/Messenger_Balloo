# Управление отделом (command-balloo-su/department-management.html)

## Описание
Страница управления отделом для руководителей. Управление сотрудниками, правами, настройками отдела. Доступна только сотрудникам с ролью «Руководитель отдела».

## Структура
- **Topbar**: логотип Command, заголовок «Управление отделом», кнопка добавления, аватар
- **Sidebar**: навигация портала
- **Content**:
  - Chip «Руководитель» + chip отдела
  - Tabs: Сотрудники / Права доступа / Вакансии / Метрики
  - Таблица сотрудников: имя, должность, права, статус, действия
  - Матрица прав по сотрудникам (✅/❌)
  - Настройки отдела: название, руководитель, описание
  - Опасная зона: удаление отдела

## Дизайн-требования
- Матрица прав: таблица с ✅/❌
- Опасная зона: карточка с border-color: var(--danger)

## Компоненты (React)
- `DepartmentEmployees` — таблица сотрудников
- `PermissionsMatrix` — матрица прав
- `DepartmentSettings` — настройки отдела
- `DangerZone` — удаление отдела

## API
- `GET /api/departments/:id` — информация об отделе
- `PUT /api/departments/:id` — обновление настроек
- `GET /api/departments/:id/employees` — сотрудники с правами
- `PUT /api/departments/:id/employees/:userId/permissions` — изменение прав
- `DELETE /api/departments/:id` — удаление отдела (требует подтверждения админа)

## Технологии
- React 19
- Проверка прав на сервере (роль «Руководитель отдела»)
