# Отпуска и отсутствие — `1_03_26`

**Узел:** `у_03` — command.balloo.su  
**Функция:** `0_03_19` — Управление отпусками  
**Формат:** Отдельный экран

---

## Описание

Экран управления отпусками и отсутствием сотрудников. Руководитель видит календарь отсутствий команды, запросы на отсутствие (с возможностью утверждения/отклонения), статистику по остаткам отпуска и таблицу всех предстоящих отсутствий.

---

## Структура

### Topbar
- Логотип Command
- Заголовок: «Отпуска и отсутствие»
- Кнопка «+ Запрос» (создание нового запроса)
- Табы: Мои / Отдел / Все

### Sidebar (левая колонка, ~25%)
- Список навигации: Дашборд, Профиль, Задачи, Календарь, Чат, Совещания, **Мой отдел** (активный), HR, Найм, База знаний

### Content
1. **KPI-карточки (4 шт., в ряд)**
   - Остаток отпуска (из годовых)
   - Использовано (дней, % годового)
   - Активные запросы (на рассмотрении)
   - Сейчас в отпуске (человек)

2. **Календарь отсутствий + Запросы (2 колонки)**
   - **Календарь отсутствий** (мини-календарь на месяц):
     - Сетка 7 колонок (ПН–ВС)
     - Цветные блоки для отпусков (синий), больничных (жёлтый)
     - Маркер «сегодня» (зелёная рамка)
     - Тултипы при наведении (имя + тип)
     - Легенда: отпуск, сегодня, больничный
   - **Запросы на отсутствие** (вертикальный список):
     - Каждый запрос: аватар, имя, тип, период, статус
     -pending (на рассмотрении): кнопки «Утвердить» / «Отклонить» / «Обсудить»
     - approved: зелёная рамка
     - rejected: красная рамка, серая прозрачность

3. **Таблица отсутствия команды**
   - Столбцы: Сотрудник, Тип, Период, Дней, Статус, Замещающий
   - Цветные chip-статусы: отпуск, больничный, полу-день
   - Активные и запланированные отдельно

## API

### GET `/api/command/time-off?view={my|team|all}`
- **Авторизация:** JWT (руководитель / сотрудник)
- **Ответ:** `{ stats: { remaining, used, pending, active }, calendar: [...], requests: [...], teamAbsence: [...] }`

### POST `/api/command/time-off/requests`
- **Тело:** `{ type, startDate, endDate, substituteId, comment }`
- **Авторизация:** JWT (сотрудник / руководитель)
- **Ответ:** `{ requestId, status: 'pending' }`

### PATCH `/api/command/time-off/requests/{id}`
- **Тело:** `{ status: 'approved'|'rejected', comment?: string }`
- **Авторизация:** JWT (руководитель)
- **Ответ:** `{ requestId, status }`

### WebSocket `time-off:team:{id}:update`
- Направление: server → client
- Payload: `{ calendar, requests }`
- Описание: обновление календаря и запросов в реальном времени
