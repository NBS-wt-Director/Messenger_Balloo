# Экран: Настройки (Desktop)

**ID:** `1_09_04`  
**Узел:** `у_09` — desktop (обёртки окна ПК)  
**Web-источник:** `balloo-su/settings.html`

## Описание

Десктопная версия настроек с sidebar (категории) и content area (табы настроек). 13 вкладок настроек.

## Структура

### Titlebar
- Иконка Balloo (B)
- Заголовок: «Balloo Messenger — Настройки»
- Меню + контролы окна

### Window Body
#### Sidebar (категории)
1. 🔔 Уведомления (active)
2. 🎨 Оформление
3. 🌍 Язык
4. 🔒 Приватность
5. 💾 Хранилище
6. 📱 Устройства
7. 👤 Аккаунты

9. 💾 Кэш
10. ☁️ Yandex Disk

13. ℹ️ О Balloo

#### Content (табы)
**Tab: Уведомления**
- Push-уведомления (превью, группировка, звук)
- DND (расписание, геолокация с адресами)
- Звонки (прерывающий, вибрация)

**Tab: Оформление**
- 3 темы (тёмная, светлая, российская)

**Tab: Язык**
- 20 языков (3 группы) в select

**Tab: Приватность**
- Видимость профиля/статуса/групп/истории
- Чёрный список (разблокировать)

**Tab: Хранилище**
- Автозагрузка медиа (WiFi, мобильные)
- Управление кэшем

**Tab: Устройства**
- Активные сессии (текущее + iPhone + Samsung)
- Вызвать/Завершить сессию

**Tab: Аккаунты**
- Мультиаккаунт (текущий + другие)
- Переключение/добавление

**Tab: Безопасность**
- 2FA TOTP (QR-код, подтверждение)
- Резервные коды
- Отключение 2FA

**Tab: Кэш**
- Настройки кэширования
- Использование (847 МБ / 2 ГБ)
- Очистка (медиа, файлы, сообщения)

**Tab: Yandex Disk**
- Подключение, объём

**Tab: Донаты**
- История донатов (Баллоо, Блог)
- Управление подпиской

**Tab: Поддержка**
- Чат с поддержкой (превью + ввод)
- Самопомощь (FAQ, база знаний, правила)

**Tab: О Balloo**
- Версия, поддержка, лицензия, история версий

### Statusbar
- Статус подключения + информация о кэше

## Бизнес-логика

### JavaScript
- `switchTab(tabName)` — переключение табов (sidebar + content)
- `toggleGeoDND(el)` — показать/скрыть опции геолокации
- `togglePrivacyComboBox(select, comboId)` — показать/скрыть список контактов
- `unblockUser(name)` — разблокировка с подтверждением
- `soundCall(deviceName)` — push-вызов устройства

### Навигация
- Кнопки tab → обновление sidebar + content
- «📷 Добавить устройство (QR)» → `switchTab('add-device')`
- «💰 Поддержать проект» → `donate.html`
- «📋 Вся история» → `my-donates.html`
