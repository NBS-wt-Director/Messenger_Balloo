## Описание

Десктопная версия экрана «Звонки» — sidebar с фильтрами (тип звонка, статус) + content со списком звонков.

## Структура

- **Titlebar** — кастомный, с меню и системными кнопками
- **Боковая панель** — кнопки типов (📞 аудио / 📹 видео) + список фильтров (все, аудио, видео, принятые, пропущенные)
- **Контент** — заголовок, подзаголовок, список звонков
- **Statusbar** — статус подключения, версия

## Компоненты (Electron / Tauri)

| Компонент | Описание |
|---|---|
| `DesktopCallFilters` | Sidebar с фильтрами звонков |
| `DesktopCallList` | Список звонков в content |

## API

### WebSocket
- `call:invite` — входящий звонок
- `call:join` — присоединение к звонку
- `call:leave` — выход из звонка

### HTTP эндпоинты
- `GET /calls` — история звонков с пагинацией
- `GET /calls/:id` — детали звонка
- `POST /calls` — инициировать звонок
- `POST /calls/:id/end` — завершить звонок

## Бизнес-логика

### JavaScript-функции
- `openCall(type)` — инициировать звонок (audio/video)

### Навигация
- Фильтры вызывают `showToast()` с информацией о выбранном фильтре
- Кнопки 📞/📹 вызывают `openCall(type)`
