# Экран: Вход (Desktop)

**ID:** `1_09_07`  
**Узел:** `у_09` — desktop (обёртки окна ПК)  
**Web-источник:** `balloo-su/login.html`

## Описание

Десктопная версия страницы авторизации в центрированном окне.

## Структура

### Titlebar
- Иконка Balloo (B)
- Заголовок: «Balloo Messenger — Вход»
- Меню + контролы окна

### Window Body
Центрированная auth-card (max-width: 420px):
1. **Логотип** — 🦊 (маскот)
2. **Заголовок** — «С возвращением!»
3. **Подзаголовок** — «Войдите в свой аккаунт Balloo»
4. **OAuth-кнопки** — Яндекс, Mail.ru, Rambler
5. **Разделитель** — «или»
6. **Email форма** — email + пароль + «Забыли пароль?»
7. **Кнопка «Войти»**
8. **Разделитель**
9. **Вход через QR** — «Войти через другое устройство (QR)»
10. **Разделитель**
11. **Ссылка на регистрацию** — «Зарегистрироваться»
12. **Разделитель**
13. **Примечание** — «v2: Вход через Госуслуги и SMS-код»

### Statusbar
- Статус подключения + информация о кэше

### Modal: reCAPTCHA
- Модальное окно «Проверка reCAPTCHA»
- Чекбокс «Я не робот»
- Кнопка «Подтвердить»

## Бизнес-логика

### JavaScript
- `closeModal('modal-recaptcha')` — закрытие модалки reCAPTCHA

### Навигация
- «Забыли пароль?» → `password-reset.html`
- «Войти через QR» → `add-device.html`
- «Зарегистрироваться» → `register.html`
