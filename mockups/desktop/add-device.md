# Задание: Desktop — Добавить устройство (QR)

## Макет
`desktop/add-device.html`

## Описание страницы
Страница добавления нового устройства через QR-код в рамках desktop-приложения (Electron/Tauri). Показывает QR-код, инструкции и таймер. На десктопе показывается QR-код + текстовая инструкция. Мобильное устройство сканирует код камерой. Работает в обе стороны.

## Структура страницы

### Window frame (Electron/Tauri)
- **Titlebar** (40px): иконка-октагон «B» + заголовок «Balloo Messenger — Добавить устройство», меню, системные кнопки
- **Window body** (640px): sidebar (260px) + content

### Sidebar (260px)
- Навигация: Чаты / Звонки / Контакты / Настройки / **Мои устройства** (active) / Yandex Disk
- Юзер-блок внизу

### Content
1. **Заголовок** «➕ Добавить устройство» + кнопка «← Назад» к устройствам
2. **Подзаголовок** «Отсканируйте QR-код камерой мобильного устройства»
3. **Карточка QR-кода**:
   - Таймер обратного отсчёта (60 сек, краснеет на ≤10)
   - QR-код (220×220px) с октагон-логотипом Balloo в центре
   - Deep link: `balloo://pair/a3f8e91c7d2b`
   - Кнопки: «🔄 Обновить код» / «Отмена»
4. **Карточка инструкции** (нумерованный список):
   1. Откройте Balloo на новом устройстве
   2. На экране входа нажмите «Войти через другое устройство»
   3. Наведите камеру мобильного на QR-код
   4. Подтвердите вход на обоих устройствах
   5. Готово!
5. **Карточка «Как это работает»**:
   - Код работает в обе стороны (показать/сканировать)
   - Мобильное всегда сканирует камерой
   - Код истекает через 60 секунд
6. **Карточка «Безопасность»**:
   - Токен одноразовый, истекает через 60 сек
   - Подтверждение на обоих устройствах
   - Новое устройство наследует права, но не пароль
   - Сессию можно отозвать в любой момент

### Statusbar (24px)
- ● Подключено · WebSocket / 🔒 E2E / 💾 Yandex Disk / 📦 Кэш / v1.0.0-beta

## QR-код
- Генерируется на сервере: `POST /api/v1/devices/pair-token`
- Содержит: `balloo://pair/<token>`
- TTL: 60 секунд
- После сканирования: `POST /api/v1/devices/pair/confirm` на обоих устройствах
- Октагон-логотип Balloo в центре QR (поверх данных с коррекцией ошибок)
- На десктопе: QR показывается на экране, мобильное сканирует камерой
- Двусторонний поток: мобильное может показать свой QR, а десктоп — не может сканировать (нет камеры), но может показать код для сканирования другим мобильным

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Window frame: Electron/Tauri style
- QR-код на белом фоне (контраст)
- Октагон-логотип в центре QR
- Таймер: accent при >10 сек, danger при ≤10 сек
- Кнопка обновления — primary

## Компоненты
- `DesktopWindow` — обёртка окна
- `DesktopSidebar` — боковая навигация
- `QRCodeDisplay` — отображение QR с логотипом и таймером
- `PairingTimer` — таймер обратного отсчёта
- `PairingInstructions` — нумерованная инструкция
- `PairingSecurityInfo` — информация о безопасности

## API
- `POST /api/v1/devices/pair-token` — генерация токена привязки (возвращает QR-данные)
- `POST /api/v1/devices/pair/confirm` — подтверждение привязки (вызывается обоими устройствами)
- `GET /api/v1/devices/pair/:token/status` — статус привязки (pending/confirmed/expired)

## Технологии
- Electron 31 (primary) или Tauri (lightweight)
- React 19 + Next.js для контента
- QR-генерация: `qrcode` npm package (server-side) или `qrcode.react` (client-side)
- Deep link: `balloo://pair/<token>` обрабатывается мобильным приложением
- WebSocket: уведомление об успешной привязке в реальном времени
- Desktop не имеет камеры — только показывает QR для сканирования мобильным
