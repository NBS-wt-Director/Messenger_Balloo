# Экран: Полноэкранный просмотрщик медиа (Desktop)

**ID:** `1_09_21`  
**Узел:** `у_09` — desktop (обёртки окна ПК)  
**Функция:** `0_09_07` — полноэкранный просмотрщик изображений/видео

## Описание

Полноэкранный viewer для изображений, видео, документов и аудиофайлов в десктопном стиле. Поддержка галереи (слайд-навигация), зума, боковой панели миниатюр, информационной панели и клавиатурных сокращений.

## Структура

### Viewer Topbar (48px, overlay)
- **Левая часть**: кнопка ← (назад) + имя файла + метаданные (размер, разрешение)
- **Правая часть**:
  - 🖼 Галерея (G) — боковая панель миниатюр
  - ℹ️ Информация (I) — панель метаданных
  - ⛶ Полный экран (F) — fullscreen API
  - ⬇️ Скачать (S) — скачивание
  - 📤 Поделиться — поделиться ссылкой
  - ✕ Закрыть (Esc)

### Viewer Body (fullscreen)

#### Слайды (5 типов контента)
1. **Изображение** (macos.png, 1920×1080, 240 КБ)
2. **Изображение** (design.png, 3840×2160, 1.2 МБ)
3. **Видео** (demo.mp4, 15 МБ, 1920×1080, 2:34) — кнопка воспроизведения
4. **Документ** (spec.pdf, 340 КБ) — кнопки «Просмотр» и «Скачать»
5. **Аудио** (voice.ogg, 88 КБ, 0:14) — волна, управление, прогресс

#### Навигация
- Стрелки ← → (по бокам, 48×48px, glassmorphism)
- Точки-индикаторы (5 шт., bottom-center)
- Счётчик «1 / 5» (bottom-center, под точками)

#### Управление зумом
- Кнопки: − / 100% / + / ⊡ (сброс)
- Диапазон: 25% — 300%
- Шаг: 25%

#### Информационная панель (overlay, bottom)
- Файл, тип, размер, разрешение, отправитель, дата
- Переключается кнопкой ℹ️

#### Боковая панель (280px, right sidebar)
- Заголовок: «🖼 Галерея (5)»
- Список миниатюр (1:1 aspect ratio, hover border, active accent border)
- Футер: ⬇️ Скачать всё / 📤 Поделиться / 🗑 Удалить

## Бизнес-логика

### JavaScript
- `updateViewer()` — обновление active states (slides, dots, thumbs, counter)
- `nextSlide()` / `prevSlide()` — навигация ±1 по кругу
- `goToSlide(index)` — переход к конкретному слайду
- `closeViewer()` — закрытие с подтверждением
- `toggleSidebar()` — показать/скрыть галерею
- `toggleInfo()` — показать/скрыть инфо-панель
- `toggleFullscreen()` — fullscreen API
- `downloadMedia()` / `shareMedia()` — действия
- `zoomIn()` / `zoomOut()` / `zoomReset()` / `applyZoom()` — зум

### Клавиатурные сокращения
- `←` / `→` — предыдущий / следующий слайд
- `Esc` — закрыть просмотрщик
- `G` — переключить галерею
- `I` — показать информацию
- `F` — полный экран
- `S` — скачать
- `+` / `-` — зум +/−
- `0` — сбросить зум

### Свайпы (touch)
- Свайп влево → следующий слайд
- Свайп вправо → предыдущий слайд
- Порог: 50px

## Технологии
- **Electron** (primary) или **Tauri** (lightweight alternative)
- `requestFullscreen()` / `exitFullscreen()` — fullscreen API
- CSS `transform: scale()` — зум
- CSS `backdrop-filter: blur()` — glassmorphism overlay
- Touch events — свайпы
- React 19 + Next.js для контента

## Дизайн-требования
- Полностью тёмный фон (#000)
- Overlay-элементы с `backdrop-filter: blur(12px)`
- Без border-radius (кроме кнопок)
- Навигация: стрелки 48×48px, glassmorphism
- Миниатюры: 1:1 aspect ratio, active border — accent
- Прогресс аудио: 4px height, accent fill
