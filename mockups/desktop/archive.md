## Описание

Десктопная версия экрана «Архив» — sidebar с поиском и списком архивированных чатов + content с empty state. При клике на архивный чат — открывается чат в основной области.

## Структура

- **Titlebar** — кастомный, с меню и системными кнопками
- **Боковая панель** — заголовок с счётчиком, поиск по архиву, список архивных чатов (с opacity 0.7)
- **Контент** — empty state с подсказкой «Архивируйте чат через меню ⋮ → «В архив»»
- **Statusbar** — статус подключения, количество архивных чатов, версия

## Компоненты (Electron / Tauri)

| Компонент | Описание |
|---|---|
| `DesktopArchiveList` | Список архивированных чатов в sidebar |
| `DesktopArchiveSearch` | Поиск по архиву |

## API

### HTTP эндпоинты
- `GET /chats?archived=true` — список архивированных чатов
- `PATCH /chats/:id/unarchive` — восстановить чат из архива
- `DELETE /chats/:id` — удалить чат из архива
- `GET /chats/:id/messages` — загрузка сообщений восстановленного чата

## Бизнес-логика

### Навигация
- Клик на архивный чат → `chat.html` (открытие чата)
- «↩ Восстановить» → `PATCH /chats/:id/unarchive`
- «🗑 Удалить» → `DELETE /chats/:id`
