## Описание

Десктопная версия экрана «Вложения чата». Открывается по кнопке 📎 в заголовке чата внутри окна приложения. Сохраняет структуру окна (titlebar, sidebar, statusbar) для нативного опыта.

## Структура

- **Titlebar** — кастомный, с меню и системными кнопками
- **Боковая панель** — список чатов (с подсветкой активного)
- **Контент** — заголовок с навигацией, вкладки, поиск, тело с секциями
- **Statusbar** — статус подключения, E2E, версия

## Компоненты (Electron / Tauri)

| Компонент | Описание |
|---|---|
| `DesktopAttachmentsPanel` | Экран вложений внутри окна |
| `DesktopAttachmentsTabs` | Вкладки категорий |
| `DesktopAttachmentsList` | Список/сетка вложений |
