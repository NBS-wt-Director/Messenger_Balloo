## Описание

Десктопная версия формы подачи жалобы на сообщение. Открывается по кнопке 🚩 на сообщении внутри окна приложения.

## Структура

- **Titlebar** — кастомный с меню
- **Контент** — форма жалобы (панель 540px по центру)
- **Statusbar** — статус подключения, E2E, версия
- Форма идентична веб-версии, но вписана в окно приложения

## Компоненты (Electron / Tauri)

| Компонент | Описание |
|---|---|
| `DesktopReportPanel` | Экран жалобы внутри окна |
| `DesktopReportReasonList` | Список причин |
