# Экран: Создание опроса (Desktop)

**ID:** `1_09_06`  
**Узел:** `у_09` — desktop (обёртки окна ПК)  
**Web-источник:** `balloo-su/poll-editor.html`

## Описание

Десктопная версия редактора опросов/квизов в виде overlay поверх чата.

## Структура

### Titlebar
- Иконка Balloo (B)
- Заголовок: «Balloo Messenger — Создание опроса»
- Меню + контролы окна

### Window Body
Overlay поверх dimmed чата (opacity: 0.4):

#### Sidebar (dimmed)
- Поиск чатов
- Список чатов (Мария Андреева, «опрос создаётся…»)

#### Content (dimmed)
- Пример сообщения: «Какой цвет для акцента?»

#### Poll Editor Overlay (z-index: 100)
Карточка 520px:
1. **Заголовок** — «📊 Создать интерактив» + кнопка закрытия
2. **Типы** (табы):
   - 📊 Опрос (active)
   - 🎯 Квиз
   - ✅ Актив. список
   - 📋 Пассив. список
   - 👤 Персонали
3. **Вопрос** — текстовое поле
4. **Варианты ответа** — 3 варианта + «+ Добавить вариант»
5. **Правильный ответ** (только для квиза) — select
6. **Настройки**:
   - Анонимное голосование (checkbox)
   - Множественный выбор (checkbox)
   - Можно переслать (checkbox)
   - Срок действия (select: 24ч / 12ч / 1ч / без ограничений)
7. **Кнопки** — Отмена / Создать

### Statusbar
- Статус подключения + информация о кэше

## Бизнес-логика

### JavaScript
- `selectPollType(el, type)` — переключение типа + показ/скрытие поля «Правильный ответ»
  - type === 'quiz' → показать #quiz-correct

### Навигация
- Кнопка ✕ → `chat.html`
- «Отмена» → `chat.html`
- «Создать» → `chat.html`
