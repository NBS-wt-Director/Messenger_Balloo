# Экран: Профиль (Desktop)

**ID:** `1_09_05`  
**Узел:** `у_09` — desktop (обёртки окна ПК)  
**Web-источник:** `balloo-su/profile.html`

## Описание

Десктопная версия профиля с sidebar (список контактов) и content area (детальная карточка профиля).

## Структура

### Titlebar
- Иконка Balloo (B)
- Заголовок: «Balloo Messenger — Профиль»
- Меню + контролы окна

### Window Body
#### Sidebar (список контактов)
- **Поиск** — `search-input`
- **Активный контакт** — Иван Иванов (это я, чип «Это я»)
- Другие контакты — Мария Андреева

#### Content (flex: 1)
1. **Аватар** — восьмигранник XL + кнопка «Изменить аватар»
2. **Аккаунты** — 3 аккаунта (Иван, Мария, Рабочий) + slide-panel
3. **Основная информация** — имя, био, статус, дата рождения
4. **Оформление** — темы (3 шт.), языки (20 шт.)
5. **Yandex Disk** — подключение
6. **Поддержка проекта** — донат + мои донаты
7. **Помощь** — чат + FAQ
8. **Устройства** — список + ссылка на my-devices
9. **Приватность** — видимость, превью, заблокированные
10. **Опасная зона** — удаление аккаунта

### Statusbar
- Статус подключения + информация о кэше

## Бизнес-логика

### Slide Panels
- **avatar-panel** — изменить аватар (загрузить/камера/AI)
- **accounts-panel** — управление аккаунтами
- **blocked-panel** — заблокированные пользователи

### JavaScript
- `openAvatarPanel()` / `closeAvatarPanel()`
- `openAccountsPanel()` / `closeAccountsPanel()`
- `openBlockedPanel()` / `closeBlockedPanel()`
- `setTheme(theme)` — переключение темы
- Закрытие по клику на фон

### Навигация
- Аватар → `balloo-su/public-profile.html`
- «💰 Поддержать» → `donate.html`
- «📋 Мои донаты» → `my-donates.html`
- «📱 Мои устройства →» → `my-devices.html`
- «➕ Добавить устройство» → `add-device.html`
