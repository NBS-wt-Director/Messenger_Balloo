# Задание: Desktop — Мои устройства

## Макет
`desktop/my-devices.html`

## Описание страницы
Управление устройствами с активными сессиями в рамках desktop-приложения (Electron/Tauri). Доступно из боковой навигации (правое меню) авторизованного пользователя. Только для основного узла balloo.su, на платформе desktop.

## Структура страницы

### Window frame (Electron/Tauri)
- **Titlebar** (40px): иконка-октагон «B» + заголовок «Balloo Messenger — Мои устройства», меню (Файл/Правка/Вид/Окно/Справка), системные кнопки (─/▢/✕)
- **Window body** (640px): sidebar (260px) + content

### Sidebar (260px)
- Навигация: Чаты / Звонки / Контакты / Настройки / **Мои устройства** (active) / Yandex Disk
- Юзер-блок внизу: аватар-октагон + имя + статус

### Content
1. **Заголовок** «📱 Мои устройства» + кнопка «← Назад»
2. **Подзаголовок** «Активные сессии на ваших устройствах»
3. **Карточки статистики** (3): Всего устройств / Активных / Узлов подключено
4. **Карточка текущего устройства** (accent border):
   - Chip «Это устройство» + «Сейчас активно»
   - Иконка, название, локация · IP · версия
   - Метаданные: узлы, ОС/Electron, последняя активность, IP
   - Кнопки: Переименовать / Подробнее (раскрывает таблицу с session ID, токенами, WS, auto-launch, tray icon)
5. **Карточки других устройств** (по 1 на устройство):
   - Иконка, название, локация · время · версия
   - Кнопки: Переименовать / Подробнее / Остановить (danger)
   - Подробнее раскрывает метаданные и таблицу сессии
6. **Кнопка** «➕ Добавить устройство» → `add-device.html`
7. **Опасная зона**: «Завершить все другие сессии» (danger)

### Statusbar (24px)
- ● Подключено · WebSocket / 🔒 E2E / 💾 Yandex Disk / 📦 Кэш / v1.0.0-beta

## Функционал
- **Переименование устройства** — inline prompt, сохраняется в БД
- **Остановка сессии** — завершение сессии (revoke refresh token), подтверждение
- **Подробнее** — сворачиваемая панель с полной инфой сессии (session ID, токены, WS, push token, auto-launch, tray)
- **Завершить все другие** — revoke всех сессий кроме текущей
- **Добавить устройство** — переход на `add-device.html`

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Window frame: Electron/Tauri style (titlebar, statusbar, sidebar)
- Текущее устройство — accent border
- Сворачиваемые панели деталей
- Кнопка «Остановить» — danger
- Статистика в карточках с цветными числами
- Без скруглений (кроме системных кнопок при необходимости)

## Компоненты
- `DesktopWindow` — обёртка окна (titlebar + body + statusbar)
- `DesktopSidebar` — боковая навигация
- `DeviceCard` — карточка устройства с действиями
- `DeviceDetailsPanel` — сворачиваемая панель деталей сессии
- `DeviceStatsGrid` — сетка статистики
- `RenameDeviceDialog` — диалог переименования
- `StopSessionButton` — кнопка остановки с подтверждением

## API
- `GET /api/v1/devices` — список устройств с активными сессиями
- `PATCH /api/v1/devices/:id` — переименовать устройство
- `DELETE /api/v1/sessions/:id` — остановить сессию
- `DELETE /api/v1/sessions` (except current) — завершить все другие
- `GET /api/v1/sessions/:id` — детали сессии

## Технологии
- Electron 31 (primary) или Tauri (lightweight)
- React 19 + Next.js для контента
- IPC-каналы для нативных функций (tray, auto-launch)
- WebSocket для realtime-обновления списка устройств
