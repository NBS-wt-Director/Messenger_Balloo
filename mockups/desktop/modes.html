🔔 Системная интеграция

  • Нативные уведомления ОС — push через Notification API (Electron) / Tauri plugins
  • Tray icon — с бейджем непрочитанных, контекстным меню (развернуть/настройки/выйти)
  • Auto-launch — опциональный запуск при старте ОС
  • Deep links — balloo://chat/abc123 открывает чат в приложении
  • Badge на иконке — счётчик непрочитанных на иконке в dock/taskbar
  • Spellcheck — нативная проверка орфографии ОС
