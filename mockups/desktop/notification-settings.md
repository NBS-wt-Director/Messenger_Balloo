# Экран: Настройки уведомлений (Desktop)

**ID:** `1_09_20`  
**Узел:** `у_09` — desktop (обёртки окна ПК)  
**Функция:** `0_09_01` — настройки уведомлений с системной интеграцией

## Описание

Десктопная версия детальных настроек уведомлений с sidebar-навигацией по 7 разделам. Включает общие уведомления, каналы, чаты, DND, звуки, превью, системную интеграцию и отложенные уведомления.

## Структура

### Titlebar
- Иконка Balloo (B)
- Заголовок: «Balloo Messenger — Настройки уведомлений»
- Меню: Чаты / Сторис / Контакты / Настройки / Профиль / **Уведомления** / Архив
- Системные кнопки: ─ / ▢ / ✕

### Window Body

#### Sidebar (260px) — разделы уведомлений
1. 🔔 Общие (active)
2. 📢 Каналы
3. 💬 Чаты
4. 🔇 Не беспокоить
5. 🔊 Звуки
6. 👁 Превью
7. 🖥 Системная интеграция
8. ⏰ Отложенные

#### Content

**Tab: Общие**
- Включить уведомления (switch)
- Звук уведомлений (switch)
- Вибрация мобильных (switch)
- Группировка до 5 сообщений (switch)
- Уведомления о новых подключениях (switch)
- Закреплённые сообщения (switch)
- Упоминания и ответы (switch)

**Tab: Каналы**
- Звук для каналов (select)
- Группировка каналов (switch)
- Список каналов с переключателями:
  - Российская Газета (broadcast)
  - Технологии будущего (broadcast)
  - Новости IT (broadcast)

**Tab: Чаты**
- Звук для личных чатов (select)
- Звук для групп (select)
- Только упоминания для групп (switch)
- Список чатов с типами и переключателями:
  - Мария Андреева (DM)
  - Команда разработки (группа)
  - Семья ❤️ (группа)

**Tab: Не беспокоить**
- Включить DND (switch)
- По расписанию (time inputs: 22:00 — 08:00)
- Повторный вызов (switch)
- Звёздочные контакты (switch)
- Авто-DND при бездействии (select: 15м / 30м / 1ч / 2ч)

**Tab: Звуки**
- Звуковая тема (select: Стандартная / Мягкая / Минимализм / Ретро)
- Громкость общая (range: 0-100%)
- Громкость уведомлений (range: 0-100%)
- Предпрослушка (кнопки)

**Tab: Превью**
- Показывать текст сообщения (switch)
- Показывать имя отправителя (switch)
- Лимит символов (select: 20 / 40 / 80 / без ограничений)
- Уровень видимости на экране блокировки
- Пример превью (карточка)

**Tab: Системная интеграция**
- Нативные уведомления ОС (switch)
- Tray-иконка (switch)
- Badge на иконке dock/taskbar (switch)
- Auto-launch при старте ОС (switch)
- Глобальный хоткей открытия (input: Ctrl+Shift+B)
- Глобальные хоткеи (4 карточки):
  - Ctrl+K — поиск
  - Ctrl+N — новый чат
  - Ctrl+Shift+V — звонок
  - Ctrl+Shift+T — переключить тему

**Tab: Отложенные**
- Умные уведомления ИИ (switch)
- Задержка пакетной отправки (select)
- Активные отложенные уведомления (список)

### Statusbar
- Статус подключения + информация о кэше

## Бизнес-логика

### JavaScript
- `showSection(sectionId)` — переключение разделов (sidebar + content)
- `showToast(message, type)` — toast-уведомления
- Range inputs обновляют отображение значения в реальном времени
- Предпрослушка звуков через `showToast`

### Навигация
- Кнопки sidebar → переключение разделов контента
- «← Все настройки» → `settings.html`

### Глобальные хоткеи
- `Ctrl+K` — поиск
- `Ctrl+N` — новый чат
- `Ctrl+Shift+V` — звонок
- `Ctrl+Shift+T` — переключить тему
- `Ctrl+Shift+B` — показать/скрыть окно (глобальный)

## Технологии
- **Electron** (primary) или **Tauri** (lightweight alternative)
- `Notification` API — нативные уведомления ОС
- `Tray` API — системный трей
- `globalShortcut` — глобальные хоткеи
- `BrowserWindow` — управление окном
- React 19 + Next.js для контента

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Sidebar с навигацией по разделам (260px)
- Каждая настройка — строка с label, description и control
- Системная интеграция — карточки с хоткеями
- Превью — визуальная карточка push-уведомления
