## Описание

Десктопная версия экрана «Контакты» — sidebar со списком контактов + content с детальной карточкой контакта.

## Структура

- **Titlebar** — кастомный, с меню и системными кнопками
- **Боковая панель** — поиск контактов, список контактов с бейджами
- **Контент** — заголовок, табы (Контакты / Группы / Чёрный список), карточка контакта
- **Statusbar** — статус подключения, версия

## Компоненты (Electron / Tauri)

| Компонент | Описание |
|---|---|
| `DesktopContactList` | Список контактов в sidebar |
| `DesktopContactDetail` | Детальная карточка контакта |

## API

### HTTP эндпоинты
- `GET /users` — список контактов с пагинацией
- `GET /users/:id` — детали контакта
- `POST /users/me/avatar` — загрузка аватарки
- `PATCH /users/me` — обновление профиля
- `POST /chats` — создать чат с контактом
- `POST /calls` — инициировать звонок контакту
- `GET /groups` — список групп
- `GET /users/blocked` — чёрный список

## Бизнес-логика

### JavaScript-функции
- `openCall(type)` — инициировать звонок (audio/video)
