# Экран: Регистрация (Desktop)

**ID:** `1_09_08`  
**Узел:** `у_09` — desktop (обёртки окна ПК)  
**Web-источник:** `balloo-su/register.html`

## Описание

Десктопная версия страницы регистрации нового аккаунта.

## Структура

### Titlebar
- Иконка Balloo (B)
- Заголовок: «Balloo Messenger — Регистрация»
- Меню + контролы окна

### Window Body
Центрированная auth-card (max-width: 420px):
1. **Заголовок** — «Создать аккаунт»
2. **Подзаголовок** — «Зарегистрируйтесь в Balloo Messenger»
3. **OAuth-кнопки** — Яндекс, Mail.ru, Rambler
4. **Разделитель** — «или email»
5. **Имя** — текстовое поле
6. **Аватарка** — превью автоаватара + кнопка «Загрузить свою»
7. **Email** — текстовое поле
8. **Пароль** — с подсказкой
9. **Чекбокс** — согласие с правилами
10. **Captcha** — картинка + поле ввода
11. **Кнопка «Зарегистрироваться»**
12. **Шаг подтверждения email** (скрыт) — 6-значный код
13. **Ссылка на вход** — «Войти»

### Statusbar
- Статус подключения + информация о кэше

### Шаг подтверждения (скрыт)
- Карточка с border-left: var(--accent)
- Поле для 6-значного кода (monospace)
- Кнопка «Подтвердить»
- Ссылка «Отправить снова» (60 сек)

## Бизнес-логика

### JavaScript
- Переключение на шаг кода:
  ```js
  document.getElementById('reg-code-step').style.display = 'block';
  document.getElementById('reg-submit-btn').style.display = 'none';
  ```
- File input для аватара: `reg-avatar-file` (png/jpeg/svg)
- Автогенерация аватара из имени: `reg-name` → `reg-avatar-preview`

### Навигация
- «Правила» → `balloo-su/rules.html`
- «Войти» → `login.html`
- OAuth — placeholder
