# Экран офлайн (гость / неавторизованный)

> **ID:** `1_00_06`  
> **Узел:** `shared` (общие экраны)  
> **Используется в:** все узлы, кроме `docs-balloo-su`

---

## Описание

Экран отображается, когда неавторизованный пользователь (гость) потерял соединение с интернетом. Не показывает кэшированные данные (нет доступа). Общий экран для всех узлов монорепо (кроме docs.balloo.su).

## Структура

- **topbar** — минимальный: лого, заголовок «Офлайн», маскот, переключатели
- **content** — центрированный блок:
  - Маскот 🦊📡
  - Заголовок «Нет соединения с интернетом»
  - Описание (требуется подключение)
  - Кнопки: «Попробовать снова», «Войти в Balloo» (ссылка на /login)

## Дизайн-требования

- Дизайн-система: `mockups/assets/common.css`
- Без border-radius
- Темы: dark, light, russian
- Визуально проще, чем авторизованный офлайн (нет списка чатов)

## Компоненты (React)

- `<OfflineScreen authed={false} />` — общий компонент офлайна (без кэша)

## API

- Нет API-вызовов (офлайн)
- Service Worker: минимальный кэш (статика)

## Адаптивность / мобильные взаимодействия

- Mobile: кнопки в столбик

## Технологии

- React + TypeScript
- Service Worker (кэширование статики)
- Общий компонент `OfflineScreen` в `packages/shared/src/components/`
