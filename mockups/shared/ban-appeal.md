# Экран обжалования бана — Оверлей

> **ID:** `1_00_08`  
> **Узел:** `shared` (общие экраны)  
> **Используется в:** все узлы, кроме `docs-balloo-su`

---

## Описание

Оверлей, перекрывающий все остальные экраны приложения. Открывается, когда инициализируется отсчёт времени для обжалования бана. Закрывается, когда решение по обжалованию принято (бан снят или отклонён).

Это не отдельная страница, а модальное окно поверх текущего контента. Пользователь не может взаимодействовать с приложением, пока оверлей открыт — он видит только окно обжалования.

## Жизненный цикл

1. **Открытие** — оверлей показывается при инициализации отсчёта обжалования (получен WebSocket event `ban:appeal:started` или пользователь нажал «Обжаловать бан» на экране 555)
2. **Заполнение формы** — пользователь описывает ситуацию (textarea, max 2000 символов)
3. **Отправка** — форма отправляется, показывается статус рассмотрения
4. **Ожидание** — статус обновляется в реальном времени (0/4 → 1/4 → 2/4 → 3/4 → 4/4 подтверждений администраторов)
5. **Закрытие** — оверлей закрывается при получении решения (WebSocket event `ban:appeal:resolved`):
   - **Одобрено** → бан снят, пользователь получает доступ к приложению
   - **Отклонено** → бан остаётся, показывается экран 555 с обновлённой информацией

## Структура

- **Overlay** — `position:fixed; inset:0; z-index:9999`, тёмный фон с blur
- **Appeal window** — центрированное окно (max-width 520px):
  - **Header** — иконка ⚖️, заголовок «Обжалование бана», badge статуса
  - **Body**:
    - Countdown timer — обратный отсчёт до истечения срока обжалования (72 часа)
    - Ban info — причина, дата, тип, ID бана
    - Appeal form — textarea для описания ситуации (max 2000 символов) + счётчик + подсказка
    - Review status — прогресс рассмотрения (заявка подана → ожидание подтверждений → решение)
    - Decision result — результат (одобрено / отклонено), показывается при закрытии
  - **Footer** — кнопки «Закрыть», «Подать обжалование»

## Дизайн-требования

- Дизайн-система: `mockups/assets/common.css`
- Overlay: `rgba(0,0,0,0.85)` + `backdrop-filter:blur(8px)`
- z-index: 9999 (выше всех остальных экранов)
- Цвета countdown: `var(--warning)` (идёт отсчёт), `var(--danger)` (истёк), `var(--accent)` (одобрено)
- Ban info: фон `var(--danger-bg)`, рамка `var(--danger)`
- Без border-radius
- Темы: dark, light, russian

## Компоненты (React)

- `<BanAppealOverlay ban={banData} onClose={handleClose} />` — корневой оверлей-компонент
- `<CountdownTimer deadline={deadline} onExpire={handleExpire} />` — обратный отсчёт
- `<BanInfoCard ban={banData} />` — информация о бане
- `<AppealForm onSubmit={handleSubmit} maxLength={2000} />` — форма обжалования
- `<ReviewStatus confirmations={0} total={4} />` — прогресс рассмотрения
- `<AppealResult decision="approved" | "rejected" />` — результат решения

## API

- `POST /api/v1/bans/appeal` — подача обжалования (body: `{ text: string }`)
- `GET /api/v1/bans/appeal/status` — статус текущего обжалования (confirmations, decision)
- `GET /api/v1/bans/me` — информация о текущем бане
- WebSocket events:
  - `ban:appeal:started` — отсчёт инициализирован → открыть оверлей
  - `ban:appeal:confirmation` — получено подтверждение от администратора (0/4 → 1/4 ...)
  - `ban:appeal:resolved` — решение принято → закрыть оверлей
  - `ban:status` — общий статус бана (снят / подтверждён)

## Адаптивность

- Mobile: окно на всю ширину с отступами 16px, textarea min-height 100px
- Desktop: окно max-width 520px, центрировано
- Оверлей скроллится если контент не помещается

## Технологии

- React + TypeScript
- Портал (`createPortal`) для рендера поверх всего приложения
- WebSocket для real-time обновлений статуса
- Общий компонент в `packages/shared/src/components/`
