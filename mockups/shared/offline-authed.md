# Экран офлайн (авторизованный)

> **ID:** `1_00_05`  
> **Узел:** `shared` (общие экраны)  
> **Используется в:** все узлы, кроме `docs-balloo-su`

---

## Описание

Экран отображается, когда авторизованный пользователь потерял соединение с интернетом. Показывает кэшированные чаты для чтения. Общий экран для всех узлов монорепо (кроме docs.balloo.su).

## Структура

- **topbar** — минимальный: лого, заголовок «Офлайн», маскот, переключатели
- **content** — центрированный блок:
  - Маскот 🦊📡
  - Заголовок «Нет соединения с интернетом»
  - Описание (доступен кэш, сообщения отправятся автоматически)
  - Кнопка «Попробовать снова»
  - Список кэшированных чатов:
    - Октагон-аватар, имя, последнее сообщение, время
    - 3 элемента (демонстрация)

## Дизайн-требования

- Дизайн-система: `mockups/assets/common.css`
- Аватарки: октагон (`clip-path: var(--octagon-clip)`)
- Кэшированные чаты: glassmorphism карточки (`var(--bg-glass)`)
- Без border-radius
- Темы: dark, light, russian

## Компоненты (React)

- `<OfflineScreen authed={true} cachedChats={chats} />` — общий компонент офлайна
- `<CachedChatItem avatar={...} name={...} message={...} time={...} />` — элемент кэшированного чата

## API

- Нет активных API-вызовов (офлайн)
- Service Worker отдаёт кэшированные данные
- WebSocket: отключён, auto-reconnect при восстановлении

## Адаптивность / мобильные взаимодействия

- Mobile: список кэшированных чатов на всю ширину
- Pull-to-refresh для повторной попытки подключения (mobile)

## Технологии

- React + TypeScript
- Service Worker (кэширование чатов)
- IndexedDB (хранение офлайн-сообщений)
- Общий компонент `OfflineScreen` в `packages/shared/src/components/`
