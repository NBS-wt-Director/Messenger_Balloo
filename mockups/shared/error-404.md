# Экран ошибки 404 — Страница не найдена

> **ID:** `1_00_01`  
> **Узел:** `shared` (общие экраны)  
> **Используется в:** все узлы, кроме `docs-balloo-su`

---

## Описание

Страница отображается, когда запрошенный URL не существует или был удалён. Общий экран для всех узлов монорепо (кроме docs.balloo.su), параметризуется логотипом/брендингом узла.

## Структура

- **topbar** — минимальный: лого Balloo, заголовок «Ошибка 404», маскот, переключатели языка/темы
- **content** — центрированный блок:
  - Маскот 🦊🔍 (с элементом поиска)
  - Код ошибки `404` (крупный, акцентный цвет)
  - Заголовок «Страница не найдена»
  - Описание
  - Кнопки: «← Назад» (history.back), «На главную» (ссылка на корень узла)

## Дизайн-требования

- Дизайн-система: `mockups/assets/common.css`
- Тема: dark (по умолчанию), light, russian
- Цвет кода ошибки: `var(--accent)` (зелёный)
- Без border-radius (прямые углы)
- Glassmorphism в topbar
- Маскот: 🦊 (Balloo)
- Адаптивность: центрированный контент, перенос кнопок на mobile

## Компоненты (React)

- `<ErrorScreen code={404} mascot="🦊🔍" title="Страница не найдена" description="..." />` — общий компонент ошибки
- `<TopBar minimal />` — минимальный topbar

## API

- Нет API-вызовов — статическая страница
- WebSocket: нет

## Адаптивность / мобильные взаимодействия

- Mobile: код ошибки уменьшается до 80px, кнопки в столбик
- Tablet/Desktop: как в макете

## Технологии

- React + TypeScript
- Общий компонент `ErrorScreen` в `packages/shared/src/components/`
- SSR-совместимый (для SEO: meta robots noindex)
