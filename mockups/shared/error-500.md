# Экран ошибки 500 — Внутренняя ошибка сервера

> **ID:** `1_00_03`  
> **Узел:** `shared` (общие экраны)  
> **Используется в:** все узлы, кроме `docs-balloo-su`

---

## Описание

Страница отображается при внутренней ошибке сервера. Общий экран для всех узлов монорепо (кроме docs.balloo.su).

## Структура

- **topbar** — минимальный: лого, заголовок «Ошибка 500», маскот, переключатели
- **content** — центрированный блок:
  - Маскот 🦊💥
  - Код ошибки `500` (крупный, цвет `var(--warning)`)
  - Заголовок «Внутренняя ошибка сервера»
  - Описание
  - Кнопки: «Обновить» (location.reload), «На главную»

## Дизайн-требования

- Дизайн-система: `mockups/assets/common.css`
- Цвет кода ошибки: `var(--warning)` (жёлтый/оранжевый) — отличает от 403/404
- Без border-radius
- Темы: dark, light, russian

## Компоненты (React)

- `<ErrorScreen code={500} mascot="🦊💥" title="Внутренняя ошибка сервера" variant="warning" />`

## API

- Нет API-вызовов — статическая страница
- Сервер логирует ошибку (Sentry/ELK) и отдаёт эту страницу

## Адаптивность

- Mobile: код ошибки 80px, кнопки в столбик

## Технологии

- React + TypeScript
- Общий компонент `ErrorScreen` в `packages/shared/src/components/`
- SSR-совместимый (отдаётся сервером при 500)

## Сохранение событий в логи (В-1…В-8)

При показе экрана (ошибка/офлайн/бан) клиент отправляет событие на сервер:

- **Эндпоинт:** `POST /api/client-errors`
- **Тело запроса:** `{ code, url, referrer, userAgent, userId?, timestamp }`
- **Где хранится:** серверный лог (console/file) + запись в `AuditLog` (Prisma) + `ServiceMetric`-счётчик `client_error:<code>`
- **Кто читает:** админ-панель → раздел «Аудит-лог» (фильтр по типу `client_error`), дашборд метрик
