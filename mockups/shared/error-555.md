# Экран ошибки 555 — Аккаунт заблокирован (бан)

> **ID:** `1_00_07`  
> **Узел:** `shared` (общие экраны)  
> **Используется в:** все узлы, кроме `docs-balloo-su`

---

## Описание

Страница отображается, когда аккаунт пользователя заблокирован (забанен). Вместо обычного контента показывается экран ошибки 555 с инструкцией по разбану (карточка ID 55501). Общий экран для всех узлов монорепо (кроме docs.balloo.su).

## Структура

- **topbar** — минимальный: лого, заголовок «Ошибка 555», маскот, переключатели
- **content** — центрированный блок:
  - Маскот 🦊🔒
  - Код ошибки `555` (крупный, цвет `var(--danger)`)
  - Заголовок «Аккаунт заблокирован»
  - Описание
  - **Карточка-инструкция ID 55501** — пошаговая инструкция по разбану:
    - Шаг 1: Ознакомиться с причиной бана
    - Шаг 2: Подать обжалование (72 часа)
    - Шаг 3: Описать ситуацию в форме
    - Шаг 4: Ожидать решения (24 часа)
    - Шаг 5: Решение принято (повтор через 30 дней при отказе)
    - Footer: ссылка на support@balloo.su
  - Кнопки: «Обжаловать бан», «Написать в поддержку»

## Дизайн-требования

- Дизайн-система: `mockups/assets/common.css`
- Цвет кода ошибки: `var(--danger)` (красный)
- Карточка инструкции 55501: glassmorphism, шаги с нумерованными квадратами (accent), разделители
- Без border-radius
- Темы: dark, light, russian

## Компоненты (React)

- `<ErrorScreen code={555} mascot="🦊🔒" title="Аккаунт заблокирован" variant="danger" />` — общий компонент с вариантом `danger`
- `<InstructionCard id="55501" title="Инструкция по разбану" steps={[...]} />` — переиспользуемый компонент карточки с шагами
- `<BanErrorPage />` — сборка ErrorScreen + InstructionCard + action buttons

## API

- `GET /api/v1/bans/me` — информация о текущем бане пользователя (причина, дата, срок действия)
- `POST /api/v1/bans/appeal` — подача обжалования
- `GET /api/v1/bans/appeal/status` — статус текущего обжалования
- WebSocket event: `ban:status` — уведомление о снятии/подтверждении бана

## Адаптивность

- Mobile: код ошибки 80px, кнопки в столбик, карточка на всю ширину
- Desktop: карточка max-width 560px
