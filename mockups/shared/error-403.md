# Экран ошибки 403 — Доступ запрещён

> **ID:** `1_00_02`  
> **Узел:** `shared` (общие экраны)  
> **Используется в:** все узлы, кроме `docs-balloo-su`

---

## Описание

Страница отображается, когда у пользователя недостаточно прав для просмотра запрошенного ресурса. Общий экран для всех узлов монорепо (кроме docs.balloo.su).

## Структура

- **topbar** — минимальный: лого, заголовок «Ошибка 403», маскот, переключатели
- **content** — центрированный блок:
  - Маскот 🦊🚫
  - Код ошибки `403` (крупный, цвет `var(--danger)`)
  - Заголовок «Доступ запрещён»
  - Описание
  - Кнопки: «← Назад», «На главную»

## Дизайн-требования

- Дизайн-система: `mockups/assets/common.css`
- Цвет кода ошибки: `var(--danger)` (красный) — визуально отличает от 404
- Без border-radius
- Темы: dark, light, russian

## Компоненты (React)

- `<ErrorScreen code={403} mascot="🦊🚫" title="Доступ запрещён" variant="danger" />` — общий компонент с вариантом `danger`

## API

- Нет API-вызовов — статическая страница

## Адаптивность

## Сохранение событий в логи (В-1…В-8)

При показе экрана (ошибка/офлайн/бан) клиент отправляет событие на сервер:

- **Эндпоинт:** `POST /api/client-errors`
- **Тело запроса:** `{ code, url, referrer, userAgent, userId?, timestamp }`
- **Где хранится:** серверный лог (console/file) + запись в `AuditLog` (Prisma) + `ServiceMetric`-счётчик `client_error:<code>`
- **Кто читает:** админ-панель → раздел «Аудит-лог» (фильтр по типу `client_error`), дашборд метрик
