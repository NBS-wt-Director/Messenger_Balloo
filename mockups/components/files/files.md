# Компонент: Files — Файлы (админ)

## Описание
Компонент административного управления файлами: статистика (объём, количество, заблокировано) и таблица файлов с метаданными.

## Props / Атрибуты

| Параметр | Тип | Описание | По умолчанию |
|---|---|---|---|
| `stats` | `FileStats` | Статистика файлов | — |
| `files` | `FileInfo[]` | Список файлов | `[]` |

## События

| Событие | Описание |
|---|---|
| `fileDelete` | Файл удалён |
| `fileBlock` | Файл заблокирован |

## Стилизация

Использует дизайн-систему из `common.css`.

## Пример использования

```html
<div class="admin-files__stats">
  <div class="admin-files__stat"><div class="admin-files__stat__value">1.2 GB</div><div class="admin-files__stat__label">Всего файлов</div></div>
</div>
```
