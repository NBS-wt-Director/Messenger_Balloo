# Задание: admin.balloo.su — Статистика блога

## Макет
`admin-balloo-su/blog-stats.html`

## Описание страницы
Статистика блога: просмотры, реакции, комментарии по статьям, каналам, категориям, во времени. Графики, топ статей.

## Структура страницы

### Topbar
- Логотип Admin, заголовок «Статистика блога»

### Sidebar (narrow)
- Навигация админки, Блог: Статистика (active)

### Content (page-container)
1. **Заголовок** + подзаголовок
2. **Период** — 30 дней / 7 дней / 90 дней / Всё время
3. **Сводка** — 4 карточки: просмотры, реакции, комментарии, статей (с динамикой)
4. **График просмотров** — bar chart за период
5. **По каналам** — таблица: канал, тип, просмотры, реакции, комментарии, статей
6. **Топ статей** — топ-5 по просмотрам
7. **По категориям** — просмотры по категориям

## Функционал
- **Смена периода** — 7/30/90 дней / всё время
- **Графики** — обновляются при смене периода
- **Сортировка** — по столбцам таблиц

## Дизайн-требования
- Карточки сводки — крупные цифры, динамика (accent/warning)
- График — CSS bar chart (зелёные столбцы)
- Таблицы — `table` компонент

## Компоненты
- `BlogStatsPage` — страница статистики
- `StatsSummary` — карточки сводки
- `ViewsChart` — график просмотров (bar chart)
- `ChannelStatsTable` — таблица по каналам
- `TopPostsList` — топ статей

## API
- `GET /api/admin/blog/stats` — общая статистика (`?period=`)
- `GET /api/admin/blog/stats/channels` — по каналам
- `GET /api/admin/blog/stats/categories` — по категориям

## Адаптивность
- Desktop: sidebar + content
- Mobile: карточки wrap, график скроллится

## Технологии
- React 19 + Next.js
- Графики: recharts / CSS bars
- Авторизация админа (2FA)
