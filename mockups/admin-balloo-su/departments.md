# Отделы — управление (admin-balloo-su/departments.html)

## Описание
Управление структурой подразделений компании: создание, настройка, назначение руководителей.

## Структура
- **Topbar**: логотип Admin, заголовок «Отделы», кнопка создания
- **Sidebar**: навигация админки (с активным «Отделы»)
- **Content**:
  - Статистика (отделов, сотрудников, вакансий)
  - Список карточек отделов: иконка, название, руководитель, количество сотрудников/вакансий, кнопка настроек
  - Форма создания отдела: название, руководитель, описание

## API
- `GET /api/admin/departments` — список отделов
- `POST /api/admin/departments` — создание отдела
- `PUT /api/admin/departments/:id` — обновление
- `DELETE /api/admin/departments/:id` — удаление

## Технологии
- React 19
