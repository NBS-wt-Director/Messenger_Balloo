# Задание: admin.balloo.su — Вход

## Макет
`admin-balloo-su/login.html`

## Описание страницы
Экран входа в админ-панель. Требует 2FA. Поддерживает вход через другое устройство (QR) с подтверждением 2FA на обоих.

## Структура страницы

### Topbar
- Логотип Admin (иконка A на warning-цвете)
- Заголовок «Вход для администраторов»
- Язык, тема

### Auth-card (warning border)
1. Иконка-октагон A
2. Заголовок «Админ-панель Balloo»
3. Подзаголовок «Вход только для администраторов системы»
4. **Предупреждение 2FA** (danger-bg карточка):
   - ⚠️ Требуется 2FA
   - TOTP / SMS обязательно
5. Форма:
   - Email (admin@balloo.su)
   - Пароль
   - 2FA код (TOTP) — моноширинный, крупный, центрированный
6. Кнопка «Войти в админ-панель» (warning-цвет)
7. **Вход через другое устройство (QR)**
   - Требует подтверждение 2FA на обоих устройствах
8. Предупреждение о логировании действий

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Auth-card с warning border
- 2FA input: моноширинный, letter-spacing 4px, font-size 18px, центрированный
- Кнопка входа — warning-цвет (не accent)
- Предупреждение 2FA — danger-bg

## Компоненты
- `AdminLoginForm` — форма входа с 2FA
- `TOTPInput` — поле ввода 2FA кода
- `WarningBanner` — баннер предупреждения 2FA
- `QRLoginButton` — кнопка входа через QR

## API
- `POST /api/v1/auth/admin/login` — вход с 2FA
- `POST /api/v1/auth/admin/2fa/verify` — проверка TOTP кода
- `POST /api/v1/devices/pair-token` — QR-токен (с требованием 2FA)

## Безопасность
- 2FA обязательно (TOTP или SMS)
- Все действия логируются
- Сессия админа — короткий TTL (1 час)
- IP- whitelist (опционально)
- При 3 неудачных попытках — блокировка на 15 минут
