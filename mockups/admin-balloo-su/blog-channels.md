# Задание: admin.balloo.su — Каналы блога

## Макет
`admin-balloo-su/blog-channels.html`

## Описание страницы
Управление каналами блога. Список корпоративных и личных каналов. Создание корпоративных каналов, выдача личных каналов сотрудникам, назначение/снятие авторов и модераторов, миграция постов при увольнении, архивирование.

## Структура страницы

### Topbar
- Логотип Admin, заголовок «Блог — Каналы», кнопка ✏ (создать канал)

### Sidebar (narrow)
- Навигация админки, Блог: Каналы (active)

### Content (page-container)
1. **Заголовок** + подзаголовок
2. **Фильтры** — Все / Корпоративные / Личные + кнопки: Создать канал, Выдать личный канал
3. **Таблица каналов** — название, тип, владелец/авторы, модераторы, статей, статус, действия (✏, 👥, 🔄)
4. **Подсказка** — компания не может удалять посты автора в личном канале

### Modals
- **Новый корпоративный канал** — название, слаг, описание, иконка
- **Выдать личный канал** — выбор сотрудника, название канала
- **Авторы и модераторы** — список + добавить/удалить
- **Миграция постов** — при увольнении: перенести / передать / архивировать
- **Редактировать канал** — название, описание, видимость

## Функционал
- **Создать корпоративный канал** — модальная форма
- **Выдать личный канал** — выбор сотрудника, он становится автором+модератором
- **Назначить/снять авторов и модераторов** — модальное окно
- **Миграция при увольнении** — перенести посты / передать канал / архивировать
- **Архивирование** — канал скрыт из ленты

## Дизайн-требования
- Тип канала: chip accent (корпоративный), фиолетовый (личный)
- Статус «Требует решения» — danger chip (при увольнении владельца)
- Modals — `modal--status-info`, `modal--status-warning`

## Компоненты
- `BlogChannelsPage` — страница управления каналами
- `ChannelTable` — таблица каналов
- `NewChannelModal` — создание корпоративного канала
- `PersonalChannelModal` — выдача личного канала
- `AuthorsModal` — управление авторами/модераторами
- `MigrateModal` — миграция постов

## API
- `GET /api/admin/blog/channels` — список всех каналов
- `POST /api/admin/blog/channels` — создать корпоративный канал
- `POST /api/admin/blog/channels/personal` — выдать личный канал
- `PUT /api/admin/blog/channels/:id` — обновить канал
- `POST /api/admin/blog/channels/:id/authors` — назначить автора
- `DELETE /api/admin/blog/channels/:id/authors/:userId` — снять автора
- `POST /api/admin/blog/channels/:id/moderators` — назначить модератора
- `DELETE /api/admin/blog/channels/:id/moderators/:userId` — снять модератора
- `POST /api/admin/blog/channels/:id/migrate` — миграция постов
- `POST /api/admin/blog/channels/:id/transfer` — передать канал

## Адаптивность
- Desktop: sidebar + content
- Mobile: таблица скроллится, modals на весь экран

## Технологии
- React 19 + Next.js
- Авторизация админа (2FA)
