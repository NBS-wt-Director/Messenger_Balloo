# Задание: admin.balloo.su — Ревью статьи

## Макет
`admin-balloo-su/blog-review.html`

## Описание страницы
Ревью статьи: метаданные, превью содержания, теги, решение (одобрить / запросить правки / отклонить) с комментарием автору.

## Структура страницы

### Topbar
- Логотип Admin, заголовок «Ревью статьи»

### Sidebar (narrow)
- Навигация админки, Блог: Очередь (active)

### Content (page-container)
1. **Навигация** — ← Очередь + предпросмотр
2. **Заголовок** + chip «На ревью»
3. **Метаданные** — автор (аватар+имя+должность), дата подачи, канал, категория
4. **Заголовок статьи + анонс**
5. **Превью содержания** — Markdown-рендер (обрезан)
6. **Теги**
7. **Решение** — комментарий автору (textarea) + кнопки: Одобрить / Запросить правки / Отклонить

## Функционал
- **Одобрить** → статус `published`, проставляется `publishedAt`
- **Запросить правки** → статус `changes_requested`, комментарий автору
- **Отклонить** → статус `rejected`, комментарий автору
- **Предпросмотр** — как будет выглядеть после публикации

## Дизайн-требования
- Карточка решения — border-left accent
- Кнопки: primary (одобрить), secondary (правки), danger (отклонить)

## Компоненты
- `BlogReviewPage` — страница ревью
- `ArticlePreview` — превью содержания
- `ReviewDecisionForm` — форма решения

## API
- `GET /api/admin/blog/posts/:id` — полные данные статьи
- `POST /api/admin/blog/posts/:id/approve` — одобрить
- `POST /api/admin/blog/posts/:id/reject` — отклонить
- `POST /api/admin/blog/posts/:id/request-changes` — запросить правки

## Адаптивность
- Desktop: sidebar + content
- Mobile: форма на весь экран

## Технологии
- React 19 + Next.js
- Авторизация админа (2FA)
