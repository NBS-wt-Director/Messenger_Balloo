# Донаты — управление (admin-balloo-su/donations.html)

## Описание
Управление пожертвованиями: цели сборов, список доноров, статистика по платформам.

## Структура
- **Topbar**: логотип Admin, заголовок «Донаты»
- **Sidebar**: навигация админки (с активным «Донаты»)
- **Content**:
  - Статистика (собрано за месяц, доноров, подписчиков, средний чек)
  - Карточка цели сбора с прогрессом и кнопкой редактирования
  - Таблица последних пожертвований: донор, сумма, тип (разово/подписка), способ, дата, статус
  - Таблица топ доноров: место, донор, уровень, всего, платформы
  - Статистика по платформам: web/download/features/history

## API
- `GET /api/admin/donations` — список пожертвований
- `GET /api/admin/donations/stats` — статистика
- `GET /api/admin/donations/top-donors` — топ доноров
- `GET /api/admin/donations/goal` — текущая цель
- `PUT /api/admin/donations/goal` — обновление цели

## Технологии
- React 19
- Единое API (данные со всех узлов с donate-страницами)
