# Вакансии — управление (admin-balloo-su/vacancies.html)

## Описание
Управление вакансиями и заявками кандидатов. Данные отображаются на command.balloo.su/vacancies.html.

## Структура
- **Topbar**: логотип Admin, заголовок «Управление вакансиями», кнопка создания
- **Sidebar**: навигация админки (с активным «Вакансии»)
- **Content**:
  - Статистика (активных, заявок, на собеседовании, принято)
  - Таблица вакансий: должность, отдел, зарплата, кандидатов, статус, действия
  - Таблица последних заявок: кандидат, вакансия, дата, этап, действия

## API
- `GET /api/admin/vacancies` — список вакансий
- `POST /api/admin/vacancies` — создание вакансии
- `PUT /api/admin/vacancies/:id` — обновление
- `GET /api/admin/applications` — список заявок
- `PUT /api/admin/applications/:id/stage` — изменение этапа

## Технологии
- React 19
- Единое API (те же данные, что в command.balloo.su)
