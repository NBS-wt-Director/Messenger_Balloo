# Боты — управление (admin-balloo-su/bots-mgmt.html)

## Описание
Управление ботами платформы. Админ НЕ может удалить бота. Доступные действия: приостановить (по жалобе), возобновить, написать создателю, забанить создателя, верифицировать. Удаление бота — только создатель через user-API.

## Структура
- **Topbar**: логотип Admin, заголовок «Боты»
- **Sidebar**: навигация админ-панели (Боты активно)
- **Content**: предупреждение о правиле удаления, поиск, таблица ботов

## Правила
- ❌ Админ НЕ может удалить бота
- ✅ Приостановить (по жалобе) / возобновить
- ✅ Написать создателю (открывает чат)
- ✅ Забанить создателя (ведёт к блокировке бота)
- ✅ Верифицировать бота
- ✅ Удаление — только создатель через пользовательский API

## Дизайн-требования
- Дизайн-система: common.css
- Предупреждение о правиле удаления — warning-карточка
- Темы: dark, light, russian

## Компоненты (React)
- `BotsManagementTable` — таблица ботов с действиями (приостановить/написать/забанить/верифицировать)

## API
- `GET /admin/bots` — список ботов
- `PUT /admin/bots/:id/suspend` — приостановить (по жалобе)
- `PUT /admin/bots/:id/resume` — возобновить
- `POST /admin/bots/:id/message-owner` — написать создателю
- `PUT /admin/bots/:id/verify` — верификация
- `DELETE /admin/bots/:id` — НЕ добавлять (удаление только создателем через user-API)

## Технологии
- React 19 / Next.js 15
- Действия админа логируются в `audit_logs`
