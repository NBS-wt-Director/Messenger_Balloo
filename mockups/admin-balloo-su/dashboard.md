# Задание: admin.balloo.su — Дашборд

## Макет
`admin-balloo-su/dashboard.html`

## Описание страницы
Главный экран админ-панели. Статистика (пользователи, активные, сообщения, жалобы), активные алерты, таблица последних жалоб. Sidebar с навигацией по разделам админки.

## Структура страницы

### Topbar
- Логотип Admin (A на warning-цвете) с dropdown навигацией
- Заголовок «Дашборд»
- Аватар админа, язык, тема

### Sidebar (narrow)
- 📊 Дашборд (active)
- 👤 Пользователи
- 🚩 Жалобы (badge: 12)
- 🔨 Баны
- 📈 Метрики
- 🎛️ Feature Flags
- 📁 Файлы

### Content
1. Заголовок «Дашборд»
2. **Карточки статистики** (4):
   - Пользователей: 12 345 (+234 за неделю, accent)
   - Активных сейчас: 1 023 (8.3%, info)
   - Сообщений сегодня: 45 678 (+12%, warning)
   - Жалобы: 12 (Ожидают рассмотрения, danger)
3. **Карточка «Активные алерты»**:
   - Высокая нагрузка на WebSocket (danger, «Критично»)
   - Бэкап БД завершён (accent, «OK»)
   - MinIO: 78% заполнено (warning, «Внимание»)
4. **Карточка «Последние жалобы»**:
   - Таблица: пользователь, причина, статус (Ожидает / В работе), кнопка «Рассмотреть» / «Открыть»

## Функционал
- **Статистика** — realtime-обновление метрик
- **Алерты** — мониторинг системы (WebSocket, БД, MinIO)
- **Жалобы** — быстрые действия (рассмотреть, открыть)
- **Навигация** — sidebar по разделам админки

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Логотип Admin — warning-цвет
- Карточки статистики — крупные цифры (32px, 800 weight)
- Алерты — status-dot + chip (danger/warning/accent)
- Таблица — table с chip-статусами

## Компоненты
- `AdminSidebar` — sidebar навигации
- `StatsGrid` — сетка карточек статистики
- `StatsCard` — карточка статистики (значение, label, дельта)
- `AlertsList` — список активных алертов
- `RecentReportsTable` — таблица последних жалоб

## API
- `GET /api/v1/admin/stats` — статистика (пользователи, сообщения, жалобы)
- `GET /api/v1/admin/alerts` — активные алерты
- `GET /api/v1/admin/reports?status=pending` — последние жалобы

## WebSocket
- `admin:stats` — realtime обновление статистики
- `admin:alert` — новый алерт
- `admin:report` — новая жалоба

## Безопасность
- 2FA обязательно для входа
- Все действия логируются
- Короткий TTL сессии (1 час)

## Адаптивность
- Desktop: sidebar + content
- Mobile: sidebar → drawer

## Технологии
- React 19 + Next.js
- Zustand: `adminStore` (stats, alerts, reports)
- WebSocket: realtime метрики
- Prometheus: сбор метрик
