# Группы — модерация (admin-balloo-su/groups-mgmt.html)

## Описание
Модерация групп платформы. Админ может: передать владение, закрыть, скрыть контент, верифицировать, обрабатывать заявки на СМИ-группу. Удалить группу может только создатель/админ группы при 1 участнике; при 0 участниках — авто-удаление.

## Структура
- **Topbar**: логотип Admin, заголовок «Группы»
- **Sidebar**: навигация админ-панели (Группы активно)
- **Content**:
  - Предупреждение о правилах удаления
  - Tabs: «Все группы» / «Заявки СМИ»
  - Таблица групп (тип, владелец, участники, статус, действия)
  - Таблица заявок на СМИ-группу (документы, статус, одобрить/отклонить)

## Правила удаления
- Удаление — только создатель/админ группы, если остался 1 участник
- При 0 участниках — удаляется автоматически
- Админ-панель НЕ удаляет группы напрямую

## Дизайн-требования
- Дизайн-система: common.css
- Типы групп: chip (СМИ — info, КОРП — warning, PRIVATE — default)
- Темы: dark, light, russian

## Компоненты (React)
- `GroupsModerationTable` — таблица групп + заявки СМИ

## API
- `GET /admin/groups` — список групп
- `PUT /admin/groups/:id` — настройки (закрытие, скрытие контента)
- `POST /admin/groups/:id/transfer` — передача владения
- `GET /admin/groups/media-requests` — заявки на СМИ-группу
- `POST /admin/groups/media-requests/:id/approve` — одобрить СМИ
- `POST /admin/groups/media-requests/:id/reject` — отклонить СМИ
- `PUT /admin/groups/:id/verify` — верификация группы

## Сущности данных
- `group_media_requests` — заявки на СМИ (groupId, requesterId, documents Json, status, reviewedByAdminId)

## Технологии
- React 19 / Next.js 15
- Действия админа логируются в `audit_logs`
