# Задание: admin.balloo.su — Жалобы

## Макет
`admin-balloo-su/reports.html`

## Описание страницы
Обработка жалоб пользователей. Табы по статусам (Ожидают / В работе / Решённые). Карточки жалоб с метаданными (без текста сообщения). Действия: запросить бан, отклонить, подробнее.

## Структура страницы

### Topbar
- Логотип Admin (A на warning-цвете)
- Заголовок «Жалобы»
- Аватар админа, язык, тема

### Sidebar (narrow)
- 📊 Дашборд
- 👤 Пользователи
- 🚩 Жалобы (active, badge: 12)
- 🔨 Баны
- 📈 Метрики
- 🎛️ Feature Flags
- 📁 Файлы

### Content
1. Заголовок «Жалобы»
2. **Табы**: Ожидают (12) / В работе (3) / Решённые (45)
3. **Tab «Ожидают»** — карточки жалоб:
   - Аватар-октагон (xs) + username
   - Chip причины (Спам=danger, Ненормативная лексика=warning)
   - Кол-во жалоб от N разных пользователей
   - ID сообщения, дата
   - Предупреждение: «Содержимое жалобы доступно только как метаданные (без текста сообщения)»
   - Кнопки: «Запросить бан» (danger) / «Отклонить» (secondary) / «Подробнее» (tertiary)
4. **Empty states** — для табов без жалоб

## Функционал
- **Табы по статусам** — фильтрация жалоб
- **Запросить бан** — отправка запроса на бан (→ подтверждение 4 админов)
- **Отклонить** — закрытие жалобы
- **Подробнее** — расширенная информация
- **Приватность** — только метаданные, без текста сообщений

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Аватары-октагоны (xs)
- Chip причины: danger (спам), warning (ненормативная лексика)
- Предупреждение о метаданных — bg-tertiary карточка
- Empty state с эмодзи

## Компоненты
- `AdminSidebar` — sidebar навигации
- `ReportsTabs` — табы по статусам
- `ReportCard` — карточка жалобы (username, причина, кол-во, метаданные, кнопки)
- `ReportActions` — кнопки (Запросить бан / Отклонить / Подробнее)
- `EmptyState` — пустое состояние

## API
- `GET /api/v1/admin/reports?status=pending|in_progress|resolved` — жалобы по статусу
- `POST /api/v1/admin/reports/:id/ban-request` — запрос бана
- `POST /api/v1/admin/reports/:id/dismiss` — отклонить
- `GET /api/v1/admin/reports/:id` — детали жалобы

## Безопасность
- Содержимое жалоб — только метаданные (без текста сообщений)
- Админы не читают чаты
- Бан: 5 жалоб + 4 подтверждения
- Все действия логируются

## Адаптивность
- Desktop: sidebar + content
- Mobile: sidebar → drawer

## Технологии
- React 19 + Next.js
- Zustand: `adminStore` (reports[], activeTab)
- Приватность: жалобы хранят только метаданные
