# Сотрудники (admin-balloo-su/employees.html)

## Описание
Управление сотрудниками: назначение по отделам, выдача разных прав по отделам. Доступно только администраторам с соответствующими правами.

## Структура
- **Topbar**: логотип Admin, заголовок «Сотрудники и отделы», кнопка добавления
- **Sidebar**: навигация админки (с активным «Сотрудники»)
- **Content**:
  - Tabs: Все сотрудники / По отделам / Права доступа
  - Таблица сотрудников: имя, email, отдел, должность, права, статус, действия
  - Матрица прав по отделам (право × отдел)
  - Форма назначения сотрудника в отдел: пользователь, отдел, должность, уровень прав

## Компоненты (React)
- `EmployeeTable` — таблица сотрудников
- `PermissionsMatrix` — матрица прав по отделам
- `AssignEmployeeForm` — форма назначения

## API
- `GET /api/admin/employees` — список сотрудников
- `POST /api/admin/employees/assign` — назначение в отдел
- `PUT /api/admin/employees/:id/permissions` — изменение прав
- `GET /api/admin/departments` — список отделов (для матрицы)

## Технологии
- React 19
- Проверка прав администратора
