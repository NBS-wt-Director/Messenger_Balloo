# Задание: admin.balloo.su — Тексты

## Макет
`admin-balloo-su/texts.html`

## Описание страницы
Управление текстовым контентом приложения: шаги онбординга (заголовок, текст, иллюстрация, порядок), информационные страницы (Правила, О компании, О Balloo). Шаги онбординга хранятся в БД и выводятся в приложении динамически — количество шагов не ограничено. Поддержка локализации (6 языков).

## Структура страницы

### Topbar
- Логотип Admin (A на warning-цвете)
- Заголовок «Тексты»
- Кнопка ✏ → модалка нового шага
- Аватар админа, язык, тема

### Sidebar (narrow)
- 📊 Дашборд
- 👤 Пользователи
- 🚩 Жалобы
- 🔨 Баны
- 📈 Метрики
- 🎛️ Feature Flags
- 📁 Файлы
- 📝 Тексты (active)
- — разделитель —
- 🏢 Отделы
- 👤 Сотрудники
- 💼 Вакансии
- 📜 Версии
- 💡 Фичи (модерация)
- 💚 Донаты

### Content
1. Заголовок «Тексты» + подзаголовок «Контент приложения • Онбординг • Информационные страницы»
2. **Вкладки**: Онбординг (active) / Правила / О компании / О Balloo
3. **Карточка «Шаги онбординга»**:
   - Счётчик шагов (chip info)
   - Таблица: №, иллюстрация (превью), заголовок, текст, язык, действия (✏/⬆/🗑)
   - Кнопки: «➕ Добавить шаг» / «👁 Предпросмотр»
4. **Карточка «Локализация шагов»**:
   - Таблица покрытия переводов по 6 языкам (✓ / —)

### Modal: Новый шаг онбординга
- Иллюстрация (drag-and-drop, PNG/SVG до 2 МБ)
- Заголовок (RU) — input
- Текст (RU) — textarea
- Порядок — number input
- Активен — switch
- Кнопки: Отмена / Создать

### Modal: Редактирование шага
- Иллюстрация (превью + Заменить / Удалить)
- Заголовок (RU), Текст (RU), Порядок, Активен
- Переводы — кнопки языков (EN, ZH, FR, BE, HI) → открывают форму перевода
- Кнопки: Отмена / Сохранить

### Modal: Предпросмотр
- Имитация экрана онбординга: иллюстрация, заголовок, текст, точки прогресса, кнопки

## Функционал
- **CRUD шагов** — создать / редактировать / удалить шаг онбординга
- **Порядок шагов** — drag-and-drop или кнопки ↑/↓, сохраняется в БД
- **Иллюстрация** — загрузка PNG/SVG (до 2 МБ), хранение в MinIO
- **Локализация** — перевод заголовка и текста для 6 языков (RU по умолчанию)
- **Активность** — вкл/выкл шага (неактивные не показываются в приложении)
- **Предпросмотр** — модалка с имитацией онбординга
- **Информационные страницы** — вкладки для редактирования текстов «Правила», «О компании», «О Balloo» (контент хранится в БД)

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Drag-and-drop зона — пунктирная рамка (--border-strong)
- Превью иллюстрации — 48×48 / 64×64, bg-tertiary
- Покрытие переводов — chip accent (✓) / chip warning (—)
- Модалки — modal--status-info

## Компоненты
- `AdminSidebar` — sidebar навигации
- `TextsTabs` — вкладки разделов (Онбординг / Правила / О компании / О Balloo)
- `OnboardingStepsTable` — таблица шагов
- `OnboardingStepRow` — строка (№, иллюстрация, заголовок, текст, язык, действия)
- `StepEditModal` — модалка создания/редактирования шага
- `IllustrationUpload` — drag-and-drop загрузка PNG/SVG
- `TranslationsMatrix` — таблица покрытия переводов
- `OnboardingPreview` — модалка предпросмотра

## API
- `GET /api/v1/admin/texts/onboarding` — список шагов онбординга
- `POST /api/v1/admin/texts/onboarding` — создание шага
- `PATCH /api/v1/admin/texts/onboarding/:id` — обновление шага (заголовок, текст, порядок, активен)
- `DELETE /api/v1/admin/texts/onboarding/:id` — удаление шага
- `PATCH /api/v1/admin/texts/onboarding/reorder` — изменение порядка (массив ID)
- `POST /api/v1/admin/texts/onboarding/:id/illustration` — загрузка иллюстрации (multipart)
- `DELETE /api/v1/admin/texts/onboarding/:id/illustration` — удаление иллюстрации
- `GET /api/v1/admin/texts/onboarding/:id/translations` — переводы шага
- `PUT /api/v1/admin/texts/onboarding/:id/translations` — обновление переводов
- `GET /api/v1/onboarding/steps` — публичный endpoint (для приложения): активные шаги на языке пользователя
- `GET /api/v1/admin/texts/pages/:slug` — контент информационной страницы (rules, about-company, about-balloo)
- `PUT /api/v1/admin/texts/pages/:slug` — обновление контента страницы

## База данных
- `OnboardingStep` — шаг онбординга (порядок, иллюстрация, активен)
- `OnboardingStepTranslation` — перевод шага (заголовок, текст, язык)
- `TextPage` — информационная страница (slug, контент по языкам)

## Безопасность
- 2FA для админа
- Изменения логируются (audit log)
- Загрузка файлов — валидация типа (PNG/SVG) и размера (до 2 МБ)
- Хранение иллюстраций — MinIO

## Адаптивность
- Desktop: sidebar + content, таблица
- Mobile: sidebar → drawer, карточки вместо таблицы

## Технологии
- React 19 + Next.js
- Zustand: `adminTextsStore` (steps[], pages[], translations)
- Drag-and-drop: @dnd-kit/core
- Загрузка файлов: multipart/form-data → MinIO
- Кэширование: Redis (onboarding steps — публичный endpoint кэшируется)
