# Задание: admin.balloo.su — Файлы (статистика)

## Макет
`admin-balloo-su/files.html`

## Описание страницы
Статистика файлов: MinIO и Yandex Disk. Только метаданные — содержимое не читается админами. Buckets MinIO, статистика по типам файлов.

## Структура страницы

### Topbar
- Логотип Admin (A на warning-цвете)
- Заголовок «Файлы»
- Аватар админа, язык, тема

### Sidebar (narrow)
- 📊 Дашборд
- 👤 Пользователи
- 🚩 Жалобы
- 🔨 Баны
- 📈 Метрики
- 🎛️ Feature Flags
- 📁 Файлы (active)

### Content
1. Заголовок «Файлы (статистика)»
2. **Предупреждение** (warning border): «Только статистика. Содержимое файлов не читается администраторами. Чаты не читаются — только статистика.»
3. **Карточки статистики** (3):
   - MinIO — всего: 1.2 TB (из 2 TB, 60%, accent)
   - Yandex Disk (пользователи): 4.5 TB (234 подключённых, info)
   - Файлов всего: 89 432 (+1 234 за неделю, warning)
4. **Карточка «Buckets (MinIO)»**:
   - Таблица: bucket (code), назначение, размер, файлов, заполненность (chip)
   - avatars (12%), group-media (25%), public-media (78% warning), backups (55% warning)
5. **Карточка «Статистика по типам файлов»**:
   - 🖼 Изображения: 34 567 (38.6%)
   - 🎬 Видео: 12 345 (13.8%)
   - 🎤 Аудио / Голосовые: 23 456 (26.2%)
   - 📄 Документы: 8 901 (9.9%)
   - 📦 Прочее: 10 163 (11.5%)

## Функционал
- **Статистика** — объём, кол-во файлов, типы
- **Buckets** — заполненность MinIO buckets
- **Типы файлов** — распределение по категориям
- **Приватность** — только метаданные, без содержимого

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Предупреждение — warning border
- Карточки статистики — крупные цифры (28px, 800 weight)
- Buckets: code (monospace), chip заполненности (accent/warning)
- Типы файлов — list с иконками и процентами

## Компоненты
- `AdminSidebar` — sidebar навигации
- `PrivacyWarning` — предупреждение о только-статистике (warning border)
- `FileStatsGrid` — сетка статистики (MinIO, Yandex Disk, всего)
- `BucketsTable` — таблица MinIO buckets
- `FileTypeStats` — статистика по типам файлов

## API
- `GET /api/v1/admin/files/stats` — общая статистика файлов
- `GET /api/v1/admin/files/buckets` — статистика MinIO buckets
- `GET /api/v1/admin/files/types` — статистика по типам

## Безопасность
- Только метаданные — содержимое файлов не читается
- Чаты не читаются админами
- 2FA для админа
- Все действия логируются

## Адаптивность
- Desktop: sidebar + content, таблицы
- Mobile: sidebar → drawer, карточки

## Технологии
- React 19 + Next.js
- Zustand: `adminStore` (fileStats, buckets, types)
- MinIO API — статистика buckets
- Yandex Disk API — статистика подключённых дисков
