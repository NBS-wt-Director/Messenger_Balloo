# Задание: admin.balloo.su — Категории и теги

## Макет
`admin-balloo-su/blog-categories.html`

## Описание страницы
Управление категориями блога (CRUD, порядок, видимость, локализация) и тегами (CRUD). Tabs: Категории / Теги.

## Структура страницы

### Topbar
- Логотип Admin, заголовок «Категории и теги», кнопка ✏

### Sidebar (narrow)
- Навигация админки, Блог: Категории (active)

### Content (page-container)
1. **Заголовок** + подзаголовок
2. **Tabs** — Категории / Теги

### Tab: Категории
3. **Таблица категорий** — №, иконка, название, URL-слаг, статей, видимость, действия (✏, ⬆, 🗑)
4. **Добавить категорию** — кнопка
5. **Локализация** — таблица переводов по 6 языкам

### Tab: Теги
6. **Список тегов** — chips с количеством статей и кнопкой удаления
7. **Добавить тег** — input + кнопка

### Modals
- **Новая категория** — иконка, название, слаг, описание, видимость
- **Редактировать категорию** — те же поля

## Функционал
- **CRUD категорий** — создание, редактирование, удаление
- **Порядок категорий** — drag-to-reorder (⬆)
- **Видимость** — switch (видна/скрыта)
- **Локализация** — переводы для 6 языков
- **CRUD тегов** — создание, удаление

## Дизайн-требования
- Tabs — `tabs` + `tab-panel`
- Теги — chips с количеством
- Таблица локализации — ✓ / — для каждого языка

## Компоненты
- `BlogCategoriesPage` — страница категорий и тегов
- `CategoryTable` — таблица категорий
- `TagManager` — управление тегами
- `CategoryModal` — модальная форма категории
- `LocalizationTable` — таблица локализаций

## API
- `POST /api/admin/blog/categories` — создать категорию
- `PUT /api/admin/blog/categories/:id` — обновить категорию
- `DELETE /api/admin/blog/categories/:id` — удалить категорию
- `POST /api/admin/blog/tags` — создать тег
- `DELETE /api/admin/blog/tags/:id` — удалить тег

## Адаптивность
- Desktop: sidebar + content
- Mobile: tabs скроллятся

## Технологии
- React 19 + Next.js
- Авторизация админа (2FA)
