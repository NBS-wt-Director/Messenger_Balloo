# Фичи — модерация (admin-balloo-su/features-mgmt.html)

## Описание
Модерация фич-реквестов: одобрение, отклонение, управление статусами. Данные отображаются на features.balloo.su.

## Структура
- **Topbar**: логотип Admin, заголовок «Фичи — модерация»
- **Sidebar**: навигация админки (с активным «Фичи (модерация)»)
- **Content**:
  - Статистика (всего, на модерации, голосов)
  - Tabs: На модерации / Все / Отклонённые
  - Карточки фич на модерации: голоса, статус, категория, название, описание, автор, кнопки одобрить/отклонить
  - Таблица статусов фич (готово/в работе/запланировано/идея/отклонено)

## API
- `GET /api/admin/features?status=pending` — фичи на модерации
- `PUT /api/admin/features/:id/approve` — одобрить
- `PUT /api/admin/features/:id/reject` — отклонить
- `PUT /api/admin/features/:id/status` — изменить статус

## Технологии
- React 19
- Единое API (те же данные, что в features.balloo.su)
