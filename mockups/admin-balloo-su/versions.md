# Версии — управление (admin-balloo-su/versions.html)

## Описание
Управление записями истории версий. Данные отображаются на history.balloo.su.

## Структура
- **Topbar**: логотип Admin, заголовок «Управление версиями», кнопка создания
- **Sidebar**: навигация админки (с активным «Версии»)
- **Content**:
  - Статистика (релизов, в планах)
  - Таблица версий: версия, тип, дата, статус (релиз/в планах), описание, действия (редактировать/удалить)
  - Форма создания версии: номер, тип, дата, статус, описание, changelog (Markdown)

## API
- `GET /api/admin/versions` — список версий
- `POST /api/admin/versions` — создание версии
- `PUT /api/admin/versions/:id` — обновление
- `DELETE /api/admin/versions/:id` — удаление

## Технологии
- React 19
- Markdown-редактор для changelog
- Единое API (те же данные, что в history.balloo.su)
