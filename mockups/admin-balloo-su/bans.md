# Задание: admin.balloo.su — Баны и обжалования

## Макет
`admin-balloo-su/bans.html`

## Описание страницы
Управление банами и обжалованиями. Табы: активные баны, обжалования, запросы на бан. Подтверждение банов (4 админа), обжалование (3 часа).

## Структура страницы

### Topbar
- Логотип Admin (A на warning-цвете)
- Заголовок «Баны и обжалования»
- Аватар админа, язык, тема

### Sidebar (narrow)
- 📊 Дашборд
- 👤 Пользователи
- 🚩 Жалобы (badge: 12)
- 🔨 Баны (active)
- 📈 Метрики
- 🎛️ Feature Flags
- 📁 Файлы

### Content
1. Заголовок «Баны и обжалования»
2. **Табы**: Активные баны (3) / Обжалования (1) / Запросы на бан (2)
3. **Tab «Активные баны»** — карточки:
   - Username, chip «Забанен» (danger)
   - Причина + кол-во жалоб
   - Дата бана, подтверждили: 4/4 админов
   - Обжалование доступно: «ещё 2 часа 15 минут» / «Обжалование истекло»
4. **Tab «Обжалования»** — карточки (warning border):
   - Username, chip «Обжалование» (warning)
   - Текст обжалования
   - Осталось времени
   - Кнопки: «Снять бан» (secondary) / «Отклонить обжалование» (danger)
5. **Tab «Запросы на бан»** — карточки:
   - Username, chip «Ожидает подтверждения» (warning)
   - Причина + кол-во жалоб
   - Подтвердили: 2/4 админов
   - Кнопка «Подтвердить бан» (danger)

## Функционал
- **Активные баны** — просмотр, таймер обжалования
- **Обжалования** — снять бан / отклонить обжалование
- **Запросы на бан** — подтверждение (нужно 4 админа)
- **Таймеры** — 3 часа на обжалование

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Chip «Забанен» — danger, «Обжалование» — warning, «Ожидает подтверждения» — warning
- Карточка обжалования — warning border
- Таймер — text-muted

## Компоненты
- `AdminSidebar` — sidebar навигации
- `BansTabs` — табы (Активные / Обжалования / Запросы)
- `BanCard` — карточка активного бана (username, причина, таймер)
- `AppealCard` — карточка обжалования (warning border, текст, кнопки)
- `BanRequestCard` — карточка запроса (подтверждение, прогресс 2/4)
- `BanTimer` — таймер обжалования

## API
- `GET /api/v1/admin/bans?status=active` — активные баны
- `GET /api/v1/admin/bans/appeals` — обжалования
- `GET /api/v1/admin/bans/requests` — запросы на бан
- `POST /api/v1/admin/bans/:id/confirm` — подтверждение бана (4 админа)
- `POST /api/v1/admin/bans/:id/unban` — снятие бана
- `POST /api/v1/admin/bans/:id/appeal/reject` — отклонить обжалование

## WebSocket
- `ban:appeal_submitted` — подано обжалование
- `ban:confirmed` — бан подтверждён (4/4)
- `ban:expired` — обжалование истекло

## Безопасность
- Бан: 5 жалоб + подтверждение 4 админов
- Обжалование: 3 часа
- Все действия логируются
- 2FA для админа

## Адаптивность
- Desktop: sidebar + content
- Mobile: sidebar → drawer

## Технологии
- React 19 + Next.js
- Zustand: `adminStore` (bans[], appeals[], requests[])
- Таймеры: cron job (проверка истечения обжалования)
- Multi-admin confirmation: блокировка до 4 подтверждений
