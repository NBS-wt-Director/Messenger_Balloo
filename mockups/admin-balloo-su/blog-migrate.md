# Задание: admin.balloo.su — Миграция постов

## Макет
`admin-balloo-su/blog-migrate.html`

## Описание страницы
Экран миграции постов при увольнении владельца личного канала. Выбор действия: перенести в другой канал, передать канал другому сотруднику, архивировать. Превью постов.

## Структура страницы

### Topbar
- Логотип Admin, заголовок «Миграция постов»

### Sidebar (narrow)
- Навигация админки, Блог: Каналы (active)

### Content (page-container)
1. **← Каналы** — возврат
2. **Заголовок** «Миграция постов»
3. **Карточка канала** — аватар, название, владелец + chip «уволен», количество статей
4. **Описание** — сотрудник уволен, выберите действие
5. **Варианты действий** (radio cards):
   - 📦 Перенести посты в другой канал (select целевого канала)
   - 👤 Передать канал другому сотруднику (select нового владельца)
   - 🗄️ Архивировать канал целиком
6. **Превью постов** — таблица всех статей канала
7. **Кнопки** — Применить / Отмена

## Функционал
- **Перенос постов** — все посты перемещаются в выбранный канал, авторство сохраняется
- **Передача канала** — новый владелец становится автором+модератором
- **Архивирование** — канал и посты скрыты из ленты
- **Превью постов** — список всех статей с метриками

## Дизайн-требования
- Карточка канала — border-left danger
- Варианты — radio cards, выбранный с border accent
- Chip «уволен» — danger

## Компоненты
- `BlogMigratePage` — страница миграции
- `MigrationOptionCard` — карточка варианта миграции
- `PostsPreviewTable` — таблица превью постов

## API
- `GET /api/admin/blog/channels/:id` — данные канала + посты
- `POST /api/admin/blog/channels/:id/migrate` — миграция (`targetChannelId` или `action: archive`)
- `POST /api/admin/blog/channels/:id/transfer` — передача (`newOwnerId`)

## Адаптивность
- Desktop: sidebar + content
- Mobile: radio cards вертикально

## Технологии
- React 19 + Next.js
- Авторизация админа (2FA)
