# Задание: admin.balloo.su — Очередь блога

## Макет
`admin-balloo-su/blog-queue.html`

## Описание страницы
Очередь статей на ревью. Фильтр по статусам, таблица статей с переходом к ревью, список недавно рассмотренных.

## Структура страницы

### Topbar
- Логотип Admin, заголовок «Блог — Очередь»

### Sidebar (narrow)
- Навигация админки + новая секция «Блог»: Очередь (active), Каналы, Категории, Статистика

### Content (page-container)
1. **Заголовок** + подзаголовок
2. **Фильтр по статусам** — На ревью / Опубликованы / Отклонены / Нужны правки / Все
3. **Таблица очереди** — заголовок, автор (аватар+имя), канал, категория, дата подачи, кнопка «Ревью →»
4. **Недавно рассмотренные** — таблица с решением и ревьюером

## Функционал
- **Фильтр по статусам**
- **Переход к ревью** — клик → `blog-review.html?id=...`

## Дизайн-требования
- Sidebar с новой секцией «Блог» (4 пункта)
- Badge «3» на пункте «Очередь» (количество на ревью)
- Таблица — `table` компонент

## Компоненты
- `BlogQueuePage` — страница очереди
- `QueueTable` — таблица очереди
- `StatusFilter` — фильтр по статусам

## API
- `GET /api/admin/blog/queue` — очередь статей (`?status=`)

## Адаптивность
- Desktop: sidebar + content
- Mobile: sidebar скрывается

## Технологии
- React 19 + Next.js
- Авторизация админа (2FA)
