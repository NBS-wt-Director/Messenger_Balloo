# Задание: balloo.su — Чат с поддержкой

## Макет
`balloo-su/support.html`

## Описание страницы
Чат с техподдержкой Balloo. Автоответчик при обращении, приоритет, среднее время ответа. Сообщения с теми же возможностями, что в обычном чате.

## Структура страницы

### Topbar
- Логотип Balloo с dropdown навигацией
- Заголовок «Чат с поддержкой»
- Аватар → `profile.html`, язык, тема

### Content — Окно чата
1. **Chat header**:
   - Аватар-октагон 🦊 (маскот)
   - «Техподдержка Balloo» + «🟢 Онлайн • Среднее время ответа: 5 мин»
   - Chip «Приоритет: Обычный»
2. **Messages**:
   - Date separator
   - Receiver (автоответ ⚙): «Здравствуйте! Опишите вашу проблему...»
   - Sender: «Не могу подключить Yandex Disk...» (msg-ticks ✓✓ read)
   - Receiver: ответ с инструкцией, действия (📋 😊)
3. **Input area**:
   - Кнопка 📎 (файл)
   - Textarea «Опишите проблему...»
   - Кнопка отправки ➤

## Функционал
- **Автоответ** — при первом обращении бот отправляет приветствие
- **Отправка сообщений** — текст, вложения
- **Приоритет** — обычный / повышенный (при повторных обращениях)
- **Копирование/реакции** — на сообщения поддержки

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Аватар поддержки — октагон с маскотом 🦊
- Сообщения — пузыри без скруглений (sender/receiver)
- Tag «⚙ Автоответ» — для бот-сообщений
- msg-ticks — для сообщений пользователя

## Компоненты
- `SupportChatHeader` — хедер (аватар, статус, время ответа, приоритет)
- `MessageBubble` — пузырь сообщения (переиспользуемый)
- `InputArea` — поле ввода (переиспользуемое)
- `AutoReplyTag` — тег автоответа

## API
- `GET /api/v1/support/chat` — история чата с поддержкой
- `POST /api/v1/support/chat/messages` — отправка сообщения
- `GET /api/v1/support/status` — статус поддержки (онлайн, время ответа)

## WebSocket
- `support:message` — новое сообщение от поддержки
- `support:typing` — поддержка печатает
- `support:auto_reply` — автоответ

## Адаптивность
- Desktop: content без sidebar (однопанельный)
- Mobile: полный экран

## Технологии
- React 19 + Next.js
- Zustand: `supportStore` (messages[], status, sendMessage)
- WebSocket: realtime сообщения
- Автоответ: серверный бот при первом обращении
