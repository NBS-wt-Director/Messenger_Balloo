# Задание: balloo.su — Приглашения

## Макет
`balloo-su/index.html` → `balloo-su/invites.html`

## Макет
`balloo-su/invites.html`

## Описание страницы
Управление приглашениями пользователей. Табы: «Мои приглашения» (статус, отмена) и «Создать» (форма: email, группы через комбобокс, срок действия через переключатель). Модалка быстрого создания.

## Структура страницы

### Topbar
- Логотип Balloo с dropdown навигацией
- Заголовок «Приглашения»
- Кнопка ✏ → модалка нового приглашения
- Аватар → `profile.html`, язык, тема

### Content
1. Заголовок «Приглашения» + подзаголовок
2. **Табы**: «Мои приглашения» / «Создать»
3. **Tab «Мои приглашения»**:
   - Карточки приглашений:
     - Email, chip статуса (✅ Принято / ⏳ Ожидает)
     - Приглашён в группы (список)
     - Даты: отправлено / принято / истекает
     - Кнопка «Отменить» (tertiary, danger) для ожидающих
4. **Tab «Создать»**:
   - Email приглашаемого
   - **Группы — комбобокс**: выпадающий список с чекбоксами, выбранные группы отображаются в строке через запятую
   - **Срок действия — переключатель** (3 кнопки):
     - «Бессрочный» — приглашение не истекает
     - «Срочный» — появляется слайдер (1–90 дней)
     - «Единоразовый» — одноразовое использование
   - При выборе «Срочный» → слайдер выбора количества дней (1–90)
   - Кнопка «Отправить приглашение»
   - Подсказка: «Приглашённые автоматически добавляются в контакты»

### Modal: Новое приглашение
- Email, группы (комбобокс), срок действия (переключатель)
- Кнопки: Отмена / Отправить

## Функционал
- **Создать приглашение** — email + группы (комбобокс) + срок (переключатель) → отправка
- **Комбобокс групп** — multi-select с выпадающим списком, выбранные значения через запятую
- **Переключатель срока** — бессрочный / срочный / единоразовый
- **Слайдер дней** — только при выборе «Срочный» (1–90 дней)
- **Отменить** — отмена ожидающего приглашения
- **Статусы** — принято / ожидает / истекло
- **Авто-контакты** — приглашённые добавляются в контакты

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Chip «Принято» — accent, «Ожидает» — warning
- Карточки приглашений — glassmorphism
- Комбобокс — form-input + выпадающий dropdown с чекбоксами
- Переключатель срока — 3 кнопки (btn--sm), активная — primary
- Слайдер — range input (1–90), значение отображается справа

## Компоненты
- `InviteTabs` — табы (Мои / Создать)
- `InviteList` — список приглашений
- `InviteCard` — карточка приглашения (email, статус, группы, даты)
- `CreateInviteForm` — форма создания (email, группы, срок)
- `GroupCombobox` — multi-select комбобокс групп (выпадающий список, значения через запятую)
- `DurationSwitch` — переключатель срока (бессрочный / срочный / единоразовый) + слайдер дней
- `InviteModal` — модалка быстрого создания

## API
- `GET /api/v1/invites` — список приглашений
- `POST /api/v1/invites` — создание приглашения (email, groups[], duration_type, duration_days?)
- `DELETE /api/v1/invites/:id` — отмена приглашения
- `POST /api/v1/invites/:id/accept` — принятие приглашения

## WebSocket
- `invite:received` — входящее приглашение
- `invite:accepted` — приглашение принято
- `invite:expired` — приглашение истекло

## Адаптивность
- Desktop: page-container
- Mobile: полный экран

## Технологии
- React 19 + Next.js
- Zustand: `inviteStore` (invites[], create, cancel)
- WebSocket: статусы приглашений в realtime
