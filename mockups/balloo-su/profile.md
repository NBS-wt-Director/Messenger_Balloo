# Задание: balloo.su — Профиль (настройки)

## Макет
`balloo-su/profile.html`

## Описание страницы
Страница профиля пользователя с настройками: аватар, мультиаккаунт, основная информация, оформление (тема/язык), Yandex Disk, устройства, приватность, опасная зона.

## Структура страницы

### Topbar
- Логотип Balloo с dropdown навигацией
- Заголовок «Профиль»
- Аватар, язык, тема

### Content (narrow, max-width 640px)
1. **Аватар** — октагон (xl), кнопка «📷 Изменить аватар»
2. **Карточка «Аккаунты»** — мультиаккаунт switcher:
   - Чипы аккаунтов (октагон-аватар + имя), активный — accent border
   - Кнопка «+» (dashed accent) → `login.html`
   - Ссылка «Управлять →» → `accounts.html`
3. **Карточка «Основная информация»**:
   - Имя, Био (textarea), Статус (input + select: На работе/Свободен/Занят/В отпуске)
   - Дата рождения, дата регистрации (disabled)
4. **Карточка «Оформление»**:
   - Тема: 🌙 Тёмная / ☀️ Светлая / 🇷🇺 Наша (синхронизация между устройствами)
   - Язык: select с группами (Русские, Дружественные, Остальные)
5. **Карточка «Yandex Disk»**:
   - Статус подключения, лимиты файлов
   - Кнопка «Отключить» (danger)
6. **Карточка «Устройства»**:
   - Список устройств (иконка, название, локация, активность)
   - Кнопка «Выйти» для каждого, кроме текущего
   - Ссылка «📱 Мои устройства →» → `my-devices.html`
   - Кнопка «➕ Добавить устройство» → `add-device.html`
7. **Карточка «Приватность»**:
   - Видимость «В сети» (select: Только контакты / Никто)
   - Превью уведомлений (20 символов)
   - Заблокированные пользователи (3 чел.)
8. **Карточка «Опасная зона»** (danger border):
   - Удаление аккаунта → анонимизация через 90 дней
   - Кнопка «Удалить аккаунт» (danger, block)

## Функционал
- **Изменить аватар** — загрузка нового аватара (MinIO)
- **Мультиаккаунт** — переключение, добавление, управление → `accounts.html`
- **Редактирование профиля** — имя, био, статус, дата рождения
- **Тема** — переключение dark/light/russian, синхронизация
- **Язык** — выбор из 6+ языков
- **Yandex Disk** — подключение/отключение
- **Устройства** — просмотр, выход из сессий, добавление
- **Приватность** — видимость, превью, блокировки
- **Удаление аккаунта** — анонимизация через 90 дней

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Аватар-октагон (xl) с двойной рамкой
- Чипы аккаунтов — октагон-аватары, активный — accent border
- Карточки — glassmorphism
- Опасная зона — danger border

## Компоненты
- `ProfileAvatar` — аватар с кнопкой изменения
- `MultiAccountSwitcher` — чипы аккаунтов (compact)
- `ProfileInfoForm` — форма основной информации
- `ThemeSelector` — выбор темы (3 кнопки)
- `LanguageSelector` — select с группами языков
- `YandexDiskCard` — карточка подключения диска
- `DeviceList` — список устройств с управлением
- `PrivacySettings` — настройки приватности
- `DangerZone` — удаление аккаунта

## API
- `GET /api/v1/users/me` — данные профиля
- `PATCH /api/v1/users/me` — обновление профиля
- `POST /api/v1/users/me/avatar` — загрузка аватара
- `PATCH /api/v1/users/me/theme` — смена темы
- `PATCH /api/v1/users/me/language` — смена языка
- `POST /api/v1/yandex-disk/connect` — подключение диска
- `DELETE /api/v1/yandex-disk` — отключение диска
- `GET /api/v1/devices` — список устройств
- `DELETE /api/v1/devices/:id/session` — выход из сессии
- `PATCH /api/v1/users/me/privacy` — настройки приватности
- `DELETE /api/v1/users/me` — удаление аккаунта (анонимизация 90 дней)

## WebSocket
- `user:status` — изменение статуса пользователя
- `theme:sync` — синхронизация темы между устройствами

## Адаптивность
- Desktop: page-container--narrow
- Mobile: полный экран, карточки подряд

## Технологии
- React 19 + Next.js
- Zustand: `userStore` (profile, theme, language, devices[])
- Yandex Disk API — OAuth, загрузка файлов
- Аватары — MinIO storage
- Анонимизация — cron job (90 дней)
