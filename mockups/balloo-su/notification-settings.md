# 1_01_34 — Настройки уведомлений (детальные)

**ID:** `1_01_34`  
**Функция:** `0_01_16` — Настройки уведомлений  
**Формат:** Модалка из настроек (отдельная страница с sidebar)  
**Файл:** `notification-settings.html`

---

## Описание

Детальные настройки уведомлений: push, группировка, DND, звонки, mute-список. 7 вкладок с переключением через sidebar.

---

## Структура

### Top Bar
- Логотип Balloo + навигация
- Заголовок: «Настройки уведомлений»
- Аватар + язык/тема

### Sidebar (навигация по вкладкам)
- 🔔 Общие
- 💬 Чаты
- 👥 Группы
- 📢 Каналы
- 📞 Звонки
- ⏰ Отложенные
- 🔕 Mute-список

### Content (7 tab-панелей)

#### Tab 0: Общие
- **Push-уведомления**: вкл/выкл, превью (20/50/100/скрыть), имя отправителя, звук (6 вариантов), вибрация, lock screen, центр уведомлений
- **Группировка**: по чатам, макс. 5 сообщений, время группировки 30 сек
- **Не беспокоить (DND)**: вкл/выкл, расписание (22:00–08:00), исключения (никто/избранные/все), авто-ответ
- **Звонки**: прерывающий звонок, вибрация видеозвонка, звук входящего

#### Tab 1: Чаты
- По умолчанию: звук, вибрация, превью
- Индивидуальные настройки: избранный (Мария Андреева), группа (Команда разработки)

#### Tab 2: Группы
- Поведение по умолчанию: тихие уведомления, только @упоминания, все сообщения
- Режим «Только важные»

#### Tab 3: Каналы
- Звук при посте, push, превью (50/100/скрыть)

#### Tab 4: Звонки
- Звук входящего, вибрация, автоответчик, звонки от незнакомых

#### Tab 5: Отложенные
- Режим тишины: вкл, 23:00–07:00, дни недели, рабочие часы

#### Tab 6: Mute-список
- Заглушённые чаты: Команда разработки (до 20.07), Российская Газета (навсегда)
- Кнопка «➕ Добавить»

---

## Дизайн-требования
- Sidebar: sidebar--narrow, список с list__item--active
- Content: page-container--narrow (max-width 640px)
- Карточки: card с common.css
- Переключатели: switch с common.css
- Select: form-select с common.css

---

## Взаимодействия
- Переключение вкладок: switchNotifTab(index)
- DND options: toggleDNDOptions(el) — показывает доп. настройки при включении
- Каждая вкладка: стандартные элементы форм

---

## API (предполагаемые)
| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/settings/notifications` | Получить настройки |
| PUT | `/api/settings/notifications` | Обновить настройки |
| POST | `/api/notifications/mute` | Заглушить чат |
| DELETE | `/api/notifications/mute/{chatId}` | Разглушить чат |
