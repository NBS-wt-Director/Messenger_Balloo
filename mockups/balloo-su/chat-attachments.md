## Описание

Страница просмотра всех вложений конкретного чата. Открывается по клику на кнопку 📎 в заголовке чата или через пункт «Вложения чата» в дропдаун-меню чата. Показывает все медиа, аудио, файлы, ссылки и опросы, отправленные в чате, сгруппированные по типам и вкладкам.

## Структура

- **Заголовок панели** — кнопка «Назад», аватар собеседника, название «Вложения чата — {имя}», кнопка «Закрыть»
- **Вкладки** — 5 категорий с счётчиками:
  - 📷 Медиа (фото и видео)
  - 🎵 Аудио (голосовые, аудиофайлы)
  - 📄 Файлы (документы, архивы)
  - 🔗 Ссылки (URL, отправленные в чате)
  - 📊 Опросы (опросы и квизы)
- **Поиск** — строка поиска по всем вложениям
- **Тело** — секции по категориям, каждая с заголовком и счётчиком

## Секции контента

### Медиа
- Сетка превью (aspect-ratio 1:1)
- Видео — с индикатором длительности и типом файла
- Клик — открытие полноэкранного просмотрщика

### Аудио
- Список элементов с иконкой, названием, длительностью, отправителем
- Кнопка ▶ для воспроизведения / ⬇ для скачивания

### Файлы
- Список с иконкой типа файла, названием, размером, отправителем, датой
- Кнопка ⬇ для скачивания

### Ссылки
- Карточки с URL, заголовком (OG-превью), отправителем, датой

### Опросы
- Карточки с вопросом, результатами голосования, счётчиком голосов, отправителем

## Дизайн-требования

- Дизайн-система: `mockups/assets/common.css`
- Тема: dark (по умолчанию), light, russian
- Glassmorphism для карточек файлов и ссылок
- Без border-radius (прямые углы), кроме phone-frames
- Аватарки — восьмигранные (октагон)
- Акцент: `--accent: #2db84d`

## Компоненты (React)

| Компонент | Описание |
|---|---|
| `ChatAttachmentsPanel` | Корневой компонент панели вложений |
| `AttachmentsTabs` | Вкладки категорий с счётчиками |
| `AttachmentsSearch` | Строка поиска |
| `MediaGrid` | Сетка медиа-превью |
| `MediaItem` | Элемент медиа (фото/видео) |
| `FileList` | Список файлов |
| `FileItem` | Элемент файла с метаданными |
| `LinkList` | Список ссылок |
| `LinkItem` | Карточка ссылки с OG-превью |
| `PollList` | Список опросов |
| `PollItem` | Карточка опроса с результатами |

## API

### REST

| Метод | Endpoint | Описание |
|---|---|---|
| `GET` | `/api/v1/chats/{chatId}/attachments?type={type}&page={page}&q={query}` | Получить вложения чата по типу с пагинацией и поиском |

### WebSocket events

| Event | Направление | Описание |
|---|---|---|
| `attachment.updated` | server → client | Обновление вложения (новый файл, удаление) |

## Адаптивность

- Desktop: панель 800px, сетка медиа auto-fill minmax(120px, 1fr)
- Tablet: панель на всю ширину, сетка адаптируется
- Mobile: переходит на мобильный макет (узел `у_08`)

## Технологии

- React + TypeScript
- Intersection Observer для lazy-loading медиа
- WebSocket для real-time обновления
- Yandex Disk / MinIO для хранения файлов
