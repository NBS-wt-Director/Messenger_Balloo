# Донат (balloo-su/donate.html)

## Описание
Страница поддержки проекта Balloo. Пользователи могут сделать разовое пожертвование или оформить ежемесячную подписку. Доступна из футера (ссылка «Донат») и из меню.

## Структура
- **Topbar**: логотип Balloo, заголовок «Поддержать проект»
- **Content** (page-container):
  - Hero-блок с иконкой и описанием
  - Карточка прогресса цели месяца (progress bar, сумма/цель)
  - Секция «Уровни поддержки» (4 карточки: кофе/спонсор/VIP/своя сумма)
  - Секция «Способы оплаты» (карта, СБП, crypto, ЮMoney)
  - Секция «Почему ваша поддержка важна» (список причин)
  - Секция «Топ доноров месяца» (список с аватарками)

## Дизайн-требования
- Дизайн-система: common.css
- Темы: dark (по умолчанию), light, russian
- Glassmorphism карточки
- Без border-radius (кроме switch и аватарок)
- Октагон-аватарки для доноров
- Акцент: --accent (#2db84d)

## Компоненты (React)
- `DonateProgress` — прогресс-бар цели месяца
- `DonateTier` — карточка уровня поддержки
- `PaymentMethods` — список способов оплаты
- `DonorList` — список топ доноров
- `CustomAmountInput` — поле ввода своей суммы

## API
- `GET /api/donate/goal` — текущая цель и прогресс
- `GET /api/donate/top-donors` — топ доноров месяца
- `POST /api/donate/create-payment` — создание платежа (сумма, метод, тип)
- `POST /api/donate/subscribe` — создание подписки
- `GET /api/donate/tiers` — доступные уровни

## Адаптивность
- Desktop: 4 колонки уровней поддержки
- Tablet: 2 колонки
- Mobile: 1 колонка, вертикальный стек

## Технологии
- React 19 / Next.js 15 (SSR для SEO)
- Платёжные шлюзы: ЮKassa, СБП, крипто-процессор
