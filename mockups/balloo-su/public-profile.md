# Задание: balloo.su — Публичный профиль

## Макет
`balloo-su/public-profile.html`

## Описание страницы
Публичная страница профиля пользователя по ссылке. Доступна без авторизации. Показывает аватар, имя, био, статус, публичные группы. Кнопки «Написать» и «В контакты» (требуют входа).

## Структура страницы

### Topbar
- Логотип Balloo с dropdown навигацией
- Заголовок «Публичный профиль»
- Маскот 🦊, язык, тема

### Content (narrow)
1. **Профиль-хедер** (центрированный):
   - Аватар-октагон (xl)
   - Имя (крупный шрифт)
   - Био
   - Статус: dot online + «В сети» + chip «Дата рег.»
   - Кнопки: «💬 Написать» (primary), «➕ В контакты» (secondary)
2. **Карточка «Публичные группы»**:
   - Список групп (аватар, название, тип, кол-во участников)

## Функционал
- **Написать** — если авторизован → чат, если нет → `login.html`
- **В контакты** — если авторизован → добавление в контакты, если нет → `login.html`
- **Публичные группы** — список групп, в которых пользователь участник (публичных)

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Аватар-октагон (xl) с двойной рамкой
- Профиль-хедер центрированный
- SSR для SEO (meta-теги, Open Graph)

## Компоненты
- `PublicProfileHeader` — аватар, имя, био, статус, кнопки
- `PublicGroupsList` — список публичных групп

## API
- `GET /api/v1/users/:username/public` — публичный профиль (SSR)
- `POST /api/v1/contacts` — добавление в контакты (требует авторизации)

## Адаптивность
- Desktop: page-container--narrow
- Mobile: полный экран

## Технологии
- React 19 + Next.js (SSR для SEO)
- Open Graph meta-теги
- Zustand: `authStore` (проверка авторизации для кнопок)
