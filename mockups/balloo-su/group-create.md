# Задание: balloo.su — Создание группы

## Макет
`balloo-su/group-create.html`

## Описание страницы
Создание группового чата. Аватар, название, описание, выбор типа группы (5 типов), настройки (правила, история, срок ссылки). Переход на `group-settings.html` после создания.

## Структура страницы

### Topbar
- Логотип Balloo с dropdown навигацией
- Заголовок «Создание группы»
- Аватар → `profile.html`, язык, тема

### Content (narrow)
1. Заголовок «Создать группу»
2. **Карточка «Основное»**:
   - Аватар-октагон (xl) + кнопка «Загрузить аватар»
   - Название группы
   - Описание (textarea)
3. **Карточка «Тип группы»** (5 типов, selectable):
   - 🔒 Обычная (закрытая) — до 1000, вход по приглашению (по умолчанию)
   - 🌐 Публичная (открытая) — до 1000, вход свободный
   - 💡 Тема (по интересам) — до 1000, рекламный доход 25/75 (v2)
   - 📰 СМИ — до 10 000 000, требуется подтверждение документами (chip «Документы»)
   - 🏢 Корпоративная — 2+ группы, сотрудники + клиенты, витрина, до 20 000
4. **Карточка «Настройки»**:
   - Обязательное ознакомление с правилами (switch)
   - История для новых участников (select: Вся / Последние 100 / С момента вступления)
   - Срок действия ссылки-приглашения (select: 24ч / 7д / Вечная / 1 использование)
5. Кнопка «Создать группу» (primary, block, lg) → `group-settings.html`

## Функционал
- **Загрузить аватар** — выбор и загрузка аватара группы (MinIO)
- **Выбор типа** — selectable list, один активный
- **Настройки** — правила, история, срок ссылки
- **Создать** — отправка данных → переход на `group-settings.html`
- **СМИ** — требует подтверждения документами (v2)

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Аватар-октагон (xl) с двойной рамкой
- Selectable list — активный с accent-bg + chip «✓ Выбрано»
- Switch для toggle
- page-container--narrow

## Компоненты
- `GroupAvatarUpload` — загрузка аватара группы
- `GroupBasicForm` — название + описание
- `GroupTypeSelector` — selectable list из 5 типов
- `GroupSettingsForm` — настройки (правила, история, срок ссылки)
- `CreateGroupButton` — кнопка создания

## API
- `POST /api/v1/groups` — создание группы
- `POST /api/v1/groups/:id/avatar` — загрузка аватара
- `POST /api/v1/groups/:id/invite-link` — генерация ссылки-приглашения

## WebSocket
- `group:created` — группа создана
- `group:member_joined` — новый участник

## Адаптивность
- Desktop: page-container--narrow
- Mobile: полный экран

## Технологии
- React 19 + Next.js
- Zustand: `groupStore` (createGroup, groupTypes)
- Аватары — MinIO storage
- СМИ-группы — модерация документов (v2)
