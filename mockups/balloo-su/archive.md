# Задание: balloo.su — Архив

## Макет
`balloo-su/archive.html`

## Описание страницы
Список архивированных чатов. Восстановление и удаление архивированных чатов.

## Структура страницы

### Topbar
- Логотип Balloo с dropdown навигацией
- Заголовок «Архив»
- Аватар, язык, тема

### Content
1. Заголовок «Архив чатов» + подзаголовок (количество)
2. **Список архивированных чатов**:
   - Аватар-октагон, имя, дата архивации
   - Кнопка «↩ Восстановить» (secondary)
   - Кнопка «🗑» (tertiary, danger)
3. **Empty state** — «Нет архивированных чатов» + подсказка «Архивируйте чат через меню ⋮ → "В архив"»

## Функционал
- **Восстановить** — возврат чата из архива в активный список
- **Удалить** — окончательное удаление архивированного чата

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Аватары-октагоны (status-offline для архивных)
- Кнопка «Восстановить» — secondary
- Кнопка удаления — tertiary, text-danger

## Компоненты
- `ArchiveList` — список архивированных чатов
- `ArchiveListItem` — элемент (аватар, имя, дата, кнопки)
- `EmptyState` — пустое состояние

## API
- `GET /api/v1/chats/archived` — список архивированных чатов
- `POST /api/v1/chats/:id/unarchive` — восстановление
- `DELETE /api/v1/chats/:id` — окончательное удаление

## Адаптивность
- Desktop: page-container
- Mobile: полный экран

## Технологии
- React 19 + Next.js
- Zustand: `chatStore` (archivedChats[], unarchive, deleteArchived)
