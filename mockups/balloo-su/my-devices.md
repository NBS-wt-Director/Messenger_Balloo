# Задание: balloo.su — Мои устройства

## Макет
`balloo-su/my-devices.html`

## Описание страницы
Страница управления устройствами с активными сессиями. Доступна из профиля (кнопка «Мои устройства»). Только для основного узла balloo.su, на всех платформах.

## Структура страницы

### Topbar
- Логотип Balloo, кнопка «← Назад» в профиль
- Аватар, язык, тема

### Content (narrow, max-width 640px)
1. **Ссылка** «← Назад в профиль»
2. **Заголовок** «📱 Мои устройства»
3. **Карточки статистики** (3): Всего устройств / Активных / Узлов подключено
4. **Карточка текущего устройства** (accent border):
   - Chip «Это устройство» + «Сейчас активно»
   - Иконка, название, локация · IP · версия
   - Метаданные: узлы, ОС/браузер, последняя активность, IP
   - Кнопки: Переименовать / Подробнее (раскрывает таблицу с session ID, токенами, WS)
5. **Карточки других устройств** (по 1 на устройство):
   - Иконка, название, локация · время · версия
   - Кнопки: Переименовать / Подробнее / Остановить (danger)
   - Подробнее раскрывает метаданные и таблицу сессии
6. **Кнопка** «➕ Добавить устройство» → `add-device.html`
7. **Опасная зона**: «Завершить все другие сессии» (danger)

## Функционал
- **Переименование устройства** — inline prompt, сохраняется в БД
- **Остановка сессии** — завершение сессии (revoke refresh token), подтверждение
- **Подробнее** — сворачиваемая панель с полной инфой сессии (session ID, токены, WS, push token)
- **Завершить все другие** — revoke всех сессий кроме текущей
- **Добавить устройство** — переход на `add-device.html`

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Текущее устройство — accent border
- Сворачиваемые панели деталей (details/summary или JS toggle)
- Кнопка «Остановить» — danger
- Статистика в карточках с цветными числами

## Компоненты
- `DeviceCard` — карточка устройства с действиями
- `DeviceDetailsPanel` — сворачиваемая панель деталей сессии
- `DeviceStatsGrid` — сетка статистики
- `RenameDeviceDialog` — диалог переименования
- `StopSessionButton` — кнопка остановки с подтверждением

## API
- `GET /api/v1/devices` — список устройств с активными сессиями
- `PATCH /api/v1/devices/:id` — переименовать устройство
- `DELETE /api/v1/sessions/:id` — остановить сессию
- `DELETE /api/v1/sessions` (except current) — завершить все другие
- `GET /api/v1/sessions/:id` — детали сессии

## Адаптивность
- Desktop: page-container--narrow
- Mobile: полный экран, карточки на всю ширину
- Кнопки действий адаптируются (иконки на мобильном)
