# Задание: balloo.su — Контакты

## Макет
`balloo-su/contacts.html`

## Описание страницы
Управление контактами. Sidebar со списком контактов и групп + content с детальной карточкой выбранного контакта. Вкладки: «Контакты», «Группы» (обычные, не СМИ/не каналы) и «Чёрный список». В карточке контакта — кнопки звонка, информация о пропущенных звонках и новых сообщениях. В списке — badges непрочитанных сообщений и пропущенных звонков.

## Структура страницы

### Topbar
- Логотип Balloo с dropdown навигацией
- Заголовок «Контакты»
- Кнопка 📨 → `invites.html`
- Аватар → `profile.html`, язык, тема

### Sidebar — Список контактов и групп
- Поиск контактов
- Список: аватар-октагон, имя, статус (в сети / был / DND / занят), badges:
  - Непрочитанные сообщения (badge с числом)
  - Пропущенные звонки (badge 📞 с числом)
- Группы (обычные, не СМИ/не каналы) — в списке с пометкой «Группа»

### Content — Детальная карточка
1. Заголовок «Контакты»
2. **Вкладки**: «Контакты» (active) / «👥 Группы» / «🚫 Чёрный список»
3. Подзаголовок (количество контактов и групп)
4. **Карточка контакта**:
   - Аватар-октагон (lg), имя, профессия/город, статус
   - Кнопки: 💬 Написать → `chats.html`, 📞 (аудиозвонок), 📹 (видеозвонок)
   - Divider
   - Био, дата рождения, дата регистрации
   - Chips: «💬 N новых сообщений», «📞 N пропущенных звонков»
5. Кнопка «📨 Пригласить друга» → `invites.html`

> Вкладка «Группы» — обычные группы (private), не СМИ и не каналы.
> Вкладка «Чёрный список» — список заблокированных пользователей с кнопкой «Разблокировать».

## Функционал
- **Поиск контактов** — фильтрация списка
- **Написать** — переход в чат с контактом
- **Звонок** — аудио/видеозвонок контакту (кнопки 📞📹 в карточке)
- **Группы** — вкладка с обычными группами
- **Чёрный список** — вкладка со списком заблокированных, разблокировка
- **Пригласить** — переход на `invites.html`
- **Badges** — непрочитанные сообщения и пропущенные звонки в списке и карточке

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Аватары-октагоны с двойной рамкой
- Карточка контакта — glassmorphism
- Кнопка «Написать» — primary

## Компоненты
- `ContactList` — sidebar со списком контактов
- `ContactListItem` — элемент (аватар, имя, статус, кнопка чата)
- `ContactCard` — детальная карточка (аватар, инфо, действия)

## API
- `GET /api/v1/contacts` — список контактов
- `GET /api/v1/contacts/:id` — детальная информация
- `DELETE /api/v1/contacts/:id` — удаление из контактов

## WebSocket
- `contact:status` — изменение статуса контакта (online/offline/DND)

## Адаптивность
- Desktop: sidebar + content (двухпанельный)
- Mobile: одна панель, список → карточка

## Технологии
- React 19 + Next.js
- Zustand: `contactStore` (contacts[], selectedId)
- WebSocket: статусы контактов в realtime
