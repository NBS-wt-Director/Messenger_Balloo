ℹ️ Как работает мультиаккаунт

  • Чаты и контакты — у каждого аккаунта свои, отображаются только для активного
  • Уведомления — приходят для всех аккаунтов одновременно, с пометкой аккаунта
  • Переключение — мгновенное, без повторного входа (сессии хранятся)
  • Тема и язык — общие для всех аккаунтов (синхронизируются)
  • Устройства — общие для всех аккаунтов на этом устройстве
  • Отключение аккаунта — сессия удаляется, данные остаются на сервере
  • Лимит — неограниченно

🔔 Уведомления мультиаккаунта

Push-уведомления приходят для всех подключённых аккаунтов. Каждое уведомление содержит:

  • Метку аккаунта — имя/аватар аккаунта, от которого пришло
  • Группировку — уведомления одного аккаунта группируются
  • Переключение по тапу — тап на уведомление переключает на нужный аккаунт и открывает чат

Уведомления можно отключить индивидуально для каждого аккаунта (кнопка 🔔/🔕).
