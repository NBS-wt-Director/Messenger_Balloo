# Настройка 2FA (balloo-su/two-factor.html)

## Описание
Настройка двухфакторной аутентификации (TOTP) для пользователя. Опциональна, включается в настройках. Все платформы. Включает: QR-код TOTP, ввод кода подтверждения, backup-коды, отключение (с подтверждением паролем/кодом).

## Структура
- **Topbar**: логотип, заголовок «Двухфакторная аутентификация»
- **Sidebar**: навигация настроек (Настройки / Профиль / 2FA / Мои донаты)
- **Content** (page-container):
  - Карточка статуса (включена/активна)
  - Шаг 1: QR-код + секрет вручную
  - Шаг 2: ввод 6-значного кода
  - Шаг 3: backup-коды (сетка) + перегенерация
  - Отключение (ввод пароля/кода + кнопка danger)

## Дизайн-требования
- Дизайн-система: common.css
- Октагон-иконка статуса
- Темы: dark, light, russian
- Опасные действия — red border (--danger)

## Компоненты (React)
- `TwoFactorSetup` — QR-код TOTP + backup-коды + отключение

## API
- `POST /auth/2fa/setup` — инициализация 2FA (возвращает QR + secret)
- `POST /auth/2fa/verify` — подтверждение 2FA-кода при входе/настройке
- `DELETE /auth/2fa` — отключить 2FA (требует пароль/код)
- `POST /auth/2fa/backup-codes/regenerate` — перегенерация backup-кодов

## Адаптивность
- Desktop: page-container--narrow, сайдбар слева
- Mobile: без сайдбара, вертикальный стек

## Технологии
- React 19 / Next.js 15
- TOTP-библиотека (otplib)
- Секреты хранятся в `user_2fa_secrets` (totpSecret, backupCodes Json, isEnabled)
