# Задание: balloo.su — О компании

## Макет
`balloo-su/about-company.html`

## Описание страницы
Информация о компании Balloo. Описание, контакты, команда, юридическая информация. SSR для SEO. Ссылка на портал сотрудников.

## Структура страницы

### Topbar
- Логотип Balloo с dropdown навигацией
- Заголовок «О компании»
- Маскот 🦊, язык, тема

### Content (narrow)
1. Заголовок «О компании»
2. **Карточка описания**:
   - Октагон-логотип B (accent)
   - Описание: российская технологическая компания, кроссплатформенный мессенджер
3. **Карточка «Контакты»**:
   - Email: info@balloo.su
   - Поддержка: через приложение → Чат с поддержкой
   - Telegram: @balloo_support
4. **Карточка «Команда»**:
   - Разработчики, дизайнеры, техподдержка
   - Ссылка «→ Портал сотрудников» → `../command-balloo-su/dashboard.html`
5. **Карточка «Юридическая информация»**:
   - ИНН, ОГРН
   - © 2026 Balloo. Все права защищены.

## Функционал
- **Просмотр информации** — статичная страница
- **Портал сотрудников** — ссылка на `command-balloo-su/dashboard.html`
- **SSR** — для SEO

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Октагон-логотип B (accent)
- Карточки — glassmorphism
- page-container--narrow

## Компоненты
- `AboutCompanyPage` — статичная страница
- `CompanyCard` — карточка секции (заголовок + контент)

## API
- `GET /api/v1/company` — информация о компании (SSR)

## Адаптивность
- Desktop: page-container--narrow
- Mobile: полный экран

## Технологии
- React 19 + Next.js (SSR для SEO)
- Статичный контент из CMS / БД
