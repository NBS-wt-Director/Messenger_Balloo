# Сторис (balloo-su/stories.html)

## Описание
Лента историй (сторис) над списком чатов + полноэкранный просмотрщик. Сторис — фото/видео с TTL 24 часа, просмотрами и ответами (ответ переходит в чат). Аватары сторис — восьмиугольники (`--octagon-clip-stories`), где диагональные стороны в 3 раза короче прямых. При просмотре углы переливаются градиентом, зависящим от активной темы (dark/light/russian).

**Добавлен экран создания сторис:** `story-create.html` — открывается по клику на «Моя сторис» в треё.

## Структура
- **Topbar**: логотип Balloo, заголовок «Чаты», кнопка сторис
- **StoriesTray**: горизонтальная лента аватарок сторис (октагон `--octagon-clip-stories`) над сайдбаром
  - «Моя сторис» (добавить) — клик → `story-create.html`
  - Непросмотренные — переливающийся градиент-рейд
  - Просмотренные — серый ринг
- **Main**: сайдбар (чат-лист) + контент (empty-state с приглашением открыть просмотр)
- **StoryViewer** (полноэкранный оверлей):
  - Прогресс-бары (по количеству сторис пользователя)
  - Хедер: аватар (октагон), имя, время, закрыть
  - Сцена: медиа (фото/видео) + навигация (‹ ›)
  - Футер: поле ответа + счётчик просмотров

## Дизайн-требования
- Дизайн-система: common.css
- CSS-переменная `--octagon-clip-stories` (диагонали в 3 раза короче прямых сторон) — НЕ заменяет `--octagon-clip`
- Переливающийся градиент `--story-gradient` per-темы (dark/light/russian)
- Анимация `story-shimmer` для градиента
- Темы: dark (по умолчанию), light, russian
- Без border-radius

## Компоненты (React)
- `StoriesTray` — горизонтальная лента аватарок сторис (октагон `--octagon-clip-stories`)
- `StoryViewer` — полноэкранный просмотрщик с прогресс-баром, свайпом, переливающимся градиентом по теме
- `StoryCreate` — экран создания сторис (`story-create.html`)

## API
- `GET /stories` — лента сторис (подписки + свои)
- `POST /stories` — создать сторис (photo/video)
- `POST /stories/draft` — сохранить черновик
- `PUT /stories/:id` — обновить сторис
- `DELETE /stories/:id` — удалить сторис
- `GET /stories/:id/views` — список просмотров
- `POST /stories/:id/reply` — ответ на сторис (переходит в чат)

## WebSocket
- `story.created` — сторис создана (real-time обновление трея)
- `story.published` — сторис опубликована

## Адаптивность
- Desktop: трей над сайдбаром, просмотрщик по центру
- Mobile: трей на всю ширину, просмотрщик full-screen, свайп для навигации
- Desktop: клик по зонам ‹ ›

## Технологии
- React 19 / Next.js 15
- Yandex Disk для хранения медиа сторис
- WebSocket: событие `story.created` для real-time обновления трея
