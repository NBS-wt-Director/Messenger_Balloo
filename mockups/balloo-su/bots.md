# Задание: balloo.su — О ботах

## Макет
`balloo-su/bots.html`

## Описание страницы
Страница управления ботами: создание бота (имя, описание, webhook), список моих ботов с токенами, API-документация. Ссылка на полную документацию API.

## Структура страницы

### Topbar
- Логотип Balloo с dropdown навигацией
- Заголовок «О ботах»
- Аватар → `profile.html`, язык, тема

### Content
1. Заголовок «🤖 Боты в Balloo» + подзаголовок
2. **Карточка «Создать бота»**:
   - Имя бота
   - Описание
   - Webhook URL
   - Кнопка «Создать бота» (primary, block)
3. **Карточка «Мои боты»**:
   - Список ботов: аватар-октагон 🤖, имя, токен (маскированный)
   - Кнопка «📋 Копировать токен»
4. **Карточка «API документация»**:
   - Описание: Balloo Bot API на REST, Webhook
   - Пример кода (monospace): `POST /api/v1/bots/{token}/sendMessage`
   - Кнопка «📚 Полная документация API →» → `../docs-balloo-su/api-docs.html`

## Функционал
- **Создать бота** — имя, описание, webhook → генерация токена
- **Копировать токен** — копирование API-токена бота в буфер
- **API документация** — переход на `docs-balloo-su/api-docs.html`
- **Управление ботами** — просмотр, удаление (v2)

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Аватар бота — октагон с 🤖
- Пример кода — monospace, bg-tertiary
- Токен — маскированный (••••••••ab3f)

## Компоненты
- `CreateBotForm` — форма создания бота (имя, описание, webhook)
- `BotList` — список ботов
- `BotListItem` — элемент (аватар, имя, токен, кнопка копирования)
- `ApiDocPreview` — превью API с примером кода

## API
- `POST /api/v1/bots` — создание бота (генерация токена)
- `GET /api/v1/bots` — список ботов пользователя
- `DELETE /api/v1/bots/:id` — удаление бота
- `POST /api/v1/bots/:token/sendMessage` — отправка сообщения от бота
- Webhook: `POST {webhook_url}` — получение обновлений

## Адаптивность
- Desktop: page-container
- Mobile: полный экран

## Технологии
- React 19 + Next.js
- Zustand: `botStore` (bots[], create, delete)
- Bot API: REST + Webhook
- Токены: криптографическая генерация
