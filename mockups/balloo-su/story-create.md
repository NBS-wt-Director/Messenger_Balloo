# 1_01_31 — Создать сторис

## Описание
Экран создания новых историй (сторис) в Balloo. Позволяет загрузить фото/видео, добавить текст, выбрать градиентный фон, добавить стикеры, настроить видимость и время хранения. Предпросмотр в реальном времени в формате 9:16.

## Структура
- **Topbar**: логотип Balloo, заголовок «Создать сторис», кнопка «Назад» к stories.html
- **Content** (двухпанельный):
  - **Левая панель (preview)**: предпросмотр сторис 9:16 с градиентом/медиа/текстом/стикерами
  - **Правая панель (editor)**:
    - Медиа: загрузка фото/видео (JPG, PNG, GIF, MP4, макс. 10 МБ), затемнение
    - Текст: textarea для текста, выбор шрифта (Inter/Manrope/Arial Black/Georgia), размер шрифта (14-32px)
    - Фон: палитра градиентов (12 вариантов) + ч/б
    - Стикеры: выбор эмодзи-стикеров (🔥❤️😂👍🎉🚀💡⭐)
    - Видимость: кто может смотреть (все/друзья/только я/выборочно), время хранения (24ч/7д/30д), разрешение ответов, показ просмотров
    - Футер: «Отмена», «Черновик», «Опубликовать»

## Дизайн-требования
- common.css, glassmorphism, темы
- Предпросмотр — 9:16 (мобильный формат)
- Градиенты переливаются в зависимости от темы
- Стикеры — перетаскиваемые (drag)
- Цветовые свотчи — сетка 6 колонок

## Компоненты
- `StoryCreatePreview` — предпросмотр 9:16 с медиа/текстом/стикерами
- `StoryCreateEditor` — панель редактора
- `MediaUpload` — загрузка фото/видео
- `TextEditor` — редактор текста с настройками шрифта
- `GradientPicker` — палитра градиентов
- `StickerPicker` — выбор стикеров
- `VisibilitySettings` — настройки видимости и хранения

## API
- `POST /stories` — создать сторис (photo/video + text + settings)
- `POST /stories/draft` — сохранить черновик
- `PUT /stories/:id` — обновить сторис
- `DELETE /stories/:id` — удалить сторис
- `GET /stories/:id` — данные сторис (для редактирования)

## WebSocket
- `story.created` — сторис создана (real-time обновление трея)
- `story.published` — сторис опубликована

## Адаптивность
- Desktop: двухпанельный layout (preview слева, editor справа)
- Mobile: preview сверху (max-height 50vh), editor снизу, вертикальный layout

## Технологии
- React 19 / Next.js 15
- Yandex Disk для хранения медиа сторис
- Drag & Drop для стикеров (react-dnd или native HTML5)
- Zustand: `storyStore` (draft, preview, settings)
