Политика неразглашения

1. Общие положения

Balloo Messenger — кроссплатформенный мессенджер. Используя сервис, вы соглашаетесь с настоящими правилами.

2. Запрещённый контент

Запрещается: спам, ненормативная лексика, оскорбления, реклама без согласования, вредоносные файлы. Нарушения → бан (5 жалоб + подтверждение 4 админов).

3. Приватность

Администраторы НЕ читают содержимое чатов — только статистика. Удаление аккаунта → анонимизация через 90 дней.

4. Обжалование бана

Пользователь может обжаловать бан в течение 3 часов после блокировки.

5. Файлы и хранилище

Без Yandex Disk: до 10 МБ. С диском: до 1 ГБ. Аватарки и медиа групп — в MinIO.

Контент загружается из RULES.md в корне монорепо

1. Сбор данных

Balloo собирает минимальный объём данных, необходимый для функционирования мессенджера: email, отображаемое имя, аватар, устройства и сессии.

2. Хранение сообщений

Сообщения хранятся на сервере в зашифрованном виде. Администраторы не имеют доступа к содержимому чатов — только метаданные (время, участники).

3. Передача третьим лицам

Balloo не передаёт данные пользователей третьим лицам. Исключение — требования законодательства РФ (при официальном запросе).

4. Удаление данных

При удалении аккаунта все персональные данные анонимизируются в течение 90 дней. Сообщения в групповых чатах сохраняются для других участников.

5. Файлы и вложения

Файлы хранятся в MinIO (аватарки, медиа) или Yandex Disk (пользовательские файлы). Доступ к файлам — только у участников чата.
