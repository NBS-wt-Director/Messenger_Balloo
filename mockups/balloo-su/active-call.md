# Задание: balloo.su — Активный звонок

## Макет
`balloo-su/active-call.html`

## Описание страницы
Полноэкранный интерфейс активного группового звонка во всю высоту окна. Говорящий участник занимает основную область экрана, остальные участники отображаются горизонтальной полосой внизу над элементами управления. Индикатор говорящего, демонстрация экрана, mute, запись. До 30 участников.

## Структура страницы

### Topbar
- Логотип Balloo
- Заголовок «Групповой звонок — Команда разработки»
- Кнопки: ⏺ Запись, 🖥 Демо экрана, 📹 Камера, 🎤 Микрофон
- Аватар, язык, тема

### Call Overlay (на всю высоту окна)
1. **Header** (flex-shrink:0):
   - Аватар группы, название, таймер (00:00)
   - Chip «⚠ Низкая скорость», chip «5 участников»
   - Кнопка «Завершить» → `calls.html`
2. **Main speaker area** (flex:1 — занимает большую часть экрана):
   - Крупный видео-блок активного говорящего
   - Speaking indicator (accent border-glow)
   - Имя + «говорит 🎤»
3. **Participants strip** (горизонтальная полоса над контролами):
   - Миниатюры остальных участников (120×90px)
   - Чипы: 🖥 Экран, 🔇 Mute
   - Имена под миниатюрами
   - Горизонтальный скролл при большом количестве
4. **Controls** (flex-shrink:0 — внизу):
   - 🎤 Mute (toggle)
   - 📹 Video (toggle)
   - 🖥 Screen share (toggle)
   - 📞 Hangup → `calls.html`

## Функционал
- **Видео/аудио** — WebRTC медиа-стримы
- **Mute** — вкл/выкл микрофона
- **Video** — вкл/выкл камеры
- **Screen share** — демонстрация экрана
- **Запись** — запись звонка (v2)
- **Speaking indicator** — определение активного говорящего
- **Низкая скорость** — авто-переключение на аудио при плохом соединении
- **Завершить** — конец звонка → `calls.html`

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Аватары-октагоны (lg) для участников без видео
- Speaking indicator — accent border-glow
- Controls — октагон-кнопки (call-control)
- Hangup — danger-цвет
- Glassmorphism для overlay

## Компоненты
- `CallOverlay` — полноэкранный overlay звонка (на всю высоту окна)
- `CallHeader` — хедер (название, таймер, участники, завершить)
- `CallMainSpeaker` — крупный видео-блок активного говорящего (flex:1)
- `CallParticipantsStrip` — горизонтальная полоса миниатюр остальных участников
- `CallParticipant` — видео-блок участника (видео/аватар, speaking, mute, screen)
- `CallControls` — кнопки управления (mute, video, screen, hangup)
- `CallTimer` — таймер звонка

## API
- `POST /api/v1/calls/:id/end` — завершение звонка
- `POST /api/v1/calls/:id/record` — запуск записи (v2)

## WebSocket
- `call:participant_joined` — участник присоединился
- `call:participant_left` — участник вышел
- `call:state` — mute/video/screen изменения
- `call:speaking` — активный говорящий
- `call:quality` — изменение качества соединения
- `call:ended` — звонок завершён

## Адаптивность
- Desktop: на всю высоту окна, говорящий — основная область, остальные — полосой снизу
- Mobile: полный экран, PiP для собственного видео, полоса участников скроллится

## Технологии
- React 19 + Next.js
- WebRTC: медиа-стримы, peer-to-peer / SFU
- Zustand: `callStore` (participants[], muted, videoOn, screenSharing, timer)
- WebSocket: сигналинг, состояние участников
- SFU: mediasoup / LiveKit (для групповых звонков)
