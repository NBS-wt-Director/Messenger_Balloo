# Задание: balloo.su — Звонки (история)

## Макет
`balloo-su/calls.html`

## Описание страницы
История всех звонков (аудио, видео, групповые). Статусы: принят, пропущен. Быстрый запуск нового звонка.

## Структура страницы

### Topbar
- Логотип Balloo с dropdown навигацией
- Заголовок «Звонки»
- Аватар → `profile.html`, язык, тема

### Content
1. Заголовок «Звонки» + подзаголовок «История всех звонков»
2. **Кнопки быстрого звонка**: 📞 (primary), 📹 (secondary)
3. **Список звонков**:
   - Аватар-октагон, имя/группа
   - Подзаголовок: тип (аудио/видео/группа), направление (принят/пропущен/исходящий), время, длительность
   - Chip: ✅ Принят (accent) / ❌ Пропущен (danger)

## Функционал
- **Новый звонок** — кнопки 📞 / 📹 → выбор контакта → звонок
- **Перезвонить** — клик на элемент истории → новый звонок
- **Детали** — расширенная информация о звонке

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Аватары-октагоны
- Chip «Принят» — accent, «Пропущен» — danger
- Иконки: 📞 аудио, 📹 видео

## Компоненты
- `CallHistoryList` — список истории звонков
- `CallHistoryItem` — элемент (аватар, имя, тип, статус, длительность)
- `QuickCallButtons` — кнопки быстрого звонка (📞 / 📹)

## API
- `GET /api/v1/calls` — история звонков (пагинация)
- `POST /api/v1/calls` — инициация звонка

## WebSocket
- `call:incoming` — входящий звонок
- `call:missed` — пропущенный звонок

## Адаптивность
- Desktop: page-container
- Mobile: полный экран

## Технологии
- React 19 + Next.js
- Zustand: `callStore` (history[], initiate)
- WebRTC: звонки
