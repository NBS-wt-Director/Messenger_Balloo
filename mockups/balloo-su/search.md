# Задание: balloo.su — Поиск

## Макет
`balloo-su/search.html`

## Описание страницы
Глобальный поиск по чатам, людям, файлам, медиа и ссылкам. Табы для фильтрации по типу контента.

## Структура страницы

### Topbar
- Логотип Balloo с dropdown навигацией
- Заголовок «Поиск»
- Аватар → `profile.html`, язык, тема

### Content
1. **Поле поиска** — крупное, placeholder «🔍 Поиск по чатам, людям, файлам, медиа...»
2. **Табы**:
   - Все / 💬 Чаты / 👤 Люди / 📎 Файлы / 🎬 Медиа / 🔗 Ссылки
3. **Tab panel «Все»**:
   - Секция «Недавние»
   - Результаты: чаты (аватар + имя + кол-во сообщений), файлы (иконка + имя + размер + источник), медиа (иконка + имя + размер + источник)
4. **Empty states** — для табов без результатов (иконка + «Нет результатов» + «Попробуйте изменить запрос»)

## Функционал
- **Глобальный поиск** — ввод запроса, debounce, результаты по всем типам
- **Табы-фильтры** — переключение между типами контента
- **Клик на результат** — переход к чату / файлу / медиа

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Поле поиска крупное (font-size 16px, padding 14px)
- Табы с эмодзи-иконками
- Empty state с анимацией-эмодзи

## Компоненты
- `SearchBar` — поле глобального поиска
- `SearchTabs` — табы фильтрации (Все / Чаты / Люди / Файлы / Медиа / Ссылки)
- `SearchResultItem` — элемент результата (аватар/иконка, заголовок, подзаголовок)
- `EmptyState` — пустое состояние для табов

## API
- `GET /api/v1/search?q=...&type=all|chats|people|files|media|links` — глобальный поиск
- `GET /api/v1/search/recent` — недавние поиски

## Адаптивность
- Desktop: page-container, центрированный
- Mobile: полный экран

## Технологии
- React 19 + Next.js
- Zustand: `searchStore` (query, activeTab, results)
- Debounce: 300ms перед запросом
- Поиск: серверный (PostgreSQL full-text search)
