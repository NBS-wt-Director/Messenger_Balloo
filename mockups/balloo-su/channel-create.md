# 1_01_35 — Создание канала

**ID:** `1_01_35`  
**Функция:** `0_01_06` — Создание каналов и групп  
**Формат:** Отдельный экран  
**Файл:** `channel-create.html`

---

## Описание

Экран создания нового канала: название, аватар, описание, тип видимости, настройки подписчиков, администраторы, бот-команды. Аналог создания группы, но с настройками подписчиков и публичности.

---

## Структура

### Top Bar
- Логотип Balloo + навигация
- Заголовок: «Создание канала»
- Аватар + язык/тема

### Sidebar
- Список чатов (упрощённый)

### Content (page-container--narrow)

#### Header
- Аватар-заглушка 📢 (градиент gold)
- Заголовок: «Создать канал»
- Подзаголовок: «Канал — рассылка сообщений для неограниченного числа подписчиков»

#### Step 1: Основное (card)
- Название канала * (70 символов, счётчик)
- Аватар (клик → загрузка, 120px octagon, placeholder 📷)
- Описание (500 символов, счётчик)

#### Step 2: Тип канала (card)
- Тип видимости: Публичный / Приватный (radio buttons с визуальным выделением)
- Ссылка-приглашение (автогенерация из названия, readonly input + кнопка копировать)
- Категория: Новости, Технологии, Наука, Бизнес, Развлечения, Образование, Спорт, Другое

#### Step 3: Подписчики (card)
- Кто может писать: только админ, админ+модераторы, все подписчики (обсуждаемый)
- Редактирование постов: 24ч / навсегда / без редактирования
- Разрешить пересылку из канала
- Скрыть счётчик подписчиков
- Требовать одобрение при вступлении

#### Step 4: Обсуждение (card, показывается если «все подписчики»)
- Включить обсуждение → создаётся группа-чат для комментариев

#### Step 5: Администраторы (card)
- Описание прав админов
- Поиск: «🔍 Добавить администратора...» + кнопка ➕
- Текущий админ: Иван Иванов (Создатель, все права)

#### Step 6: Бот-команды (card)
- Описание: бот для автоматической публикации
- Поле: @botname /publish + кнопка ➕

#### Actions
- 📢 Создать канал (primary, block)
- Отмена (tertiary)

---

## Дизайн-требования
- page-container--narrow (max-width 640px)
- Карточки: card с common.css
- Аватар создания: 120px octagon, gradient gold
- Radio buttons: form-checkbox с визуальным выделением (border 2px solid var(--accent))
- Счётчики символов: text-xs text-muted

---

## Взаимодействия
- Ввод названия → auto-generate link (slug из названия)
- Переключение типа → toggleChannelLink(show/hide link)
- Создание → createChannel(): валидация → showToast → redirect на chats.html
- Отмена → window.history.back()

---

## API (предполагаемые)
| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/channels` | Создать канал |
| PATCH | `/api/channels/{id}` | Обновить канал |
| POST | `/api/channels/{id}/admins` | Добавить администратора |
| POST | `/api/channels/{id}/bots` | Привязать бота |
| GET | `/api/channels/search` | Поиск каналов |
