# 1_01_19 — Настройки группы

## Описание
Полная страница настроек группы Balloo с вкладками: Основное, Участники, Роли, Шаблоны сообщений (текст/вложение/интерактив), СМИ, Корпоративные (витрина/расписание/чаты/реклама), Экспорт/импорт, Удаление. Все поля редактируемы, кроме статистики. **Добавлена модалка «Корпоративные настройки»** с подмодалками: добавить офис, добавить товар, добавить чат.

## Структура
- **Topbar**: логотип Balloo, заголовок, аватар, язык, тема
- **Sidebar**: 8 разделов (Основное, Участники, Роли, Шаблоны, СМИ, Корпоративные, Экспорт, Удалить)
- **Content** — панели переключаются через sidebar:
  - **Основное**: название, описание, тип группы, ссылка-приглашение, приватность, правила, статистика (read-only)
  - **Участники**: таблица с поиском, роли, кнопка добавить
  - **Роли**: таблица прав (удаление, закреп, приглашение, редактирование, назначение)
  - **Шаблоны сообщений** (подвкладки: Текст, Вложение, Интерактив) — списки шаблонов + редактор
  - **СМИ**: статус верификации, реклама (в разработке v2), ссылки на блог/донаты/историю
  - **Корпоративные** (подвкладки: Витрина, Расписание, Чат клиентов, Чат сотрудников, Реклама, Доп. чаты) — **открывается модалка `modal-corporate-settings`**
  - **Экспорт/импорт**: JSON/PDF/CSV экспорт, импорт настроек
  - **Удаление**: только при 0 участников (disabled)

## Модалки
- **`modal-corporate-settings`** — полная модалка настроек корпоративной группы:
  - Название корпоративной группы + привязка к отделу
  - Корпоративные правила (textarea)
  - Список адресов офисов (с кнопками редактировать/удалить) → подмодалка `modal-add-office`
  - Витрина товаров/услуг (список + кнопка добавить) → подмодалка `modal-add-product`
  - Настройка чатов (клиенты/сотрудники) → подмодалка `modal-add-chat`
  - Кнопки «Отмена» / «Сохранить»
- **`modal-add-office`** — добавить адрес офиса (название, адрес, расписание Пн-Пт, расписание Сб)
- **`modal-add-product`** — добавить товар/услугу (название, описание, тип, файл, статус активности)
- **`modal-add-chat`** — добавить чат (название, тип чата, админ)

## Дизайн-требования
- common.css, glassmorphism, темы
- Статистика — только чтение (opacity 0.7, pointer-events: none)
- Подвкладки с горизонтальным скроллом
- Badge «в разработке» для рекламных секций
- Модалки — backdrop-blur, полупрозрачный фон, фиксированная позиция top-right

## Компоненты
- `GroupSettingsSidebar` — 8 разделов с переключением
- `GroupHeader` — аватар, название, мета
- `GroupSettingsPanel` — обёртка для каждой вкладки
- `SubTabs` — подвкладки (текст/вложение/интерактив, витрина/расписание и т.д.)
- `TemplateEditor` — редактор шаблонов сообщений
- `CorpShowcase` — витрина товаров/услуг
- `ChatAdminAssign` — назначение администраторов/модераторов чатов
- `AdvertisingOrder` — заказ рекламы у платформы/каналов СМИ
- `CorporateSettingsModal` — модалка корпоративных настроек
- `AddOfficeModal` — подмодалка добавления офиса
- `AddProductModal` — подмодалка добавления товара
- `AddChatModal` — подмодалка добавления чата

## API
- `GET /api/v1/groups/:id` — данные группы
- `PATCH /api/v1/groups/:id` — обновление основных настроек
- `GET /api/v1/groups/:id/members` — список участников
- `PATCH /api/v1/groups/:id/members/:userId/role` — изменение роли
- `GET /api/v1/groups/:id/templates` — шаблоны сообщений
- `POST /api/v1/groups/:id/templates` — создание шаблона
- `PATCH /api/v1/groups/:id/templates/:id` — обновление шаблона
- `GET /api/v1/groups/:id/showcase` — витрина товаров
- `POST /api/v1/groups/:id/showcase` — добавить товар
- `GET /api/v1/groups/:id/schedule` — расписание офисов
- `PATCH /api/v1/groups/:id/schedule` — обновить расписание
- `POST /api/v1/groups/:id/schedule` — добавить офис
- `DELETE /api/v1/groups/:id/schedule/:officeId` — удалить офис
- `PATCH /api/v1/groups/:id/client-chat-admins` — админы чата клиентов
- `PATCH /api/v1/groups/:id/employee-chat-admins` — админы чата сотрудников
- `POST /api/v1/groups/:id/advertising` — заказ рекламы
- `GET /api/v1/groups/:id/additional-chats` — дополнительные чаты
- `POST /api/v1/groups/:id/export` — экспорт настроек
- `POST /api/v1/groups/:id/import` — импорт настроек
- `DELETE /api/v1/groups/:id` — удаление (только при 0 участников)

## WebSocket
- `group:updated` — настройки обновлены
- `group:member_role_changed` — роль изменена
- `group:template_created` — шаблон создан
- `group:showcase_updated` — витрина обновлена
- `group:schedule_updated` — расписание офисов обновлено
- `group:chat_admin_changed` — админ чата изменён

## Адаптивность
- Desktop: sidebar + content (двухпанельный), модалка top-right
- Mobile: список разделов → контент, подвкладки горизонтально скролятся, модалка на весь экран

## Технологии
- React 19 + Next.js
- Zustand: `groupStore` (group, members, roles, templates, showcase, schedule)
- Подвкладки реализованы через data-tab-group
- Модалки управляются через Zustand `modalStore`
