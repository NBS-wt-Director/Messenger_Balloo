# Задание: balloo.su — Правила

## Макет
`balloo-su/rules.html`

## Описание страницы
Страница с двумя вкладками: «Правила» (правила использования платформы) и «Политика неразглашения» (политика конфиденциальности). Контент обеих вкладок загружается из соответствующих Markdown-файлов в корне монорепо (`RULES.md` и `PRIVACY.md`). SSR для SEO. Доступна без авторизации.

> Текст в макете — демонстрационный. В реальном приложении контент берётся из md-файлов корня монорепо и рендерится через Markdown-парсер.

## Структура страницы

### Topbar
- Логотип Balloo с dropdown навигацией
- Заголовок «Правила»
- Маскот 🦊, язык, тема

### Content (narrow)
1. Заголовок «Правила» + подзаголовок «Редакция от 1 января 2026»
2. **Вкладки**: «Правила» / «Политика неразглашения»
3. **Tab «Правила»** (контент из `RULES.md`):
   - Карточки разделов: общие положения, запрещённый контент, приватность, обжалование бана, файлы и хранилище
4. **Tab «Политика неразглашения»** (контент из `PRIVACY.md`):
   - Карточки разделов: сбор данных, хранение сообщений, передача третьим лицам, удаление данных, файлы и вложения

## Функционал
- **Переключение вкладок** — табы «Правила» / «Политика неразглашения»
- **Просмотр контента** — Markdown-рендеринг из файлов корня монорепо
- **SSR** — для SEO и доступа без авторизации
- **Ссылка из регистрации** — чекбокс согласия → `rules.html`
- **Тот же шаблон** используется на всех платформах (mobile, desktop) — данные из тех же md-файлов

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Карточки разделов — glassmorphism
- Заголовки секций — section-title
- page-container
- Вкладки — tabs / tab / tab--active

## Компоненты
- `RulesPage` — страница с вкладками
- `RulesTabs` — переключатель вкладок «Правила» / «Политика неразглашения»
- `RulesSection` — карточка раздела (заголовок + текст)
- `MarkdownRenderer` — рендеринг Markdown-контента из файлов

## API
- `GET /api/v1/content/rules` — получение текста правил (из `RULES.md`, SSR)
- `GET /api/v1/content/privacy` — получение текста политики неразглашения (из `PRIVACY.md`, SSR)

## Источник данных
- `RULES.md` — файл в корне монорепо, содержит правила использования
- `PRIVACY.md` — файл в корне монорепо, содержит политику неразглашения
- Файлы единые для всех платформ (web, mobile, desktop)

## Адаптивность
- Desktop: page-container
- Mobile: полный экран

## Технологии
- React 19 + Next.js (SSR для SEO)
- Markdown-парсер (react-markdown / mdx)
- Файлы `RULES.md` и `PRIVACY.md` в корне монорепо
- Версионирование: редакция от даты
