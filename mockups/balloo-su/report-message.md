**ID:** `1_01_26`  
**Узел:** `у_01` — balloo.su  
**Файл макета:** `mockups/balloo-su/report-message.html`

## Описание

Форма подачи жалобы на конкретное сообщение. Открывается по клику на кнопку 🚩 в действиях сообщения. Показывает цитируемое сообщение, список причин жалобы, поле для комментария и экран успеха с ID жалобы.

## Структура

- **Заголовок панели** — кнопка «Назад», заголовок «🚩 Пожаловаться», кнопка «Закрыть»
- **Цитируемое сообщение** — аватар отправителя, имя, текст, дата/время; левая граница — красная (`--danger`)
- **Причины жалобы** — 7 категорий (radio-список):
  1. 📢 Спам / Реклама
  2. 🤬 Оскорбления / Травля
  3. 🔞 Неприемлемый контент
  4. ⚠️ Дезинформация
  5. 🔐 Нарушение приватности
  6. ⚖️ Нарушение закона
  7. 📋 Другое
- **Комментарий** — необязательное текстовое поле
- **Футер** — кнопки «Отмена» / «🚩 Отправить жалобу»
- **Экран успеха** — иконка ✅, текст подтверждения, ID жалобы

## Дизайн-требования

- Дизайн-система: `mockups/assets/common.css`
- Тема: dark (по умолчанию), light, russian
- Выбранная причина — зелёная рамка (`--accent`), radio-индикатор с галочкой
- Цитируемое сообщение — красная левая граница (`--danger`)
- Без border-radius (прямые углы)
- Акцент: `--accent: #2db84d`

## Компоненты (React)

| Компонент | Описание |
|---|---|
| `ReportMessagePanel` | Корневой компонент формы жалобы |
| `QuotedMessage` | Цитируемое сообщение с аватаром |
| `ReportReasonList` | Список причин с radio-выбором |
| `ReportReason` | Элемент причины (radio + title + desc) |
| `ReportComment` | Текстовое поле комментария |
| `ReportSuccess` | Экран успеха с ID жалобы |

## API

### REST

| Метод | Endpoint | Описание |
|---|---|---|
| `POST` | `/api/v1/reports` | Создать жалобу на сообщение |

**Тело запроса:**
```json
{
  "message_id": "string",
  "chat_id": "string",
  "reason": "spam|insults|adult_content|misinformation|privacy|illegal|other",
  "comment": "string (optional)"
}
```

**Ответ:**
```json
{
  "report_id": "RP-2026-0717-4281",
  "status": "pending",
  "estimated_review_time": "24h"
}
```

### WebSocket events

| Event | Направление | Описание |
|---|---|---|
| `report.status_changed` | server → client | Изменение статуса жалобы (рассмотрена, отклонена, принята) |
