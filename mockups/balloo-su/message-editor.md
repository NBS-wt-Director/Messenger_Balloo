# 1_01_32 — Редактор сообщения (reply/edit)

**ID:** `1_01_32`  
**Функция:** `0_01_05` — Отправка сообщений  
**Формат:** Модалка из чата  
**Файл:** `message-editor.html`

---

## Описание

Модалка редактирования и ответа на сообщения. Открывается по кнопке ✏ на любом сообщении (своём или чужом).

---

## Структура

### Top Bar
- Логотип Balloo + навигация по узлам
- Заголовок: «Редактор сообщения»
- Аватар пользователя + язык/тема

### Sidebar (список чатов)
- Поиск чатов
- Список чатов (активный выделен)
- 3 чата: Мария Андреева (активный), Команда разработки, Алексей Козлов

### Content (чат)
- Заголовок чата: аватар + имя + статус
- Кнопки: звонок, видеозвонок
- Сообщения с кнопкой редактирования ✏

### Modal (message-editor) — top-right modal

#### Header
- Заголовок: «✏️ Редактировать сообщение» или «↩ Ответить на сообщение»
- Кнопка закрытия ✕

#### Body
1. **Превью ответа** (только при reply) — показывает, на какое сообщение отвечаем
2. **Панель форматирования Markdown** — вкладки:
   - **B** — жирный (`**текст**`)
   - *I* — курсив (`_текст_`)
   - U — подчёркнутый (`__текст__`)
   - `</>` — код (`` `текст` ``)
   - 🔗 — ссылка (`[текст](url)`)
   - ❝ — цитата (`> текст`)
   - ☰ — список (`- пункт`)
3. **Textarea** для ввода/редактирования текста
4. **Кнопки**: 👁 Превью, 📎 Вложения
5. **Счётчик символов**: `0/4096`
6. **Превью** (скрыто по умолчанию) — показывает отформатированный текст
7. **История изменений** (если сообщение уже редактировалось) — показывает список правок с временем

#### Footer
- Отмена
- 🗑 Удалить (только для своих сообщений)
- 💾 Сохранить

## Дизайн-требования
- Модалка: backdrop-blur, полупрозрачный фон, border 2px
- Размер: 520px ширина
- Цвет статуса: info (синий)
- Markdown-панель: tabs с common.css
- Превью: background var(--bg-tertiary), border var(--border-color)

---

## Взаимодействия
- Кнопка ✏ на сообщении → openModal('modal-message-editor')
- Форматирование: toggleFormat() вставляет markdown-обёртки
- Превью: toggleEditorPreview() показывает/скрывает preview
- Сохранение: saveMessage() → closeModal() + showToast()
- Счётчик символов обновляется на input

---

## API (предполагаемые)
| Метод | Путь | Описание |
|---|---|---|
| PATCH | `/api/messages/{id}` | Редактировать сообщение |
| POST | `/api/messages/{id}/reply` | Ответить на сообщение |
| DELETE | `/api/messages/{id}` | Удалить сообщение |
| GET | `/api/messages/{id}/history` | История изменений |
