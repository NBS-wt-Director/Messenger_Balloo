# Задание: balloo.su — Регистрация

## Макет
`balloo-su/register.html`

## Описание страницы
Экран регистрации нового аккаунта. Поддерживает OAuth и email-регистрацию. Обязательно согласие с правилами и собственная капча. После нажатия «Зарегистрироваться» — шаг подтверждения по email (код). Автоаватар генерируется из имени (случайный градиент фона), пользователь может загрузить свою. Пароль поддерживает кириллицу.

## Структура страницы

### Topbar
- Логотип Balloo с dropdown навигацией
- Заголовок «Регистрация»
- Маскот 🦊, язык, тема

### Auth-card (центрированная)
1. Заголовок «Создать аккаунт» + подзаголовок
2. **OAuth-кнопки**:
   - Через Яндекс
   - Через Mail.ru
   - Через Rambler
3. Divider «или email»
4. **Форма регистрации**:
   - Имя
   - Автоаватар (превью октагона с инициалами из имени + случайный градиент фона, кнопка «Загрузить свою»)
   - Email
   - Пароль (минимум 8 символов, поддерживает латиницу, кириллицу, цифры, спецсимволы)
   - Чекбокс согласия с правилами и политикой конфиденциальности → `rules.html`
5. **Собственная капча** — картинка с кодом (генерируется на сервере), кнопка обновления, поле ввода
6. Кнопка «Зарегистрироваться» (primary, block)
7. **Шаг подтверждения email** (появляется после нажатия «Зарегистрироваться»):
   - Текст «На ваш email отправлен код подтверждения»
   - Поле ввода 6-значного кода (центрированное, monospace)
   - Кнопка «Подтвердить»
   - Ссылка «Отправить снова» (через 60 сек)
8. Ссылка «Уже есть аккаунт? Войти» → `login.html`

## Функционал
- **OAuth-регистрация** — редирект на провайдера, автовход
- **Email-регистрация** — валидация, создание аккаунта, отправка кода подтверждения на email
- **Подтверждение email** — ввод 6-значного кода, повторная отправка через 60 сек
- **Автоаватар** — генерация из имени (инициалы), случайный градиент фона; опциональная загрузка своей картинки
- **Согласие с правилами** — обязательно для регистрации
- **Собственная капча** — серверная генерация изображения с кодом, проверка на сервере
- **Вход** — переход на `login.html`

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Auth-card центрированная, glassmorphism
- Чекбокс согласия — с ссылкой на правила (accent)
- reCAPTCHA в карточке с padding

## Компоненты
- `AuthCard` — контейнер формы регистрации
- `OAuthButtons` — кнопки OAuth-провайдеров
- `RegisterForm` — форма (имя, аватар, email, пароль, согласие)
- `AutoAvatar` — превью автоаватара (инициалы + случайный градиент), кнопка загрузки
- `CaptchaWidget` — собственная капча (изображение с кодом, обновление, ввод)
- `EmailCodeStep` — шаг подтверждения email (поле кода, кнопка «Подтвердить», повторная отправка)

## API
- `POST /api/v1/auth/register` — регистрация по email (создание аккаунта, отправка кода на email)
- `POST /api/v1/auth/verify-email` — подтверждение email по коду
- `POST /api/v1/auth/resend-code` — повторная отправка кода (не чаще 1 раза в 60 сек)
- `GET /api/v1/auth/captcha` — получение изображения капчи (серверная генерация)
- `POST /api/v1/auth/captcha/verify` — проверка кода капчи
- `POST /api/v1/auth/avatar/auto` — генерация автоаватара (из имени, случайный градиент)
- `POST /api/v1/auth/avatar/upload` — загрузка своей аватарки (PNG/JPEG/SVG)
- `GET /api/v1/auth/oauth/:provider` — редирект на OAuth
- `GET /api/v1/auth/oauth/:provider/callback` — callback после OAuth

## Безопасность
- Пароль: минимум 8 символов, bcrypt/argon2, поддерживает кириллицу
- Собственная капча (серверная генерация, не reCAPTCHA)
- Подтверждение email — 6-значный код, TTL 10 мин
- Согласие с правилами — обязательно
- Rate limiting: 3 регистрации / час с IP

## Адаптивность
- Desktop: центрированная auth-card, max-width 440px
- Mobile: полный экран
