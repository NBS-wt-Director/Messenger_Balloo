# 1_01_37 — Настройки приватности (детальные)

**ID:** `1_01_37`  
**Функция:** `0_01_16` — Настройки приватности  
**Формат:** Модалка из настроек (отдельная страница с sidebar)  
**Файл:** `privacy-settings.html`

---

## Описание

Детальные настройки приватности: видимость профиля, безопасность, чёрный список, секретные чаты, история. 5 вкладок с переключением через sidebar.

---

## Структура

### Top Bar
- Логотип Balloo + навигация
- Заголовок: «Настройки приватности»
- Аватар + язык/тема

### Sidebar (навигация)
- 👁 Видимость
- 🔒 Безопасность
- 🚫 Чёрный список
- 🔐 Секретные чаты
- 📊 История

### Content (5 tab-панелей)

#### Tab 0: Видимость
- **Профиль**: кто видит профиль (все/только контакты/все кроме/только), кто видит номер, кто видит статус «в сети»
- **Сообщения**: кто может писать, кто добавляет в группы, кто видит seen, кто видит «печатает»
- **Данные**: история сообщений, Stories, индексация поисковиками
- **Ссылка-профиль**: @username, превью ссылки

#### Tab 1: Безопасность
- **E2EE**: секретные чаты (начать), обычные чаты (активно)
- **Автоудаление**: 1 день / 1 неделя / 1 месяц / 1 год / никогда
- **Входящие запросы**: только от контактов, подтверждение групп
- **2FA**: TOTP, резервные коды

#### Tab 2: Чёрный список
- Заблокированные пользователи (3 примера): аватар, имя, дата блокировки, кнопка «Разблокировать»
- Статистика: всего заблокировано, попыток написать
- Заблокированные каналы
- Информация о блокировке (что происходит)

#### Tab 3: Секретные чаты
- Описание E2EE
- Настройки: пересылка, скриншоты, саморазрушение (1сек/5сек/30сек/1мин/1день)
- Код безопасности (монospace шрифт)

#### Tab 4: История
- Хранение на сервере, автоудаление (30д/90д/180д/1г/никогда)
- Экспорт: JSON, TXT, PDF

## Дизайн-требования
- Sidebar: sidebar--narrow
- Content: page-container--narrow
- Чёрный список: avatar--ctx-blocked (background #000)
- 2FA QR: grid pattern placeholder

---

## Взаимодействия
- Переключение вкладок: switchPrivTab(index)
- Toggle privacy combo: togglePrivacyCombo(select, comboId) — показывает/скрывает search+checkboxes
- Разблокировка: unblockUser(name) → confirm → showToast
- Modal block user: openModal('modal-block-user')

---

## API (предполагаемые)
| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/settings/privacy` | Получить настройки приватности |
| PUT | `/api/settings/privacy` | Обновить настройки |
| POST | `/api/blocklist` | Заблокировать пользователя |
| DELETE | `/api/blocklist/{userId}` | Разблокировать |
| GET | `/api/chats/secret` | Список секретных чатов |
