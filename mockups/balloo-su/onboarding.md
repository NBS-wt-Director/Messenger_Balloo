# Задание: balloo.su — Онбординг

## Макет
`balloo-su/onboarding.html`

## Описание страницы
Приветственные экраны при первом запуске приложения. Шаги онбординга **не захардкожены** — они загружаются из БД через API и управляются через админку (раздел «Тексты» → «Онбординг»). Количество шагов не ограничено (по умолчанию 5). Каждый шаг: иллюстрация (PNG/SVG), заголовок, текст, поддержка локализации (6 языков). Кнопка «Пропустить» доступна на каждом шаге.

> Макет показывает 3 шага как демонстрацию визуала. В реальном приложении шаги приходят с сервера (`GET /api/v1/onboarding/steps?lang=ru`) — их может быть больше или меньше.

## Структура страницы

### Topbar
- Логотип Balloo с dropdown навигацией по узлам
- Заголовок «Онбординг» (клик → режим обучения)
- Маскот 🦊, язык, тема

### Onboarding (центрированный)
1. **Шаг 1** — «Добро пожаловать в Balloo!»
   - Иллюстрация 💬
   - Описание: кроссплатформенный мессенджер, групповые звонки, защита данных
   - 3 точки прогресса (активна первая)
   - Кнопки: «Пропустить» / «Далее →»
2. **Шаг 2** — «Звонки и группы»
   - Иллюстрация 📞
   - Аудио/видео до 30 человек, опросы, квизы, списки
   - Кнопки: «← Назад» / «Далее →»
3. **Шаг 3** — «Приватность и безопасность»
   - Иллюстрация 🔐
   - JWT-сессии, шифрование, 3 темы, мультиязычность, Yandex Disk
   - Кнопки: «← Назад» / «Начать →» (завершает онбординг)

### Tooltip (Learning Mode)
- Подсказка о клике по заголовку для включения режима обучения

## Функционал
- **Навигация** — кнопки «Далее» / «Назад» переключают шаги
- **Пропустить** — завершает онбординг, переход на `login.html`
- **Точки прогресса** — кликабельные, переход к конкретному шагу
- **Начать** — завершает онбординг, переход на `chats.html` (если авторизован) или `login.html`

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Центрированный layout, иллюстрации крупным эмодзи
- Точки прогресса — активная accent-цвет
- Кнопка «Пропустить» — tertiary, «Далее» — primary

## Компоненты
- `OnboardingStep` — карточка шага (иллюстрация, заголовок, текст, точки)
- `OnboardingProgress` — точки прогресса (кликабельные, количество = число шагов с сервера)
- `OnboardingButtons` — навигационные кнопки (Назад / Далее / Пропустить)

## API
- `GET /api/v1/onboarding/steps?lang=ru` — получить активные шаги онбординга на языке пользователя (публичный, кэшируется в Redis)
- `PATCH /api/v1/users/me/onboarding` — отметка о прохождении онбординга
- Управление шагами: через админку (см. `admin-balloo-su/texts.md`)

## Адаптивность
- Desktop: центрированный, max-width 480px
- Mobile: полный экран, крупный шрифт
- Desktop: показывается в окне приложения

## Технологии
- React 19 + Next.js
- Zustand: `onboardingStore` (currentStep, completed, skip)
- Локальное хранение: `localStorage` (флаг прохождения)
- Анимации: Framer Motion (переходы между шагами)
