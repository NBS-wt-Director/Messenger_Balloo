# 1_01_36 — Экран пустого чата

**ID:** `1_01_36`  
**Функция:** `0_01_05` — Отправка сообщений  
**Формат:** Состояние чата (empty state)  
**Файл:** `empty-chat.html`

---

## Описание

Экран отображается когда чат пуст (нет сообщений) или при первом открытии мессенджера. Содержит приветственное состояние, быстрые действия, сетку типов чатов, полезные ссылки.

---

## Структура

### Top Bar
- Логотип Balloo + навигация
- Заголовок: «Новый чат»
- Аватар + язык/тема

### Sidebar
- Поиск чатов
- Список чатов (2 чата: Мария, Команда)

### Content (empty-state)
- Центрированный empty-state по центру экрана

#### Mascot
- 🎈 (120px octagon, gradient accent)

#### Заголовок
- «Balloo Messenger»

#### Подзаголовок
- «Выберите чат из списка слева или начните новый разговор. Общайтесь, делитесь файлами и создавайте группы.»

#### Quick actions (кнопки)
- ✏️ Новый чат → openModal('modal-new-chat')
- 👥 Создать группу → group-create.html
- 📢 Создать канал → channel-create.html

#### Features grid (3 карточки)
- 💬 Личные — «Один на один»
- 👥 Группы — «До 200 000 участников»
- 📢 Каналы — «Неограниченные подписчики»

#### Полезные действия
- 🔍 Найти человека по номеру или @username
- 📷 Посмотреть сторис
- 📞 Посмотреть звонки
- 📨 Приглашения

---

## Modal: Новый чат
- Поиск человека

---

## Дизайн-требования
- empty-state: flex column, center align, padding 60px 24px
- Mascot: 120px octagon, gradient accent
- Features grid: 3 columns, card--hover
- Quick actions: flex gap 12px

---

## Взаимодействия
- ✏️ Новый чат → openModal('modal-new-chat')
- 👥 Создать группу → window.location.href = 'group-create.html'
- 📢 Создать канал → window.location.href = 'channel-create.html'
- Карточки features → те же переходы
- Полезные действия → навигация
