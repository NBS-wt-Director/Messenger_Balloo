# Создание опроса/квиза/списка (balloo-su/poll-editor.html)

## Описание
Оверлей из чата для создания интерактива одного из 5 типов: опрос, квиз, активный список, пассивный список, персонали. Открывается из поля ввода чата (кнопка «Интерактив» или slash-команды `/poll_`, `/quiz_`, `/list_active_`, `/list_passive_`, `/personali_`).

## Структура
- **Topbar**: логотип, заголовок «Создание опроса»
- **Main**: сайдбар (чат-лист, затемнённый) + контент (затемнённый чат + оверлей-карточка редактора)
- **PollEditor** (оверлей-карточка):
  - Tabs выбора типа (5 типов)
  - Поле «Вопрос / заголовок»
  - Список вариантов ответа (динамический, добавить/удалить)
  - Для квиза: выбор правильного ответа
  - Настройки: анонимность, множественный выбор, пересылка, срок действия

## Типы интерактивов
1. **poll** — опрос (голосование, можно несколько вариантов)
2. **quiz** — квиз (один правильный ответ)
3. **active_list** — активный список (отметка выполненных пунктов)
4. **passive_list** — пассивный список (просто список пунктов)
5. **personali** — персонали (выбор людей)

## Дизайн-требования
- Дизайн-система: common.css
- Оверлей с затемнением фона (rgba 0.55)
- Glassmorphism карточка редактора
- Темы: dark, light, russian

## Компоненты (React)
- `PollEditor` — форма создания опроса/квиза/списка (5 типов)

## API
- `POST /chats/:id/polls` — создать интерактив (type, question, options, settings)
- Поддерживаемые type: poll | quiz | active_list | passive_list | personali

## Адаптивность
- Desktop: оверлей по центру, max-width 520px
- Mobile: оверлей на всю ширину

## Технологии
- React 19 / Next.js 15
- Slash-команды обрабатываются в поле ввода чата
