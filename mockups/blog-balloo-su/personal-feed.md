# Задание: blog.balloo.su — Личные каналы

## Макет
`blog-balloo-su/personal-feed.html`

## Описание страницы
Отдельная лента для постов из **личных каналов сотрудников**. Посты из личных каналов НЕ выводятся в основную ленту (`feed.html`) — только сюда. Список личных каналов + последние статьи из них. SSR для SEO.

## Структура страницы

### Topbar
- Логотип 📝 Blog, заголовок «Личные каналы»

### Content (page-container)
1. **Заголовок** «Личные каналы сотрудников» + подзоловок
2. **Список личных каналов** — карточки: октагон-аватар, название, chip «Личный», описание, статистика
3. **Последние статьи** — карточки из всех личных каналов (с указанием канала)

## Функционал
- **Переход к каналу** — клик на карточку канала → `channel.html?slug=...`
- **Переход к статье** — клик на карточку статьи
- **SSR**

## Дизайн-требования
- Карточки каналов — горизонтальные, октагон-аватар с двойной рамкой
- Chip «Личный» — фиолетовый (`rgba(168,85,247,0.12)`, `#a855f7`)
- Аватары каналов — настраиваются владельцем (gradient + эмодзи)

## Компоненты
- `PersonalFeedPage` — страница личных каналов
- `PersonalChannelCard` — карточка личного канала
- `BlogPostCard` — карточка статьи (общий компонент)

## API
- `GET /api/blog/channels?type=personal` — список личных каналов
- `GET /api/blog/posts?type=personal` — последние статьи из личных каналов

## Адаптивность
- Desktop: page-container
- Mobile: полный экран

## Технологии
- React 19 + Next.js (SSR для SEO)
