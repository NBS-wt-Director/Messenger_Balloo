# Задание: blog.balloo.su — Лента блога

## Макет
`blog-balloo-su/feed.html`

## Описание страницы
Главная страница корпоративного блога. Лента статей из **корпоративных каналов** (посты из личных каналов сотрудников сюда НЕ выводятся — для них отдельный экран `personal-feed.html`). SSR для SEO.

## Структура страницы

### Topbar
- Логотип 📝 Blog (фиолетовый) с dropdown навигацией по экосистеме
- Заголовок «Корпоративный блог»
- Маскот/аватар, язык, тема (через common.js)

### Content (page-container)
1. **Заголовок** «Корпоративный блог» + подзаголовок
2. **Фильтр каналов** — chip-кнопки: Все каналы, Новости, Технологии, Команда, Метрики
3. **Закреплённый пост** (featured) — обложка, канал, заголовок, анонс, автор, дата, время чтения, счётчики (просмотры, реакции, комментарии)
4. **Карточки статей** — горизонтальные: миниатюра + канал + заголовок + анонс + автор + метрика
5. **Пагинация** — Назад / 1 / 2 / 3 / Вперёд

## Функционал
- **Фильтр по каналам** — переключение chip-фильтров (только корпоративные)
- **Переход к статье** — клик по карточке → `post.html?slug=...`
- **SSR** — лента рендерится на сервере для SEO
- **Пагинация** — по 10-15 статей на страницу

## Дизайн-требования
- Дизайн-система: `@balloo/shared` + `mockups/assets/common.css`
- Логотип: октагон, фон `#a855f7` (фиолетовый), иконка 📝
- Карточки — glassmorphism, card--hover
- Без border-radius (кроме switch/аватарок)
- Октагон-аватарки авторов

## Компоненты
- `BlogFeedPage` — страница ленты
- `BlogPostCard` — карточка статьи (горизонтальная)
- `BlogPostCardFeatured` — закреплённая карточка (с обложкой)
- `ChannelFilter` — фильтр по каналам (chips)

## API
- `GET /api/blog/posts` — лента статей (`?page`, `?channel`, `?type=corporate`)
- `GET /api/blog/channels` — список каналов для фильтра

## Адаптивность
- Desktop: page-container, карточки в один столбец
- Mobile: полный экран, карточки вертикально

## Технологии
- React 19 + Next.js (SSR для SEO)
- Markdown-рендер для анонсов
