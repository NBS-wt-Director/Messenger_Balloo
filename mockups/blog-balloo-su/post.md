# Задание: blog.balloo.su — Статья

## Макет
`blog-balloo-su/post.html`

## Описание страницы
Полный текст статьи блога. Markdown-рендер, обложка, автор, метаданные, реакции (эмодзи-бар, до 5), комментарии (дерево, вложенность), соседние/похожие статьи. SSR для SEO.

## Структура страницы

### Topbar
- Логотип 📝 Blog, заголовок «Статья»

### Content (page-container)
1. **Навигация** — ← Лента, ← Предыдущая / Следующая →
2. **Хлебные крошки** — канал → заголовок
3. **Обложка** — на всю ширину
4. **Заголовок + подзаголовок**
5. **Автор + мета** — аватар (→ публичный профиль), имя, должность, дата, время чтения, счётчики
6. **Тело статьи** — Markdown-рендер (заголовки, списки, цитаты, код)
7. **Теги** — chip-ссылки
8. **Реакции** — эмодзи-бар (👍❤️🚀🎉🔥), до 5 на пользователя
9. **Комментарии** — дерево, вложенные ответы, поле ввода
10. **Похожие статьи** — 2 карточки

## Функционал
- **Реакции** — авторизованный пользователь ставит до 5 эмодзи; гость видит, но не может реагировать
- **Комментарии** — авторизованный комментирует, отвечает (вложенность); гость видит
- **Удаление комментария** — автор удаляет свой
- **Переход к автору** — клик на аватар → публичный профиль
- **SSR** — статья рендерится на сервере

## Дизайн-требования
- Markdown-рендер с типографикой Balloo
- Цитаты — border-left accent
- Реакции — `message__reaction` стили
- Комментарии — отступы для вложенности

## Компоненты
- `BlogPostPage` — страница статьи
- `MarkdownRenderer` — рендер Markdown
- `ReactionBar` — бар реакций (эмодзи)
- `CommentTree` — дерево комментариев
- `CommentInput` — поле ввода комментария
- `RelatedPosts` — похожие статьи

## API
- `GET /api/blog/posts/:slug` — статья (SSR)
- `POST /api/blog/posts/:id/reactions` — поставить реакцию
- `DELETE /api/blog/posts/:id/reactions` — снять реакцию
- `GET /api/blog/posts/:id/comments` — дерево комментариев
- `POST /api/blog/posts/:id/comments` — добавить комментарий
- `POST /api/blog/comments/:id/reply` — ответ на комментарий
- `DELETE /api/blog/comments/:id` — удалить свой комментарий
- `GET /api/blog/posts/:id/related` — соседние/похожие статьи

## Адаптивность
- Desktop: page-container
- Mobile: полный экран, реакции wrap

## Технологии
- React 19 + Next.js (SSR для SEO)
- Markdown-рендер (react-markdown)
