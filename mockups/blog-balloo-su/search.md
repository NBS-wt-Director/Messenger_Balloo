# Задание: blog.balloo.su — Поиск

## Макет
`blog-balloo-su/search.html`

## Описание страницы
Поиск по статьям блога. Работает **per-channel** — пользователь выбирает канал (или «Все каналы») и ищет в его рамках. Подсветка совпадений в результатах.

## Структура страницы

### Topbar
- Логотип 📝 Blog, заголовок «Поиск»

### Content (page-container)
1. **Поисковый input** — крупный, с текущим запросом
2. **Выбор канала** — chips: Все каналы, Новости, Технологии, Команда (per-channel)
3. **Счётчик результатов**
4. **Результаты** — карточки с подсветкой `<mark>` совпадений
5. **Empty state** — «Ничего не найдено» (скрыт, показывается при 0 результатов)

## Функционал
- **Per-channel поиск** — выбор канала ограничивает поиск
- **Подсветка** — совпадения в заголовке и анонсе подсвечиваются
- **Переход к статье** — клик по результату

## Дизайн-требования
- `<mark>` — фон `rgba(168,85,247,0.25)` (фиолетовый)
- Карточки — горизонтальные, компактные

## Компоненты
- `BlogSearchPage` — страница поиска
- `SearchResultCard` — карточка результата с подсветкой
- `ChannelScopeSelector` — выбор канала для поиска

## API
- `GET /api/blog/search?q=&channel=` — поиск (per-channel)

## Адаптивность
- Desktop: page-container
- Mobile: полный экран

## Технологии
- React 19 + Next.js
- Debounce на поиск (300ms)
