# Задание: blog.balloo.su — Категория

## Макет
`blog-balloo-su/category.html`

## Описание страницы
Лента статей отфильтрованная по одной категории. Заголовок категории, описание, статистика, карточки статей. SSR для SEO.

## Структура страницы

### Topbar
- Логотип 📝 Blog, заголовок «Категория»

### Content (page-container)
1. **← Лента** — возврат
2. **Заголовок категории** — иконка, название, описание, статистика (статей, просмотров)
3. **Карточки статей** — горизонтальные, с указанием канала
4. **Пагинация**

## Функционал
- **Переход к статье** — клик по карточке
- **Переход к каналу** — клик на chip канала
- **SSR**

## Дизайн-требования
- Карточки — glassmorphism, card--hover
- Chip канала на каждой карточке

## Компоненты
- `CategoryPage` — страница категории
- `BlogPostCard` — карточка статьи (общий компонент)

## API
- `GET /api/blog/categories/:slug` — категория + статьи (SSR)

## Адаптивность
- Desktop: page-container
- Mobile: полный экран

## Технологии
- React 19 + Next.js (SSR для SEO)
