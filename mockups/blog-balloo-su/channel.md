# Задание: blog.balloo.su — Канал

## Макет
`blog-balloo-su/channel.html`

## Описание страницы
Страница канала (корпоративного или личного). Баннер, аватар, описание, тип канала, статистика, лента статей канала, поиск по каналу. SSR для SEO.

## Структура страницы

### Topbar
- Логотип 📝 Blog, заголовок «Канал»

### Content (page-container)
1. **← Все каналы** — возврат к ленте
2. **Заголовок канала** — баннер (gradient), октагон-аватар, название, тип (корпоративный/личный), описание, статистика (статей, просмотров, реакций)
3. **Поиск по каналу** — input
4. **Лента статей канала** — карточки (горизонтальные)
5. **Пагинация**

## Функционал
- **Поиск по каналу** — отдельный экран поиска с `?channel=slug`
- **Переход к статье** — клик по карточке
- **SSR** — канал и статьи рендерятся на сервере

## Дизайн-требования
- Баннер канала — gradient (для личных — настраивается владельцем)
- Октагон-аватар канала с двойной рамкой
- Тип канала: chip (корпоративный = accent, личный = фиолетовый)

## Компоненты
- `ChannelPage` — страница канала
- `ChannelHeader` — баннер + аватар + описание + статистика
- `BlogPostCard` — карточка статьи (общий компонент)

## API
- `GET /api/blog/channels/:slug` — канал + статьи (SSR)
- `GET /api/blog/search?q=&channel=` — поиск по каналу

## Адаптивность
- Desktop: page-container
- Mobile: полный экран

## Технологии
- React 19 + Next.js (SSR для SEO)
