# Задание: download.balloo.su — Страница загрузок

## Макет
`download-balloo-su/downloads.html`

## Описание страницы
Страница загрузки приложения Balloo для всех платформ с определением платформы пользователя, адаптивным расположением плиток и QR-кодом.

## Структура страницы

### Topbar
- Логотип Download (иконка D на info-цвете)
- Dropdown навигации по узлам
- Переключатели языка и темы

### Content (max-width 960px)

1. **Заголовок** «⬇️ Скачать Balloo» + версия и дата

2. **Определение платформы пользователя** (новый элемент 15.10.2026):
   - Баннер над плитками: «Вы используете: <strong>Windows</strong>»
   - Определяется по User-Agent
   - Возможные значения: Windows, macOS, Linux, Android, iOS, браузер (PWA-совместим)

3. **Секция «Для компьютера»**:
   - **Главная плитка** (увеличенная, с рамкой `var(--accent)` и меткой «✓ Ваша платформа»)
     - Определяется по UA: Windows / macOS / Linux
     - Содержит: иконка 64px, название 24px, формат, кнопка скачивания, SHA256
     - **Инструкция по установке** внизу плитки (нумерованный список)
   - **Боковая колонка** (справа, вертикально):
     - Остальные платформы десктопа (если главная — Windows, то справа Linux + macOS)
     - Каждая плитка: иконка 32px, название, кнопка
     - Рамка `var(--border)`
   - **PWA-плитка** в боковой колонке (синяя рамка `var(--info)`)

4. **Секция «Для телефона»**:
   - **Главная плитка** (аналогично десктопу):
     - Определяется по UA: Android / iOS
     - Android: полная плитка с кнопкой APK, ссылками Google Play/RuStore, инструкцией
     - iOS: **грустная извиняющаяся плитка** (см. ниже)
   - **Боковая колонка**:
     - iOS: если главная Android — и наоборот
     - PWA-плитка

5. **Платформа без скомпилированного образа** (новый элемент 15.10.2026):
   - Стилизована пунктирной рамкой `var(--warning)` или красной `var(--error)` для Apple
   - Иконка приглушена (`filter: grayscale(0.5)`)
   - Текст-извинение:
     - **Общий текст:** «Мы стараемся сделать приложение под вашу платформу максимально быстро и качественно для удобства пользователей. А пока вам доступно PWA — полнофункциональное веб-приложение, которое работает точно так же, как нативное.»
     - **Apple (iOS/macOS):** «Мы — российская компания и осознанно выбрали путь PWA на продукции корпорации Apple до тех пор, пока они не прекратят несправедливо баннить российское ПО и не возместят экономике РФ потерянные из-за их политики деньги. Мы приносим наши искренние извинения за эти неудобства. PWA имеет точно такие же функции, как нативное приложение. А когда мы введём внутриприложение транзакции, наш пользователь получит извинительный бонус за неудобства и за то, что ему приходится страдать на этой платформе.»

6. **Секция QR-код**:
   - QR-код для перехода на download.balloo.su
   - Октагон-логотип Balloo в центре QR

7. **Системные требования** (таблица: платформа/ОС/ОЗУ/диск)

8. **Ссылка** на историю версий

|---|---|---|---|
| Windows | .msi | 82 МБ | Win 10 (x64) |
| Linux | .AppImage / .deb / .rpm | 76 МБ | Ubuntu 20.04+ |

| Android | .apk | 48 МБ | Android 8.0+ |
| iOS | App Store | — | iOS 14+ |

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- **Платформа пользователя** — увеличенная карточка с акцентной рамкой и меткой «✓ Ваша платформа»
- **Боковая колонка** — остальные платформы столбиком, рамка `var(--border)`
- **Инструкции по установке** — внизу главной карточки, нумерованный список
- **PWA-плитка** — в обоих разделах (desktop и mobile), синяя рамка `var(--info)`
- **Платформа без образа** — грустная карточка (пунктирная рамка, приглушённая иконка, текст-извинение)
- **Apple-карточка** — красная рамка, курсив, особый текст про российскую компанию
- QR-код с октагон-логотипом Balloo в центре
- Таблица системных требований

## Компоненты
- `PlatformDetector` — баннер определения платформы пользователя по UA
- `PlatformCard` — карточка платформы с кнопкой загрузки
  - variants: `main` (увеличенная, акцентная рамка), `side` (боковая, обычная рамка), `sad` (грустная), `apple-sad` (Apple-извинение)
- `InstallInstructions` — блок инструкций по установке
- `QRCode` — QR-код с логотипом
- `SystemRequirementsTable` — таблица требований
- `DownloadButton` — кнопка загрузки с размером и хешем

## Технические требования
- **Автоопределение ОС пользователя** (User-Agent detection) — подсветка нужной платформы
  - Windows, macOS, Linux → десктопная секция
  - Android, iOS → мобильная секция
  - Остальные → PWA как главная
- **Адаптивное расположение**: главная карточка + боковая колонка
- **PWA-плитка** в обоих разделах
- **Прямые ссылки на CDN** для загрузки
- **SHA256-чексуммы** для проверки целостности
- **PWA-манифест** для установки из браузера
- **RuStore и Google Play** deep links для Android
