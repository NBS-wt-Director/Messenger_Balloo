# Задание: specifity.balloo.su — Правила проектирования и разработки

## Макет
`specifity-balloo-su/rules.html`

## Описание страницы
Сводка единых правил монорепо: порядок проектирования функциональности, система нумерации `z_xx_yy`, жизненный цикл проекта (4 фазы), порядок обработки замечаний по макетам, дизайн-система (краткая справка), статусы реализации. Источник правил — `AGENTS.md`.

## Структура страницы

### Topbar
- Логотип Specifity + dropdown узлов
- Заголовок: «Правила проектирования и разработки»
- Переключатели языка и темы

### Sidebar (240px)
- Навигация по разделам specifity (активная — Правила)

### Content
1. **Заголовок экрана** — ID `1_10_03`
2. **Порядок проектирования** — нумерованный список из 6 шагов (функция → узел → ситуация → экраны → эндпоинты+компоненты → сущности)
3. **Система нумерации** — таблица префиксов (`у`, `0`, `1`, `2`, `3`, `4`) + правила (узел 00, независимость, неизменность ID)
4. **Жизненный цикл** — таблица 4 фаз с описанием
5. **Порядок обработки замечаний** — нумерованный список из 6 шагов (макет → MD → index.html → index_ecrans.md → index_ecrans.json → docs/)
6. **Дизайн-система** — таблица принципов (аватарки, пузыри, темы, glassmorphism, border-radius, шрифт, акцент, языки)
7. **Статусы реализации** — таблица статусов

## Дизайн-требования
- Дизайн-система: `@balloo/shared` + `spec.css`
- Нумерованные правила — карточки с счётчиком (`counter-reset`)
- Таблицы — `.spec-table` (без border-radius, hover-строки)
- Темы: dark, light, russian

## Компоненты
- `SpecSidebar` — общий (shared layout)
- `SpecPageHead` — заголовок экрана
- `SpecRuleList` / `SpecRule` — нумерованный список правил (карточка + счётчик)
- `SpecTable` — таблица с типизированными колонками

## API
- `GET /api/v1/specifity/rules` — текст правил и таблицы (контент из `AGENTS.md`, парсится при сборке)
- Контент статичен, генерируется SSG из `AGENTS.md`

## Адаптивность / мобильные взаимодействия
- Десктоп: sidebar 240px + content
- Планшет: sidebar → drawer
- Мобильный: таблицы горизонтально-скроллируемые, правила в одну колонку

## Технологии
- Next.js 14 + TypeScript (SSG)
- Парсинг `AGENTS.md` → статический контент при сборке
- Общий `SpecSidebar` (shared layout узла)
