# Задание: specifity.balloo.su — Экраны (каталог по узлам)

## Макет
`specifity-balloo-su/screens.html`

## Описание страницы
Полный каталог экранов монорепо, сгруппированный по узлам. Каждый экран — ID `1_xx_yy`, название, файл макета, статус. Раскрываемые группы по узлам, фильтр по узлам. Клик по экрану открывает split-view спецификацию (`1_10_01`). Полный список генерируется из `index_ecrans.json`.

## Структура страницы

### Topbar
- Логотип Specifity + dropdown узлов
- Заголовок: «Экраны · каталог по узлам»
- Переключатели языка и темы

### Sidebar (240px)
- Навигация по разделам specifity (активная — Экраны, счётчик 110)

### Content
1. **Заголовок экрана** — ID `1_10_04`
2. **Фильтры по узлам** — chip-фильтры (Все 110, shared 8, balloo 26, ...)
3. **Раскрываемые группы по узлам** (`<details>`) — для каждой:
   - Summary: иконка, название узла, кол-во экранов, ID узла
   - Таблица: ID, Экран, Файл, Статус
   - Для узлов с большим кол-вом — примеры + ссылка «полный список в index_ecrans.md»
4. **Подвал** — ссылка на `index_ecrans.md` / `index_ecrans.json`

## Дизайн-требования
- Дизайн-система: `@balloo/shared` + `spec.css`
- Группы — `<details>` с glass-заголовком
- Таблицы — `.spec-table`
- Статусы — цветные chip (`спроектирован`, `принят` = accent)
- Темы: dark, light, russian

## Компоненты
- `SpecSidebar` — общий
- `SpecPageHead` — заголовок
- `SpecFilterBar` / `SpecFilter` — chip-фильтры по узлам
- `SpecScreensGroup` — раскрываемая группа узла (summary + таблица)
- `SpecScreenRow` — строка экрана (ID, название, файл, статус)

## API
- `GET /api/v1/specifity/screens` — список всех экранов (ID, название, путь к макету, узел, статус, описание)
- `GET /api/v1/specifity/nodes/:id/screens` — экраны конкретного узла
- Клик по экрану → переход на `specification.html?id=1_xx_yy` (split-view)
- Данные из `index_ecrans.json`, SSG

## Адаптивность / мобильные взаимодействия
- Десктоп: sidebar + раскрываемые группы
- Планшет/мобильный: таблицы горизонтально-скроллируемые, фильтры в строку с переносом

## Технологии
- Next.js 14 + TypeScript (SSG)
- Данные из `index_ecrans.json`
- Общий `SpecSidebar` (shared layout)
