# Задание: specifity.balloo.su — Главная · обзор монорепо

## Макет
`specifity-balloo-su/home.html`

## Описание страницы
Входной экран (домашний) узла specifity. Обзор структуры монорепо Balloo: категории объектов, узлы экосистемы, ключевые метрики, структура каталогов и фазы жизненного цикла. Отсюда осуществляется навигация во все остальные разделы спецификации (Правила, Экраны, Эндпоинты, Данные, Компоненты, Спецификация экрана).

## Структура страницы

### Topbar
- Логотип Specifity (иконка S на accent-цвете) + dropdown узлов экосистемы
- Заголовок: «Главная · обзор монорепо»
- Переключатели языка и темы

### Sidebar (240px) — навигация по разделам specifity
- Поиск по спецификации
- Разделы: Главная (активная), Правила, Экраны (110), Эндпоинты, Данные (75), Компоненты (241)
- Divider
- Спецификация экрана (split-view инструмент, `1_10_01`)

### Content
1. **Заголовок экрана** — ID `1_10_02`, название, описание
2. **Метрики** — 12 узлов, 110 экранов, 75 таблиц, 241 компонент, 3 темы, 6 языков
3. **Категории объектов** — 6 карточек: Узлы (у), Функции (0), Экраны (1), Эндпоинты (2), Данные (3), Компоненты (4)
4. **Узлы экосистемы** — 12 карточек: иконка, ID узла, название, кол-во экранов, описание, тег
5. **Структура монорепо** — дерево каталогов (balloo/, docs/, mockups/, packages/, docker/)
6. **Жизненный цикл** — 4 фазы + текущая (Фаза 1)

## Дизайн-требования
- Дизайн-система: `@balloo/shared` + `spec.css` (локальный)
- Glassmorphism на карточках (`backdrop-filter: blur()`)
- Без border-radius — прямые углы везде
- Темы: dark (по умолчанию), light, russian
- Шрифт: Inter / Manrope; код — JetBrains Mono / Fira Code
- Иконки узлов — в октагон-клипе (`--octagon-clip`)

## Компоненты
- `SpecSidebar` — боковая навигация по разделам specifity (общий для всех экранов узла)
- `SpecPageHead` — заголовок экрана (ID, h1, описание)
- `SpecStatRow` / `SpecStat` — строка метрик
- `SpecNodeCard` — карточка узла/категории (иконка, ID, заголовок, описание, теги)
- `SpecCodeTree` — блок с деревом каталогов (моноширинный)

## API
- `GET /api/v1/specifity/overview` — сводка монорепо (счётчики узлов/экранов/таблиц/компонентов, текущая фаза)
- `GET /api/v1/specifity/nodes` — список узлов (ID, иконка, название, кол-во экранов, статус, описание)
- Данные генерируются из `index_ecrans.*` на этапе сборки (SSG)

## Адаптивность / мобильные взаимодействия
- Десктоп: sidebar 240px + content
- Планшет: sidebar сворачивается в drawer (гамбургер)
- Мобильный: карточки 1 в ряд, sidebar — drawer overlay

## Технологии
- Next.js 14 (App Router) + TypeScript — SSG для метаданных
- Данные спецификации из `index_ecrans.json` (генерация статических метаданных при сборке)
- Общий `SpecSidebar` для всех экранов узла (shared layout)
