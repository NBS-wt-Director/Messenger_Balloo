# Задание: specifity.balloo.su — Спецификация экрана (split-view)

## Макет
`specifity-balloo-su/specification.html`

## Описание страницы
Один из 7 экранов узла specifity (`1_10_01`). Split-view инструмент для разработки: слева — спецификация выбранного экрана (описание, ID, связанные объекты: API-эндпоинты, таблицы БД, компоненты, технологии), справа — превью макета в `iframe` с изменяемыми размерами (тест адаптивности). Выбор экрана через выпадающий список в тулбаре. Остальные экраны узла: Главная (`1_10_02`), Правила (`1_10_03`), Экраны (`1_10_04`), Эндпоинты (`1_10_05`), Данные (`1_10_06`), Компоненты (`1_10_07`).

## Структура страницы

### Topbar
- Логотип Specifity (иконка S на accent-цвете)
- Dropdown навигации по узлам
- Переключатели языка и темы

### Split-view (основная область)

#### Левая панель — спецификация (380px, resizable)
1. **Заголовок экрана** — название (например «Чаты»)
2. **ID экрана** — `ID: 1_01_04 · узел у_01 (balloo.su)`
3. **Описание** — текстовое описание экрана
4. **Связанные объекты** — список с типизированными бейджами:
   - `API` — эндпоинты REST и WebSocket events
   - `Data` — таблицы базы данных
   - `Comp` — React-компоненты
   - `Screen` — ссылка на макет
5. **Технологии** — стек реализации экрана

#### Правая панель — превью (flex: 1)
1. **Тулбар**:
   - Выпадающий список выбора экрана (из всех узлов)
   - Кнопки изменения размера: ◀ ▶ ⟳ ⛶
   - Индикатор текущего размера (100% × 100%)
2. **iframe-область** — превью выбранного макета
3. **Resize-ручка** — угол ◢ для перетаскивания мышью

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Glassmorphism на левой панели (`backdrop-filter: blur()`)
- Без border-radius — прямые углы везде
- Темы: dark (по умолчанию), light, russian
- Шрифт: Inter / Manrope
- Цвета бейджей связанных объектов:
  - API — info (синий)
  - Data — warning (жёлтый)
  - Comp — accent (зелёный)
  - Screen — фиолетовый

## Компоненты
- `SpecSplitView` — контейнер split-view (левая + правая панель)
- `SpecLeftPanel` — панель спецификации (заголовок, ID, описание, связанные объекты, технологии)
- `SpecLinkedItem` — элемент связанного объекта с типизированным бейджем
- `SpecToolbar` — тулбар правой панели (селектор экрана, кнопки resize, индикатор размера)
- `SpecFramePreview` — iframe-превью с resize-ручкой
- `SpecResizeHandle` — угол для перетаскивания мышью

## API
- `GET /api/v1/specifity/screens` — список всех экранов для селектора (ID, название, путь к макету, описание, связанные объекты)
- `GET /api/v1/specifity/screens/:id` — полная спецификация экрана (описание, связанные API, таблицы БД, компоненты, технологии)
- Данные статичны на этапе проектирования, в продакшене генерируются из метаданных

## Адаптивность / мобильные взаимодействия
- На десктопе: split-view 380px + flex (как в макете)
- На планшете: левая панель сворачивается в drawer (кнопка-гамбургер)
- На мобильном: табы — «Спецификация» / «Превью» (переключение между панелями)
- Resize-ручка работает только на десктопе (touch не поддерживается)

## Технологии
- React 18 + TypeScript
- iframe для превью макетов (sandbox)
- Mouse events для resize (mousemove + mouseup)
- localStorage для сохранения последнего выбранного экрана и размера
- Данные спецификации из `index_ecrans.json` (генерация статических метаданных)
