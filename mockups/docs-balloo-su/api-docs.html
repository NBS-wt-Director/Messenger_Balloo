🔐 Аутентификация
POST /auth/login

Аутентификация пользователя по email и паролю. Возвращает access и refresh токены.

REQUEST BODY
{
  "email": "user@example.com",
  "password": "secret123"
}
RESPONSE 200
{
  "accessToken": "eyJhbG...",
  "refreshToken": "dGhpcyB...",
  "user": {
    "id": "usr_abc123",
    "email": "user@example.com",
    "name": "Иван Иванов"
  }
}
💬 Сообщения
GET /messages?chatId=:id&limit=50&before=:msgId

Получить сообщения чата с пагинацией. Поддерживает cursor-based pagination через параметр before.

QUERY PARAMETERS
ПараметрТипОбяз.Описание
chatIdstring✅ID чата
limitnumber❌Лимит (по умолч. 50, макс. 200)
beforestring❌ID сообщения для пагинации
🔌 WebSocket Events
WS wss://balloo.su/ws

Постоянное соединение для realtime-обновлений. Авторизация через query-параметр ?token=.

CLIENT → SERVER
EventPayloadОписание
message:send{ chatId, text, attachments? }Отправить сообщение
typing:start{ chatId }Начал печатать
typing:stop{ chatId }Перестал печатать
presence:update{ status }Обновить статус
reaction:add{ msgId, emoji }Добавить реакцию
SERVER → CLIENT
EventPayloadОписание
message:new{ id, chatId, author, text, ... }Новое сообщение
message:edit{ id, text, editedAt }Сообщение изменено
message:delete{ id }Сообщение удалено
presence:update{ userId, status }Статус пользователя
call:incoming{ callId, caller, type }Входящий звонок
