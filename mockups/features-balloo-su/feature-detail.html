В работе Звонки Приоритет: высокий

Групповые видеозвонки до 12 человек

Предложил Иван Иванов · 12 июня 2026
Описание

Видео-конференции внутри Balloo с поддержкой до 12 одновременных участников. Сетка участников с автоматическим переключением на активного диктора (active speaker). Встроенное шумоподавление на основе WebRTC. Режим низкой пропускной способности для стабильной работы при слабом интернете. Поддержка демонстрации экрана с выбором окна/вкладки.

Мотивация

Текущие звонки поддерживают только 1:1. Для групповых чатов не хватает возможности быстро начать видеоконференцию. Конкуренты (Telegram, WhatsApp) уже имеют эту функцию.

Планируемая реализация
  • WebRTC mesh для ≤4 участников, SFU для 5–12
  • Сетка 3×4 с автосворачиванием неработающих камер
  • Шумоподавление через RNNoise (WASM)
  • Low bandwidth mode: только аудио + скриншоты каждые 2с
  • Интеграция с существующим call-overlay
