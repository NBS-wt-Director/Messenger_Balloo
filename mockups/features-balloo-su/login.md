# Задание: features.balloo.su — Вход

## Макет
`features-balloo-su/login.html`

## Описание страницы
Экран входа на портал фич-реквестов. OAuth + email/пароль + вход через другое устройство (QR). Голосование возможно без входа, но голоса не сохраняются.

## Структура страницы

### Topbar
- Логотип Features (иконка F на accent-цвете)
- Заголовок «Вход»

### Auth-card
1. Иконка-октагон F
2. Заголовок «Портал фич-реквестов»
3. Подзаголовок «Войдите, чтобы голосовать и предлагать функции»
4. OAuth: Яндекс / Mail.ru / Rambler
5. Email + пароль
6. Кнопка «Войти» (accent-цвет)
7. **Вход через другое устройство (QR)**
   - Единый аккаунт Balloo для всех узлов
8. Ссылка «Зарегистрироваться»
9. Примечание: можно голосовать без входа, но голоса не сохранятся

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Стандартная auth-card (без цветного border)
- Кнопка входа — accent-цвет
- OAuth кнопки с цветными логотипами

## Компоненты
- `FeaturesLoginForm` — форма входа
- `OAuthButtons` — OAuth кнопки
- `QRLoginButton` — кнопка входа через QR
- `GuestVotingNotice` — уведомление о гостевом голосовании

## API
- `POST /api/v1/auth/login` — вход (общий endpoint)
- `POST /api/v1/auth/oauth/:provider` — OAuth
- `POST /api/v1/devices/pair-token` — QR-токен
- `POST /api/v1/features/:id/vote` — голосование (требует auth для сохранения)

## Особенности
- Единый аккаунт Balloo для всех узлов (SSO)
- Гостевое голосование: анонимные голоса в памяти, не сохраняются
- При входе — синхронизация гостевых голосов с аккаунтом
