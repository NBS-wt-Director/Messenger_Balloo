# Донат (features-balloo-su/donate.html)

## Описание
Страница доната на узле фич-реквестов. Контекст: пользователь голосует за фичи и может поддержать разработку.

## Структура
- **Topbar**: логотип Features, заголовок «Поддержать проект»
- **Content**: hero, прогресс цели, уровни поддержки, способы оплаты, ссылка на list.html

## API
- Единое API для всех узлов

## Технологии
- React 19 / Next.js 15 (SSR)
