# Задание: features.balloo.su — Список фич

## Макет
`features-balloo-su/list.html`

## Описание страницы
Страница списка фич-реквестов с голосованием, фильтрацией по категориям и статусам.

## Структура страницы

### Topbar
- Логотип «Features» (иконка F на зелёном фоне)
- Dropdown-меню навигации по узлам монорепо
- Аватар пользователя, переключатель языка, переключатель темы

### Sidebar (узкая, 240px)
- Поиск по фичам
- Фильтры: Все фичи / Готово / В работе / Запланировано / Идеи
- Сортировки: Топ голосов / Обсуждаемые / Свежие
- Бейджи с количеством в каждой категории

### Content
1. **Заголовок** «Фич-реквесты» + подзаголовок
2. **Табы категорий**: Все / Мессенджер / Звонки / Группы / UI/UX / Боты
3. **Карточки статистики** (4 шт.): Всего фич / Готово / В работе / Голосов всего
4. **Список фич** — карточки с:
   - Кнопка голосования (▲) и счётчик голосов
   - Статус (chip: готово/в работе/запланировано/идея)
   - Категория (chip)
   - Заголовок и описание
   - Количество комментариев и дата обновления
   - Клик по карточке → переход на `feature-detail.html`
5. **Кнопка** «💡 Предложить новую фичу» → `submit.html`

## Дизайн-требования
- Дизайн-система: `@balloo/shared` (common.css)
- Glassmorphism карточки с blur
- Темы: dark (по умолчанию), light, russian
- Шрифт: Inter / Manrope
- Цвет акцента: `--accent` (#2db84d)
- Без скруглений углов (кроме аватарок-октагонов)

## Компоненты
- `FeatureCard` — карточка фичи с голосованием
- `CategoryTabs` — табы категорий
- `StatsGrid` — сетка статистики
- `FilterSidebar` — боковая панель фильтров

## API
- `GET /api/v1/features?category=&status=&sort=` — список фич
- `POST /api/v1/features/:id/vote` — голосование
- `GET /api/v1/features/stats` — статистика

## Адаптивность
- Desktop: sidebar + content
- Mobile: sidebar сворачивается в drawer, табы скроллятся горизонтально
