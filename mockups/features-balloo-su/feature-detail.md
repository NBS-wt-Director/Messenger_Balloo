# Задание: features.balloo.su — Детали фичи

## Макет
`features-balloo-su/feature-detail.html`

## Описание страницы
Страница детального просмотра фич-реквеста с описанием, голосованием, комментариями.

## Структура страницы

### Topbar
- Логотип Features, кнопка «Назад» к списку

### Content (single column, max-width 960px)
1. **Ссылка** «← Назад к списку»
2. **Карточка фичи**:
   - Кнопка голосования (▲) крупная + счётчик (74)
   - Статус (chip), категория (chip), приоритет (chip)
   - Заголовок фичи (h1)
   - Автор и дата предложения
   - Кнопка «▲ Голосовать» (крупная, справа)
   - Описание (текст)
   - Мотивация (текст)
   - Планируемая реализация (список)
   - Метаданные: статус, команда, версия, срок
3. **Карточка комментариев** (18 шт.):
   - Список комментариев с аватарами, именами, датами
   - Вложенные ответы (отступ слева)
   - Кнопки ▲ и «Ответить» на каждом комментарии
   - Поле ввода нового комментария + кнопка «Отправить»

## Дизайн-требования
- Дизайн-система: `@balloo/shared`
- Аватарки-октагоны с двойной рамкой
- Chip-метки статусов: accent (готово), info (в работе), warning (запланировано), default (идея)
- Автор фичи помечается chip «автор»

## Компоненты
- `FeatureHeader` — заголовок с голосованием
- `FeatureDescription` — описание с секциями
- `CommentThread` — дерево комментариев
- `CommentInput` — поле ввода комментария

## API
- `GET /api/v1/features/:id` — детали фичи
- `POST /api/v1/features/:id/vote` — голосование
- `GET /api/v1/features/:id/comments` — комментарии
- `POST /api/v1/features/:id/comments` — добавить комментарий
- `POST /api/v1/comments/:id/vote` — голос за комментарий
