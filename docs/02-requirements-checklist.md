# 📋 Чек-лист требований к мессенджеру Balloo (150 вопросов)

Данный документ содержит 150 вопросов по всем аспектам продукта: от страниц и дизайна до безопасности и звонков. 
Для уже принятых решений добавлен тег `[ОТВЕЧЕНО]` с кратким итогом. Для остальных вопросов предложены варианты ответов.

## 📑 1. Дополнительные страницы (15 вопросов)

### 1. Онбординг (Welcome screens)
При первом входе показывать экраны с описанием возможностей перед входом?

- [ ] Да, но без возможности пропуска

> **Решение:** Шаги онбординга хранятся в БД (`OnboardingStep` + `OnboardingStepTranslation`), управляются через админку (раздел «Тексты»). Количество не ограничено. Иллюстрации — PNG/SVG в MinIO. Локализация — 6 языков. Кнопка «Пропустить» доступна на каждом шаге.
