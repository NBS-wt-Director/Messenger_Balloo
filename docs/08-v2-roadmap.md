# 🗺️ Дорожная карта v2 — Отложенные функции

> Этот документ содержит все функции, изменения и сущности, которые **отложены до v2**.
> В v1 они **не реализуются** — не входят в схему БД, API, UI и инфраструктуру.

---

## 1. 🔐 Аутентификация и безопасность (v2)

### 1.1. Госуслуги OAuth
- **Статус:** отложено до v2
- **Описание:** Авторизация через Госуслуги (v2) — не нужна на первом этапе
- **Затрагивает:** таблицу `Account` (добавить provider `"gov"`), эндпоинты OAuth
- **Ссылка:** вопрос 4.2.2 вопросника

### 1.2. SMS-уведомления
- **Статус:** отложено до v2
- **Описание:** SMS-коды для верификации — только email на первом этапе
- **Затрагивает:** интеграция с SMS-провайдером, новые эндпоинты
- **Ссылка:** вопрос 4.4.3 вопросника

### 1.3. E2EE (End-to-End Encryption)
- **Статус:** отложено до v2
- **Описание:** Сквозное шифрование сообщений — пользователь может подключить за плату на каждый чат отдельно
- **Затрагивает:** архитектуру сообщений, WebSocket, клиентское шифрование
- **Ссылка:** п. 127 чек-листа требований

## 6. 🗄️ Сущности данных (отложены до v2)

| Сущность | Описание | Причина откладывания |
|---|---|---|
| `message_mentions` | Отдельная таблица для @упоминаний | Пока обрабатываются на уровне текста/парсинга |
| `group_join_requests` | Заявки на вступление в группу | Пока только инвайты |
| `feature_subscriptions` | Подписки на фичи-реквесты | Не критично для v1 |
| `version_subscribers` | Подписки на релизы версий | Не критично для v1 |
| `admin_roles` | Ролевая модель админов | Пока `User.role` строкой |
| `message_forwards` | Отдельная таблица пересылок | Пока через цитирование |
| `saved_messages` | Избранное/сохранённые сообщения | Пока через `chat.type=saved` |
| `chat_folders` | Папки для чатов | Пока архив и поиск |

## 9. 📝 Примечания

1. **Все решения по v2 могут быть пересмотрены** при переходе в Фазу 4 (разработка v2).
2. **Архитектура v1 спроектирована так, чтобы v2-функции добавлялись без breaking changes.**
3. **2FA (email-код) — в v1, не TOTP.** Backup-коды не нужны (ответ пользователя на вопросы 4.2.3 и 4.2.4).
4. **Firebase (FCM) не нужна** — на первом этапе только Web Push API (вопрос 5.1.5).
5. **Госуслуги OAuth** — перенесены в v2 (вопрос 5.1.9).
6. **Desktop (Tauri) и Mobile (Expo) — в v1**, не отложены.
