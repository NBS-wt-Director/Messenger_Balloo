## 1. Регистрация и авторизация

### Процесс

```
┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
│  Экран   │────▶│  Отправка │────▶│  Вериф. │────▶│  Вход в  │
│ регистрации │  │  данных  │     │  email   │     │  систему │
└──────────┘     └──────────┘     └──────────┘     └──────────┘
                        │                       │
                        │              ┌──────────────────┐
                        │              │ OAuth (Yandex/VK)│
                        │              │ → мгновенный вход │
                        └──────────────┘
```

### Шаги

1. **Регистрация:** email + пароль + согласие на ПД
2. **Верификация:** письмо на email с кодом подтверждения
3. **OAuth-вход:** Яндекс, VK, Mail.ru → мгновенная авторизация
4. **2FA:** TOTP (Google Authenticator) + backup-коды

### API

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/auth/register` | Регистрация |
| POST | `/api/auth/verify` | Подтверждение email |
| POST | `/api/auth/login` | Логин по email/паролю |
| GET | `/api/auth/oauth/:provider` | OAuth-редирект |
| GET | `/api/auth/oauth/:provider/callback` | OAuth-колбэк |
| POST | `/api/auth/refresh-cookie` | Обновление сессии |
| POST | `/api/auth/logout` | Выход |
| POST | `/api/auth/2fa/enable` | Включение 2FA |
| POST | `/api/auth/2fa/verify` | Проверка 2FA |

## 10. Взаимодействие между доменами

### Авторизация

| Домен | URL входа |
|---|---|
| balloo.su | `https://balloo.su/#/login` |
| admin.balloo.su | `https://admin.balloo.su/#/login` |
| command.balloo.su | `https://command.balloo.su/#/login` |
| features.balloo.su | `https://features.balloo.su/#/login` |

### API

Все домены обращаются к `https://api.balloo.su/api/...`.

### Cookie

`COOKIE_DOMAIN=.balloo.su` — cookie видны всем поддоменам.
