## Как работают приглашения (требование владельца)

1. Приглашение — **ссылка на страницу**, письма не отправляются.
2. Попав на страницу, приглашаемый:
   - видит **кто пригласил**, **какие группы**, **что за мессенджер**, **текст
     приглашения** (если задан);
   - по кнопке присоединяется к выбранным группам;
   - если стоит галочка «добавлять в контакты» — попадает в контакты пригласившего.
3. Если нужна авторизация — **id-метка приглашения передаётся в регистрацию**.
4. Новый пользователь по приглашению **засчитывается в рефералы** — вкладка
   «Я присоединил к Balloo» на странице приглашений.
5. MVP2/3: реферальная программа с бонусами за приглашённых (см. раздел «На будущее»).

## Реализация

### 1. Схема (Prisma)

`InviteLink`:
- `addToContacts Boolean @default(false)` — добавлять принявшего в контакты создателя
- `message String? @db.Text` — текст на странице приглашения

Новая модель `InviteAcceptance` (реферал):
- `inviteId`, `userId` (принявший), `inviterId` (создатель), `code`, `createdAt`
- `@@unique([inviteId, userId])`, индексы по `inviterId`, `userId`

### 2. Backend

- `GET /api/invites/preview/:code` (**public**) — пригласивший (имя/аватар),
  группы (id/имя/тип), текст, тип мессенджера.
- `POST /api/invites/accept/:code` (**auth**) — вступить во все группы ссылки,
  при `addToContacts` — контакты, записать `InviteAcceptance`.
- `GET /api/invites/referrals` (**auth**) — список «я присоединил».
- `POST /api/invites` — расширить: `groupIds`, `addToContacts`, `message`.
- Регистрация (`POST /api/auth/register`) — принимать `inviteCode`, после создания
  пользователя обработать приглашение (группы + контакты + реферал).

### 3. Frontend

- Публичный экран `JoinInviteScreen` (`/join/:code`) — карточка приглашения + кнопка.
  - не авторизован → редирект на `/register?invite=<code>`;
  - авторизован → принять приглашение и уйти в чаты.
- `InvitesScreen` — третья вкладка «Я присоединил к Balloo» (рефералы) + форма
  создания по макету (группы, галочка контактов, текст).
- `RegisterScreen` — подхватить `?invite=` из hash-URL и передать в `api.register`.
