# Тикет 1791626400 — Глобальное правило: проверка только исполнением

**Создан:** 2026-10-10 (unix 1791626400)
**Статус:** готов
**Источник запроса:** владелец, прямое указание «записать новое правило межсессионно»

## Цель

Записать в `AGENTS.md` правило, действующее во всех проектах и всех сессиях:
код проверяется только исполнением, а не перечитыванием; при невозможности
прогона — честно об этом писать, не выдавать «написано» за «работает».

## Подзадачи

- [x] 1. Найти в `AGENTS.md` место вставки и уже существующие правила на эту
  тему. Доказательство: `grep -n "^## \|^### " AGENTS.md` — разделов «Проверка
  изменений», «Протокол тикетов» в HEAD нет; есть §1 «Проверяемые факты»
  (замер 27.09.2026) и «Запрет на выдумки в отчётах».
- [x] 2. Записать §0 (проверка исполнением, 5 пунктов).
  Доказательство: `git diff -- AGENTS.md` → `+## §0. Глобальное правило: код
  проверяется запуском, а не чтением (№1)`.
- [x] 3. Записать §0.1 (приоритет: живой источник над методом, 5 пунктов) —
  вторая половина указания: «файлы пустые, папок нет — обязана это проверить».
  Доказательство: `git diff -- AGENTS.md` → `+### §0.1. Приоритет: живой
  источник над методом (записано 2026-10-10, №1bis)`.
- [x] 4. Проверить, что правка пережила запись: `git diff --stat -- AGENTS.md`
  → `1 file changed, 60 insertions(+)`; `git show HEAD:AGENTS.md | grep "## §0"`
  → пусто (в HEAD раздела нет, правка рабочая).

## Критерии готовности

- Текст правила в `AGENTS.md`, читается в новой сессии при старте;
- ни один существующий раздел не удалён (diff — только добавления);
- тикет закрыт и перенесён в `tickets/Done/2026-10-10/`.

## Проблемы и решения

1. Первая вставка не появилась при проверке `grep` сразу после успешного
   `edit_file`: параллельная сессия в это же время перезаписывала `AGENTS.md`
   (в дереве одновременно правятся `docker/nginx.conf`, `installService.ts`,
   `packages/web/index.html`). Решение: правка повторена, проверка diff
   выполнена после записи. Случай соответствует разделу «Один писатель»
   (`tickets/active/1790000000-ПОРЯДОК-обработки-active.md`, шаг 0quater).
2. Формулировка задачи изначально звучала как «написать тест, который ловил бы
   расхождение». По §0.1 п.3 она отклонена: источник ожидаемого значения в
   репозитории отсутствует (`mockups/index_ecrans.json` — только метаданные
   экранов, `data_schema.json` — 0 упоминаний тёмной темы), тест пришлось бы
   выдумать. Вместо него — правило в `AGENTS.md` + проверка фактического
   состояния файлов.

## Результат

`AGENTS.md` дополнен двумя разделами, +60 строк, 0 удалений:

- §0 «Глобальное правило: код проверяется запуском, а не чтением (№1)»;
- §0.1 «Приоритет: живой источник над методом (№1bis)».
