## Цель

Полный аудит фронтенда `packages/web` (114 tsx-экранов, 82 маршрута) на три вещи:
1. **Соответствие ТЗ и макетам** — каждый принятый экран макетов (`mockups/index_ecrans.json`,
   113 принятых экранов MVP1) имеет реализацию в коде; структура экрана совпадает с макетом.
2. **Адаптивная вёрстка** — каждый экран корректно отображается на мобильной ширине.
3. **Три темы** — `dark` / `light` / `russian` (подтверждены владельцем, `packages/web/src/styles/themes.css`
   содержит `[data-theme='dark']`, `[data-theme='light']`, `[data-theme='russian']`) работают на каждом
   экране; цвета экранов берутся из CSS-переменных, а не захардкожены.

Несоответствия пишутся в **журнал рядом с тикетом**:
`tickets/active/1794891985-журнал-несоответствий.md`.

### Часть 3. Критические блокировки (не позволяют работать)

1. **FeedbackModal всегда тёмный** — `var(--bg-card, #16181f)`, `var(--bg, #0f1116)`, `var(--border, #2a2d37)` — переменные `--bg`, `--border`, `--bg-card` **не определены** в themes.css. Фоллбэки — тёмные цвета GitHub Dark.
2. **SettingsScreen локальный стейт** — `useState('dark')` на строке 27; не привязан к uiStore; по умолчанию `'dark'` противоречит решению владельца (`'russian'`).
3. **34 экрана без кода** — включая 5 shared-ошибок (503, offline-authed, offline-guest, ban, ban-appeal).
