## Правила расщепления (приняты, чтобы не изобретать их на каждом документе)

1. **Живой подтикет** (не закрыт / есть остаток) → новый файл
   `tickets/active/<unix>.md` в формате `AGENTS.md` §3: цель, подзадачи
   чек-боксом, критерии готовности, откуда брать контекст.
2. **Закрытый подтикет** → отдельный файл-заглушка **не создаётся** (иначе 70+
   пустыхы файлов). Его смысл сохраняется в исходном документе, который уезжает
   в `tickets/archive/` целиком — удаление не производится.
3. **Ссылка на первоисточник** обязательна в каждой новой задаче:
   `Первоисточник: tickets/archive/<мультитикет>.md, тикет №N` — иначе задача
   невыполнима после очистки контекста.
4. **Имя файла** = `date +%s` на момент создания + суффикс `-a`,`-b`, … при
   коллизии в пределах секунды (протокол допускает unix-время в имени).
5. **Перенос оригинала**: `git mv` в `tickets/archive/` для трекаемых файлов
   (`tickets/archive/` в `.gitignore:89` — файл уходит из индекса, история
   остаётся в `git log`; решение владельца 26.09 — архив вне git).
6. **Каталог**: в `tickets/catalog.md` позиция мультикета заменяется на
   «расщеплён на …» со списком новых файлов и путём к оригиналу в архиве.
7. Каждый обработанный документ = один пункт чек-листа ниже + отметка `[x]` с
   доказательством (`ls`, счётчик файлов) сразу по ходу (режим «Дальше», п.5bis).
