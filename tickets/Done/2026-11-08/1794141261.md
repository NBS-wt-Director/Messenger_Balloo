# Тикет 1794141261 — Перенос /var/lib/containerd → /data/balloo/containerd

**Создан:** 08.11.2026 (unix 1794141261)
**Статус:** выполнен
**Источник:** требование «всё Баллу — на одном диске»
**Родитель:** `tickets/active/1793567633.md` (батч W)

## Цель

Перенести containerd image store с системного диска (`/var/lib/containerd` = 24G) на `/data/balloo/containerd`, чтобы все образы и кэш сборки Баллу жили на одном диске `sdd` (3,6T).

## Выполнение

### W-D1 (07.11.2026)
- `sudo rsync -aHAXxv /var/lib/containerd/ /data/balloo/containerd/` — 24G скопировано
- `sudo mv /var/lib/containerd /var/lib/containerd.old-20261107` — контейнеры живы (6/6)
- `sudo rm -rf /var/lib/containerd.old-*` — старое удалено

### W-D2 (07.11.2026)
- `/etc/containerd/config.toml`: `root = "/data/balloo/containerd"` (раскомментировано, путь изменён)
- `systemctl restart containerd` + `systemctl restart docker` — оба активны
- Docker видит образы: `balloo/server=5c75a29f3b91` (новый)
- Все 6 контейнеров поднялись `restart=always`
- `docker info | grep Root` → `/data/balloo/docker`

### W-D3 (07.11.2026)
- `/var/lib/containerd` — каталога нет
- `/data/balloo/containerd` — 24G
- `/data/balloo/docker` — 12G
- `df /` — **33%** (было 59%, минус 23G)
- `df /data/balloo` — 25G занято из 3,6T (1%)

### W-D4 (08.11.2026) — WS-рукопожатие
- 12/12 проб со своей машины → **401** (стабильно, TIMEOUT — разовый)
- Логи сервера: `[WS] Connection rejected: no token` ×2, `jwt malformed` ×1 (мои пробы)
- Сервер получает рукопожатия через nginx — маршрут жив

## Проблемы и решения

- **Проблема:** `rsync` прошёл успешно, но `sed` в W-D сломался из-за кавычек — `root` остался закомментированным (`#root`), `set -e` оборвал скрипт до перезапуска.
- **Решение:** W-D-fix2 — `sed -i "s|^#\?root = .*|root = ..."` (правильный regex), `grep` подтвердил раскомментирование, перезапуск прошёл.
- **Риск:** `mv /var/lib/containerd` без отката. Решён через `mv` (не `rm`): обратный `mv` мгновенный, в процессе все 6 контейнеров были живы — значит новое хранилище работало.
