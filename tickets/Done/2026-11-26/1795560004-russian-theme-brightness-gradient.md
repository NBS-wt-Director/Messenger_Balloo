# Тикет 1795560004 — Тема «русская»: ярче + градиент в чате

**Создан:** 24.11.2026
**Источник:** владелец (чат 24.11.2026)

## Симптом

1. Где градиентный фон у экрана сообщений в теме «русская»?
2. Слишком темно для темы «русская».

## Диагноз

1. `--app-bg` в russian (themes.css:205-210) — градиент с opacity 0.22/0.38/0.42 поверх `#0a0c10` (почти чёрный). Итог визуально почти чёрный.
2. `--bg-primary: #0a0c10` (russian) — слишком тёмный базовый цвет.
3. `.content` (chat.css:124-132) красит `--bg-primary` solid; themes.css:232 переопределяет `[data-theme='russian'] .content.content { background: transparent }` — работает, но градиент настолько тёмный, что не виден.
4. `.messages` — прозрачен, градиент родителя должен быть виден. Реально — тёмно-красный едва заметен.
5. Пузыри сообщений в russian (themes.css:238-243) — малахитовый градиент с opacity 0.88/0.94, сам по себе яркий, но фон экрана почти чёрный.

## План

- [x] 2. Поднять opacity градиента `--app-bg`: белый 0.30 / синий 0.50 / красный 0.55.
- [x] 3. Убедиться что `.content` в russian — прозрачен (проверить удвоенный селектор `.content.content`).
- [x] 4. Добавить `[data-theme='russian'] .messages { background: transparent }` если chat.css красит.
- [x] 5. Убедиться что message__bubble (малахит + золото) контрастирует с новым фоном.
- [x] 6. Проверка: скриншот темы «русская» в браузере, tsc, vitest, build.
