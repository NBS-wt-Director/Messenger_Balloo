# Тикет 1794211605 — Онбординг: шаги без текста; правило «нет контента — не показываем»

**Создан:** 2026-11-09 (unix 1794211605)
**Статус:** в работе
**Источник запроса:** приёмка Шага 7 владельцем в браузере (прод balloo.su)

## Цель
Онбординг на проде показывает шаги БЕЗ текста, кнопки «съехали в правый
верхний угол». Владельцем установлено правило: **если у шага нет текста —
онбординг не показываем вообще.**

## Найденные факты (замеры 09.11.2026)
1. `curl https://api.balloo.su/api/onboarding/steps` → 200, шаги с текстами,
   но формат: `{id, order, illustrationUrl, translations:[{language,title,description}]}`.
2. `OnboardingScreen.tsx` читает `step.title / step.text / step.illustration` —
   в API-формате таких полей нет → undefined → шаги без текста.
3. CSS-класса `.onboarding*` в `packages/web/src/**/*.css` **нет вообще**
   (`grep -rn "onboarding" --include="*.css"` пусто) → раскладки нет, кнопки
   в углу. В макете `mockups/balloo-su/onboarding.html` стили есть (common.css).
4. Экран монтируется в `router/index.tsx`: путь `/onboarding` и путь `/`
   (гость, строка ~198).
