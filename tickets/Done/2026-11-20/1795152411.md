# Тикет 1795152411 — Dockerfile.web: стадии web_history/web_download падали (dist not found)

**Создан:** 20.11.2026 10:40 (unix 1795152411)
**Статус:** готов (исправлено и доказано docker-сборкой)
**Источник запроса:** батч полной пересборки стека 20.11.2026
(`with_lord/1795152409-пересборка-всего-и-ключи.md`, Часть B) — сборка упала
на `build web-history`

## Цель

Починить `docker/Dockerfile.web`, чтобы полная пересборка стека
(`docker compose build`) не падала на сервисах `web-history`/`web-download`.

## Диагноз (доказано выводом сервера и чтением файла)

Вывод батча 20.11.2026:
```
target web-history: failed to solve: failed to compute cache key:
"/app/packages/web-history/dist": not found
```

Причина в `docker/Dockerfile.web`:
- стадии `web_history` (стр. 113-120) и `web_download` (стр. 122-129)
  копируют `packages/web-history/dist` и `packages/web-download/dist`;
- но builder **не собирал** эти пакеты: не было ни `COPY packages/web-history/`,
  ни `RUN … vite build` для них (собирались только `web`, `web-features`,
  `web-admin`);
- манифесты этих пакетов тоже не копировались → `pnpm install` их не видел.

Дефект внёс коммит `454f30e` («задел варианта А — web-history + web-download») —
заготовка, у которой была дописана финальная стадия, но не builder.

## Подзадачи

- [x] 1. `COPY packages/web-history/package.json`, `packages/web-download/package.json`
      (для `pnpm install`). Доказательство: `git diff docker/Dockerfile.web`.
- [x] 2. `COPY packages/web-history/`, `packages/web-download/` (исходники).
- [x] 3. `RUN cd packages/web-history && ./node_modules/.bin/vite build` и то же
      для web-download.
- [x] 4. Локальный `vite build` обоих пакетов — `EXIT=0`:
      `web-history` → `dist/assets/index-BAqclDcD.js` (159.42 kB);
      `web-download` → `dist/assets/index-BtCqrfEU.js` (159.17 kB).
- [x] 5. Docker-сборка целевых стадий — `EXIT=0`:
      `docker build --target web_download -t balloo/web-download:test .` → OK;
      `docker build --target web_history  -t balloo/web-history:test  .` → OK.

## Критерии готовности

- [x] `docker build --target web_history` и `--target web_download` → `EXIT=0`
- [x] Сборка `web`/`features`/`web-admin` не сломана (общий builder прошёл целиком)
- [x] `pnpm --filter @balloo/web-history build` и `@balloo/web-download build` → `EXIT=0`

## Проблемы и решения

- **Зачем чинить, если сервисы не запущены.** Контейнеры `balloo-web-history`/
  `balloo-web-download` на проде **не запущены**, а `history.balloo.su`/
  `download.balloo.su` наружно отдают **web-бандль** (`index-Us-3a8_X.js`), т.е.
  хостовый nginx проксирует их на `balloo-web`. Но `docker compose build`
  собирает **все** сервисы файла, поэтому падал бы на каждой полной пересборке.
  Фикс делает сборку зелёной; вопрос «нужны ли эти сервисы вообще или их убрать
  из compose» — **решение владельца** (варианты ниже).
- **Варианты по сервисам** (после фикса они собираемы, но не запущены):
  (а) оставить как задел — ноль действий; (б) убрать из
  `docker-compose.local.yml` (домены и так отдают web) — меньше мусора, но
  теряется заготовка; рекомендация — **(а)** до явного решения владельца.
