## Как пользоваться этим тикетом

### Шаг 1: Считай контекст
В разделе «УЖЕ СДЕЛАНО» — что уже изменено в текущей сессии. Это твой базовый контекст.

### Шаг 2: Читай по приоритетам
Задачи отсортированы: P0 (критично) → P1 (важно) → P2 (мелочи).

### Шаг 3: Для каждого экрана — 3 файла
При работе с экраном меняй:
1. `mockups/<узл>/<файл>.html` — макет
2. `mockups/<узл>/<файл>.md` — документация (если существует)
3. `mockups/index.html` — обновить счётчики (в конце сессии)

### Шаг 4: Порядок действий
1. Прочитай HTML-файл макета
2. Прочитай MD-файл рядом (если есть)
3. Прочитай комментарий пользователя ниже (раздел «Комментарий»)
4. Внеси правки в HTML
5. Если MD существует — обновить. Если нет — создать по шаблону
6. В конце — обновить `index.html`, `index_ecrans.json`, `index_ecrans.md`

### Шаг 5: Шаблон MD-файла (если не существует)
```
# <ID> — <Название>

## Описание
[2-3 строки]

## Структура
- **Topbar**: ...
- **Sidebar**: ...
- **Content**: ...

## Дизайн-требования
- common.css, glassmorphism, темы

## Компоненты
- `ComponentName` — описание

## API
- `GET /api/...` — описание
```

### 1_01_19 — group-settings.html

**Файл:** `mockups/balloo-su/group-settings.html`

**Комментарий пользователя:**
> «Шаблоны сообщений в чатах — отдельная вкладка. Для каждого вида вложения/интерактива — своя вкладка. У СМИ вкладка реклама (пока в разработке). У корпоративных отдельные вкладки: витрина, расписание и адреса, настройки чата клиентов (назначить администраторов/модераторов), настройки чата сотрудников (назначить администраторов/модераторов, сотрудники автоматически добавляются в контакты с припиской "коллега - компания: роль"), реклама (заказ рекламы у платформы или у каналов СМИ через комбобокс), дополнительные чаты (из клиентов назначаем), экспорт/импорт настроек (все чаты как отдельные, админиристрируются как один). Все поля редактируемы, кроме статистики.»

**План действий:**
1. Прочитай `group-settings.html` — сейчас там вкладки настроек группы
2. Добавь вкладки:
   - **Шаблоны сообщений** (подвкладки: текст, вложение, интерактив)
   - **СМИ** (реклама — заглушка v2 + ссылки на блог/донаты/историю)
   - **Корпоративные:**
     - Витрина
     - Расписание и адреса
     - Настройки чата клиентов (назначение администраторов/модераторов)
     - Настройки чата сотрудников (назначение администраторов/модераторов, автосписок коллег)
     - Реклама (заказ у платформы или у каналов СМИ через комбобокс)
     - Дополнительные чаты (из клиентов назначаем)
     - Экспорт/импорт настроек
3. В каждой вкладке — редактируемые поля
4. Обновить `group-settings.md`
