## 2.1. Вердикт по двум претензиям владельца

**1) «Нет ни страницы, ни пункта меню по „поддержи нас"»** — это про **донат/поддержку проекта**, а не про чат поддержки. Вынесено отдельным тикетом `1795435147-donate-entry.md` (экран доната есть — `/donat`, `DonateScreen`; точки входа в UI нет: в подвале макета ссылка «Донат» была — `mockups/assets/common.js:680`, в коде подвала её нет).

**2) «Техподдержки вообще никакой из плана»** — **частично верно:**
- **Технически страница и бэкенд есть:** экран `SupportScreen` + маршрут `/support` (`packages/web/src/router/index.tsx:253`), серверный чат `GET/POST /api/support/chat`, `GET /api/support/status` (`packages/server/src/routes/support.ts:13-19`), сервис тикетов + автоответ (`packages/server/src/services/supportService.ts`), тесты (`packages/server/src/__tests__/support.test.ts`).
- **Но в интерфейсе точки входа нет:** пункта «Поддержка» нет в левом меню (S-3); пункт правого меню у гостя ведёт на `ProtectedRoute` → вход (S-5).
- **И ИИ-составляющей нет вообще** (S-6): «ИИ» есть только в макете как ярлык аватара, фактически это статичный автоответ.
