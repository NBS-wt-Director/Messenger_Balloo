1. **Первая попытка ушла на старый код.** `git checkout -B main origin/main`
   без `git fetch` использовал устаревший ref: HEAD остался `4e9e9e5`, сборка
   полностью CACHED, etag не изменился (`6b041000-66e`). Перезапуск контейнера
   ≠ деплой. Лечение: `git fetch origin` перед checkout (батч D выше).
   Правило зафиксировано: перед сборкой сверять `git log --oneline -1` с
   ожидаемым коммитом.
2. `force-recreate` web безопасен: nginx-образ stateless, миграции/БД не трогает.
