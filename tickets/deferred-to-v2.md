### Тикет v2-024: Автоперевод контента (ИИ)
**Приоритет:** 🟡 Средний  
**Зависит от:** [v2-023]  
**Цель:** Автоматический перевод сообщений, постов и комментариев на язык пользователя с помощью ИИ

**Описание:**
Пользователь получает контент (сообщения, посты блога, комментарии) на чужом языке — система автоматически переводит его на язык пользователя. Функция включается в настройках.

**Включение:**
- Settings → Язык → «Автоперевод контента» (toggle вкл/выкл)
- Дополнительная настройка: выбор языков-источников для перевода (или «все языки»)

**Сценарии:**
1. **Сообщения в чатах** — перевод входящих сообщений на язык получателя
2. **Посты в блоге** — перевод на язык читателя
3. **Комментарии** — перевод на язык читателя
4. **Stories** — перевод текстовых историй
5. **Feature-реквесты** — перевод описаний и комментариев
6. **Каналы** — перевод постов в каналах на язык подписчика

**UI/UX:**
- Badge «Автоперевод» на переведённых сообщениях/постах
- Кнопка «Показать оригинал» рядом с переведённым контентом
- Индикатор языка оригинала (флаг + код языка)
- Настройка: переводить всегда / спрашивать / никогда

**Технология:**
- ИИ-переводчик: self-hosted модель (например, NLLB, OPUS-MT) или API российского сервиса
- **ЗАПРЕЩЕНО:** Google Translate, DeepL, Yandex Translate (если не self-hosted) — только российские или self-hosted решения
- Кэширование переведённых текстов в Redis (TTL: 24ч)
- Batch-перевод для оптимизации (несколько сообщений за один запрос)
- Fallback: если перевод недоступен — показать оригинал с badge «перевод недоступен»

**Бэкенд:**
1. Создать `packages/server/src/services/translationService.ts`
2. Модель в БД: `ContentTranslation` (contentHash, sourceLang, targetLang, translatedText, createdAt)
3. API: `POST /api/translate` (text, sourceLang, targetLang)
4. WebSocket event: `message.translated` (отправка переведённого сообщения в реальном времени)
5. Webhook/queue для batch-переводов (BullMQ + Redis)
6. Rate limiting: 100 переводов/мин на пользователя

**Фронтенд:**
1. Перехват входящих сообщений/постов → запрос перевода
2. Кэширование на клиенте (IndexedDB)
3. Toggle в настройках
4. Badge и кнопка «оригинал» в MessageBubble, BlogPost, Comment
