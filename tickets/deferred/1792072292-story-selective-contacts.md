# Тикет 1792072292 — Выборочный доступ к истории: список контактов

**Создан:** 2026-10-15 (unix 1792072292)
**Статус:** отложен
**trigger:** реализация списков контактов (групп контактов)
**Источник запроса:** приёмка 1.1.31 (В-37) от владельца 15.10.2026

## Цель

При выборе «выборочный доступ» на экране создания истории (`1_01_41`,
`story-create.html`) появляется список контактов с чекбоксами для выборочной
аудитории. Когда будут реализованы **списки контактов (группы контактов)** —
использовать их в этом экране.

## Подзадачи

- [ ] 1. UI: при выборе «выборочный доступ» — раскрывающийся список контактов
      с чекбоксами (галочками).
- [ ] 2. После реализации групп контактов: добавить переключатель «Контакты /
      Группы» и отображение групп в списке.
- [ ] 3. API: эндпоинт получения контактов/групп для выбора аудитории.
- [ ] 4. Хранение: связь история ↔ выбранные контакты (audience list).

## Критерии готовности

На экране создания истории при выборе «выборочный доступ» доступен список
контактов и групп контактов с чекбоксами.
