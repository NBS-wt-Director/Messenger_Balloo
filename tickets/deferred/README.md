# ⏸️ ОТЛОЖЕННО — папка отложенных задач

Здесь задачи, которые **осознанно не делаются сейчас**. Это не «забыли» и не
«забыли доделать» — владелец принял решение отложить. Искать работу здесь
**нельзя**, пока не наступил триггер задачи.

## Правило

Каждый файл здесь обязан содержать строку **Триггер**. Пока триггер не наступил:

- задачу не начинать;
- не «предложить вернуться к ней»;
- не переспрашивать владельца — решение принято и записано в `AGENTS.md`
  (раздел «Решения владельца»).

Наступил триггер → файл переезжает в `../active/` (`git mv`), в шапке
`status: active`, в истории — строка «триггер наступил <дата>».
