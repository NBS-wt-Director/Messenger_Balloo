## Что нужно сделать

1. `packages/web-admin`: Vite + React + `@balloo/ui`; перенести 18 экранов +
   `AdminLayout`; `VITE_API_URL=https://api.balloo.su`.
2. `packages/web-command`: 13 экранов + `CommandLayout`.
3. **Аудит серверных гвардов:** по каждому маршруту `/api/admin*` и
   `/api/command*` — требует ли он роль на сервере. Результат — таблица
   «эндпоинт → middleware → вердикт» в комментарии к тикету. Всё, что защищено
   только фронтом, — добавить `requireRole`.
4. На balloo.su маршруты `/admin*`, `/command*` → редирект на поддомены
   (сохранить совместимость со старыми ссылками `balloo.su/#/admin`).
5. `docker/Dockerfile.admin`, `Dockerfile.command` по образцу `Dockerfile.web`
   (COPY `packages/ui`, `packages/shared`).
6. Инфраструктура (vhost/certbot/compose) — тикет `-07`, не здесь.
