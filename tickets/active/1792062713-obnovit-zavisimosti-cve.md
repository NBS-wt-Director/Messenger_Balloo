# Тикет 1792062713 — Зависимости: закрепить версии с CVE-фиксами в манифестах

**Создан:** 2026-10-15 (unix 1792062713)
**Статус:** в работе
**Источник запроса:** решение владельца 1.2.2 от 15.10.2026
(`with_lord/СДЕЛАТЬ_ВЛАДЕЛЬЦУ.md` §1.2.2): вариант (а) — обновить `ws`, `axios`,
`dompurify` сейчас; `bcrypt` 6 и React 19 — не трогаем.
Правило «решения владельца → атомарные задачи» (`tickets/ПРОТОКОЛ.md` §2).

## Цель

CVE-уязвимые версии не могут быть установлены ни из lockfile, ни при fresh `pnpm install`.

## Найденные факты (замеры 15.10.2026 — таблица 1.2.2 устарела, фиксирую расхождение)

| Пакет | Таблица 1.2.2 (05.10) | Факт 15.10 | CVE-цель |
|---|---|---|---|
| `ws` (server) | 8.18.0 | манифест `^8.18.0` (`packages/server/package.json:37`), **установлен 8.21.1** (замер `require('ws/package.json').version`) | ≥ 8.19.0 (CVE-2025-32379) — уже покрыт |
| `axios` (web) | 1.12.0 | манифест `^1.7.0` (`packages/web/package.json:19`), **установлен 1.18.1** | ≥ 1.13.2 (CVE-2025-32860) — уже покрыт |
| `dompurify` | 3.1.6 (shared) | **пакета нет в проекте**: `grep -c dompurify pnpm-lock.yaml` → 0, в коде 0 совпадений | не применимо |
| `bcrypt` | 5.1.1 (server) | нативного bcrypt **нет**; есть `bcryptjs ^2.4.3` (`packages/server/package.json:21`) — чистый JS, проблема байт-кодов к нему не относится | не применимо |

**Вывод:** установленные версии уже выше CVE-фиксов (lockfile), но declared-диапазоны
позволяют fresh-install получить уязвимую версию. Задача сводится к подъёму нижних
границ в манифестах + синхронизации таблицы 1.2.2/§1.5.

## Подзадачи

- [ ] 1. `packages/server/package.json`: `"ws": "^8.18.0"` → `"^8.19.0"`.
- [ ] 2. `packages/web/package.json`: `"axios": "^1.7.0"` → `"^1.13.2"`.
- [ ] 3. `pnpm install` → exit 0; installed-версии не изменились (8.21.1 / 1.18.1) —
      зафиксировать выводом.
- [ ] 4. `pnpm test` и `pnpm build` → exit 0.
- [ ] 5. Обновить строку 1.2.2 в `with_lord/СДЕЛАТЬ_ВЛАДЕЛЬЦУ.md`: dompurify/bcrypt
      строки убрать как неприменимые (пакетов нет), зафиксировать исполнение.
- [ ] 6. Коммит `chore(deps): нижние границы ws/axios над CVE-фиксами (1.2.2а, тикет 1792062713)`.

## Критерии готовности

grep манифестов → `^8.19.0` / `^1.13.2`; `pnpm install`/`test`/`build` зелёные;
коммит есть; строка 1.2.2 помечена.
