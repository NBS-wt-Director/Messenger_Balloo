## Цель

В `ChatViewScreen` при отсутствии выбранного чата (`!chatId`) показывать empty state
по принятому макету `mockups/balloo-su/empty-chat.html`:
- маскот Балунишка (🐻, title «медведь Борис») вместо пиктограммы шарика;
- секция «🐻 Балунишка предлагает пообщаться» — контакты, с которыми НЕТ чатов;
- поиск по этим контактам («🔍 Поиск человека...»).

  empty state с маскотом ОТСУТСТВУЕТ (grep `🎈/mascot/Выберите` в screens/chat → пусто);
- 🎈 есть только в `SettingsScreen` (:617,:744) и `Sidebar` (:87) — не этот экран;

  (contacts минус userId из чатов store); при большом объёме — позже серверный
