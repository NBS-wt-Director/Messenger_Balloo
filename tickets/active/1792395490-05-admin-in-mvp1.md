## Цель

Вынести 24 admin-экрана из основного web (`packages/web/src/screens/admin/`) в
`packages/web-admin/`, добавить guard (не-админы → редирект на /#/chat или
онбординг), переключить 4 эндпоинта на существующие роуты (B2-в).

## Живые замеры (19.10.2026)

- `packages/web-admin/` — заглушка: только `package.json` + `tsconfig.json`, `src/` нет.
- `pnpm-workspace.yaml:3` → `'!packages/web-admin'` (исключение mvp1-01).
- `packages/web/src/screens/admin/` — 24 файла (замер `ls | wc -l` = 24).
- `grep -c "screens/admin" packages/web/src/router/index.tsx` → 24 монтажа.
- Guard не-админов в роутере → grep `isAdmin|moderator` = 0 (никогда не было).

      `packages/web-admin/src/screens/`. Проверка: `ls packages/web-admin/src/screens/ | wc -l` → 24.
- [ ] 4. Удалить admin-роуты из `packages/web/src/router/index.tsx` (24 строки).
      Проверка: `grep "screens/admin" packages/web/src/router/index.tsx` → 0.

      `pnpm --filter @balloo/web build` exit 0 (admin больше не в web).

## Проблемы и решения

- `packages/web-admin` — заглушка без src: это не «перенос из готового пакета»,
  а создание пакета с нуля + перенос файлов. Объём — один проход, структура
  повторяет web.
- `EmployeesScreen` остаётся в web-admin, но не работает (нет модели Employee)
  — по решению владельца отложен, не блокирует тикет.
