# Тикет 1795101592 — QR-вход со второго устройства: поток разорван (ПРОВЕРИТЬ/ПОЧИНИТЬ)

**Создан:** 19.11.2026 (unix 1795101592)
**Статус:** код готов и проверен тестами; осталось п.7 — браузерная приёмка владельца
**Источник запроса:** владелец 19.11.2026: «есть возможность авторизации через второе
устройство (qr-код генерится/читается? коды авторизации доходят из push?)»

## Ответ на вопрос владельца (замер, не чтение)

**Нет, вход со второго устройства сейчас невозможен.** Поток разорван в двух местах:

| Слой | Состояние | Доказательство |
|---|---|---|
| Сервер | ✅ реализован полностью | `deviceService.ts`: `createPairToken` (Redis, TTL 60с), `getPairStatus`, `confirmPair` (создаёт Device + пару токенов, кладёт в Redis); роуты `POST /api/devices/pair-token`, `GET /api/devices/pair/:token/status`, `POST /api/devices/pair/confirm` (`routes/devices.ts:27,33,39`) |
| Web — показывающее устройство | ⚠️ есть, но **QR фейковый** | `AddDeviceScreen.tsx:133–168` — QR-«код» нарисован CSS `repeating-conic-gradient`, **не содержит токена и не сканируется**; реальный токен показан только текстом `balloo://pair/{token}` (`:171`). Вход на экран есть: `/login` → `/add-device` (`LoginScreen.tsx:185`), роут `router/index.tsx:404` |
| Web — подтверждающее устройство | ❌ **отсутствует** | `confirmPair` не вызывается из `packages/web/src` нигде (`grep -rn "confirmPair\|pair/confirm" packages/web/src` → пусто). Сканера QR нет; `BarcodeDetector`/`jsQR`/`getUserMedia(video)` не используются. QR-библиотек в проекте нет (`qrcode-terminal` — только для терминала) |

**Следствие:** пользователь может открыть экран и увидеть таймер с «кодом», но
отсканировать нечего и подтвердить нечем — кнопка «Войти через другое устройство»
ведёт в тупик.

## Цель

Сделать вход со второго устройства рабочим end-to-end:
новое устройство показывает **настоящий** QR → авторизованное устройство сканирует →
подтверждает → новое устройство получает cookie и уходит в `/chat`.

## Критерии готовности

- QR на экране — настоящий, декодируется в `balloo://pair/<token>`.
- Авторизованное устройство может отсканировать и подтвердить; новое уходит в `/chat`.
- Тесты и сборки зелёные (вывод в «Результат»), приёмка описана владельцу.
