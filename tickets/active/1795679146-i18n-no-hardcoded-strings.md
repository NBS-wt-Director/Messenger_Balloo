# Тикет 1795679146 — i18n: убрать захардкоженный русский, перевести весь UI на 20 языков

**Создан:** 26.11.2026
**Источник:** владелец (чат 26.11.2026): «ещё одна критическая и системная ошибка — захардкоренный русский язык везде. везде должен быть активен и возможен к использованию перевод на каждый из заявленных языков системы. каждое слово текста должно быть снабжено переводом и зафиксировано в модуле переводов, хардкорить слова запрещено!»
**Критичность:** системная — блокирует заявленную функцию «20 языков» (MVP1)

**Причина:** словарь содержит 133 ключа — это ~2% от объёма текста продукта.
Экраны писались с русскими литералами в JSX/строках. `scripts/check-i18n.cjs`
проверяет только согласованность ключей (словарь ↔ тип ↔ использование), но
**не ловит кириллицу вне `t()`** — поэтому CI зелёный при 228 файлах хардкода.

## Что требуется (постоянное правило)

1. **Каждое слово интерфейса — через модуль переводов.** Русский литерал в
   UI-коде запрещён. Единственное исключение — значения **в самом словаре**.
2. **Все 20 языков обязательны** для каждого ключа. Нет перевода → ключ не
   считается готовым (заглушка `en` недопустима как финальное состояние).
3. **Перевод фиксируется в модуле переводов** (`packages/shared/src/i18n/translations.ts`)
   в момент появления строки, а не «потом».
4. **Правило действует на все пакеты и все будущие экраны**: `web`, `ui`,
   `web-admin`, `web-features`, `web-history`, `web-download`, `desktop`,
   `mobile-android`, `server` (пользовательские тексты ошибок).
5. **Запрет обходится только явным решением владельца** (например, юридический
   текст с юридически значимой формулировкой — тогда ключ всё равно заводится,
   а русский текст становится значением `ru`).
