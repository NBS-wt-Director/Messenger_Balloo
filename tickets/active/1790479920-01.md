| Переменная | Где получает владелец |
|---|---|
| OAuth Яндекс: client id / secret | Яндекс OAuth (oauth.yandex.ru) |
| OAuth VK: client id / secret | VK для разработчиков |

форма ввода — `tickets/active/api-keys-questionnaire.md` (оба существуют).

## Почему это блокер продукта, а не бумажка

Без OAuth-ключей не проходит вход через Яндекс/VK/Mail → блокируется приёмка
входа (см. `Приёмка_20260920_P27-P51_desktop_android.md`, блок 0 предусловий).
