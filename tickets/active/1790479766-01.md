## Что нужно сделать

1. PostgreSQL поднят: `pg_isready -h localhost -p 5432` (учётки: `balloo/balloo123`, БД `balloo`).
2. Миграции: `cd packages/shared && npx prisma migrate deploy` (не `db push` — схема версионирована).
3. Seed: `npx prisma db seed` — идемпотентность повторного запуска.
4. `pnpm dev:server` → порт 3100; проверить `curl -s http://localhost:3100/health`.
5. `pnpm dev:web` → порт 5173; открыть браузером, убедиться, что запросы идут на
   `http://localhost:3100/api/...`, консоль чистая.
6. Записать в «Результат»: какие команды реально понадобились (остальное вычеркнуть
   из инструкции), вывод `health`, номер порта, время.
