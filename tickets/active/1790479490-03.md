## Что нужно сделать

1. **Backend-слой** по каждому сервису: наличие файла в
   `packages/server/src/routes/`, контроллера в `controllers/`, сервиса в
   `services/`, подключения маршрута в `app.ts`/`server.ts`.
2. **Точечные проверки:**
   - OAuth callbacks: `/api/auth/yandex/callback`, `/api/auth/vk/callback`,
     `/api/auth/mailru/callback`;
   - webhook платежей: `/api/payments/webhook/yookassa`;
   - Web Push: endpoint выдачи VAPID-ключа.
3. **Frontend-слой:** экран настройки (`InstallScreen`, `SystemSettingsScreen`,
   `AdminDonationsScreen`, …), вызов в `api.ts`, UI ввода/отображения ключей.
4. **Артефакты:**
   - `tickets/services-integration-audit.md` — таблица
     `Сервис → route → controller → service → screen → api.ts → статус`,
     по каждому расхождению — описание и план;
