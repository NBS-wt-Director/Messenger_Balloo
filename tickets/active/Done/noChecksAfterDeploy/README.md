с сервера, но не закрыта **браузерная приёмка после W-прохода** (пересборка
server+web) или внешние замеры владельца.

## Когда переносить обратно в `active/`

После выполнения W-прохода (пересборка server+web, команда «Деплой») и
подтверждения пунктов владельцем — закрывать переносом в `tickets/Done/<дата>/`.
