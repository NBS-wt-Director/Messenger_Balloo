## Что нужно сделать

1. **Собрать статистику командами** (не по памяти):
   - файлов всего без `node_modules`: `find . -type f -not -path '*/node_modules/*' | wc -l`;
   - размер по каталогам: `du -sh */`;
   - файлы по типам: `find … | sed 's/.*\.//' | sort | uniq -c | sort -rn | head -20`;
   - макеты по узлам: число `.html`/`.md` в каждом `mockups/<узел>/`;
   - код по подпроектам: `packages/*/src` — файлы и строки;
   - строки кода по языкам (tokei/cloc, если нет — `wc -l` по расширениям);
   - экраны: `mockups/index_ecrans.json` → `total_screens`, разбивка по `status`;
   - тикеты: `tickets/active/`, `tickets/Done/<дата>/`, `tickets/deferred/` — счётчики.
2. **`docs/project-report.md`** — таблицы: общая сводка, структура проекта,
   макеты по узлам (узел, ID, HTML, MD, всего, размер), код по подпроектам,
   строки по языкам, тикеты и документы.
3. **`docs/project-report.html`** — тёмная тема, CSS-переменные `mockups/assets/common.css`.
4. **`docs/project-report.pdf`** — конвертация (`pandoc` / `wkhtmltopdf`; если
   недоступны — HTML-версия для печати с `@media print`).
5. В шапке отчёта — дата генерации и команды, которыми сняты цифры (иначе через
   месяц повторится эта же задача).
