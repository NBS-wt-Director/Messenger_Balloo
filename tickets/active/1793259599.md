## Причины (две, обе подтверждены)

1. **`lazy` без `.then(m => ({default: m.X}))`.** В `packages/web-admin/src/App.tsx`
   все 24 экрана грузятся как `lazy(() => import('./screens/X'))`, но каждый экран
   — **именованный** экспорт (`export function X()`), default-экспорта нет
   (`grep -c "export default"` по 24 файлам → 0). React 18 при монтировании
   lazy-компонента без `default` бросает ошибку → ErrorBoundary → белый экран.
   В `packages/web/src/router/index.tsx` тот же приём работает, потому что там
   экраны имеют default-экспорт.
2. **Редирект на несуществующий `/login`.** `AdminGuard` и `AdminLayout` уводят
   неавторизованного на `/login`, но маршрута `/login` в `App.tsx` нет вообще →
   срабатывает `path="*"` → 404. Вход живёт на `balloo.su/#/login` (другой
   домен, hash-роутер).

Дополнительно (третья, мелкая): `InstallScreen.tsx:53` вызывает `fetch` внутри
`useState(() => ...)` — это инициализатор состояния, побочный эффект в нём
не должен быть; корректно — `useEffect(..., [])`.
