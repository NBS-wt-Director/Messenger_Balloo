- **Миграции: НЕ НУЖНЫ.** Проверено 29.10.2026:
  `git diff --name-only ab1575c..fe602f0 | grep -i migration` → пусто.
  Каталог миграций — `packages/shared/prisma/migrations`, последняя
  `20261021000000_add_employees` (уже на проде). Шаг F2 снят.
- **Хостовый nginx на сервере устарел и опасен.** Факты (29.10.2026):
  файл 6350 байт от 15.10, `grep -c mc.yandex.ru` → 0, CSP-заголовка нет вовсе,
  **отдельного блока `admin.balloo.su` нет** — админка проксируется в общем
  SPA-блоке на `:8090`. В репозитории (`docker/prod/nginx/balloo-docker.conf`)
  блок есть и ведёт на `:8092`.
  **Копировать файл целиком нельзя:** репо-версия ссылается на
  `live/balloo.su/`, а на сервере `live/balloo.su-0001/`; в репо нет блока
  `cdn.balloo.su`, который на сервере есть. Правка — точечная (`sed`/вставка
  блока) с бэкапом `/root/balloo-docker.conf.bak-20261029`.
- **24 админ-экрана удалены из `packages/web`** (коммит в диапазоне).
  `grep -n admin packages/web/src/App.tsx` → пусто; каталога
  `packages/web/src/screens/admin/` нет. Значит пересоздание `web` без правки
  nginx = белый экран на `admin.balloo.su`. Порядок обязателен: **G → H**.
- **Размещение Balloo — на отдельном диске.** `docker info` →
  `/data/balloo/docker`; `lsblk` → `sdd 3,6T ext4 balloo /data/balloo`;
  `sudo du -sh /var/lib/docker` → `0`. Требование владельца выполнено.
- **Расхождение размеров (не решено):** `docker system df` → 14.59 ГБ образов,
