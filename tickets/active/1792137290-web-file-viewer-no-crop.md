## Цель

По принятому макету `mockups/balloo-su/file-viewer.html` реализовать
полноэкранный просмотрщик файлов/изображений. Ключевое требование приёмки:
**при просмотре изображение не обрезается** (без clip-path; `object-fit: contain`).

## Живое состояние на момент создания (проверено командами)

- Компонента просмотрщика НЕТ: `find packages/web/src -iname "*viewer*" -o
  -iname "*lightbox*" -o -iname "*fullscreen*"` → пусто;
- `MessageBubble.tsx:125` — вложение отображается только именем и размером
  (`attachment?.name`, `formatBytes(size)`), `img`-превью и клика для открытия нет;
- Макет: тулбар (Закрыть/имя/счётчик/🔍/ℹ️/📥/📤), превью-лента снизу,
  боковая панель свойств, стрелки ‹ ›, Esc/←/→/+;
- Клипы из макета (`--hexagon-clip`) допустимы ТОЛЬКО для миниатюр,
  НЕ для просматриваемого файла.
