## 3. Перепроверка ВСЕХ ключей `.env.production` (СДЕЛАТЬ_ВЛАДЕЛЬЦУ 1.6.5)

**Что нужно от вас:** сверить значения ключей в `docker/prod/.env.production`
на сервере с живыми кабинетами провайдеров — что значения **текущие**, а не
устаревшие.

**Список для сверки:**

| Ключ(и) | Кабинет |
|---|---|
| `YANDEX_CLIENT_ID` / `YANDEX_CLIENT_SECRET` | Яндекс OAuth |
| `VK_CLIENT_ID` / `VK_CLIENT_SECRET` | VK OAuth |
| `MAILRU_CLIENT_ID` / `MAILRU_CLIENT_SECRET` | Mail.ru OAuth |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | Web-push |
| `VITE_YM_METRIKA_ID` (= `112269610`) | Яндекс Метрика |
| `YOOKASSA_SHOP_ID` / `YOOKASSA_API_KEY` | ЮKassa (пусты — до реальных платежей) |
| `SMTP_USER` / `SMTP_PASSWORD` | SMTP |

**Замечание по безопасности (не действие):** значения ключей в отчёт не
выводите — достаточно «текущий / устарел / пусто». Секреты в чат не копируем
(решение №3: до 1000 пользователей не трогаем).
