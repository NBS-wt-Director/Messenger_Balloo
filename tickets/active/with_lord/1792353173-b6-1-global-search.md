## Что должно быть

`GET /api/search?q=<query>&type=<type>` — глобальный поиск по всем сущностям.

## Вопрос к владельцу

1. **Какие сущности искать?**
   - a) только `users` (username, displayName)
   - b) `users` + `chats` (название)
   - c) `users` + `chats` + `messages` (текст) + `blog posts` + `channels`

2. **Формат ответа:**
   - a) `{ users: [...], chats: [...], messages: [...] }` (сгруппировано)
   - b) `[ { type: 'user', ... }, { type: 'chat', ... } ]` (единый массив)

3. **Пагинация:** единая или по типам?

## Моя рекомендация

Вариант b (users + chats + messages), формат a (сгруппировано). Это покрывает SearchScreen из макета и не требует полнотекстового индекса.
