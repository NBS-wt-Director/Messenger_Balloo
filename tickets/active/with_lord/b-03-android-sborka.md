локальный стек поднимается, базовые пользовательские сценарии работают.

## Что нужно сделать

1. **Сборка монорепо:** `pnpm build` — зелёный. Вывод целиком в «Результат».
2. **Тесты:** `pnpm test` — зелёный (сверять со счётчиками 26.09: shared 66,
   server 245, web 158; падение числа = регресс).
3. **Экспорт Android-бандла:** `cd packages/mobile-android && npx expo export`
   (не `eas build` — облачная сборка не нужна). Артефакт: путь + размер.
4. **Локальный стек:** `docker compose -f docker/prod/docker-compose.local.yml
   --env-file docker/prod/.env.production up -d` **только на этой машине**.
   ⚠️ На проде так не делать: сеть `balloo-net` со шлюзом `172.19.0.1` — это
   `SMTP_HOST` postfix-релея, пересоздание сети ломает почту.
5. **Health:** `curl -s http://localhost:3100/health`; для web — порт, поднятый
   compose-файлом (у у у прод-контейнера `balloo-web` это `127.0.0.1:8090`).
   Порт `8080` из оригинального тикёта в этом стеке **не используется** — проверять
   фактические маппинги `docker compose ps`, а не текст от 09.08.
6. **Пользовательские сценарии браузером:** регистрация → вход → отправка
   сообщения → получение (вторая вкладка/WS). Скриншоты в «Результат».
