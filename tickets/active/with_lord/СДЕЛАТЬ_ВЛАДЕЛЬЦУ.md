#### 1.7.1 TLS — сертификат не покрывает поддомены

**Зачем:** `https://history.balloo.su` и `https://download.balloo.su` отдают `CN=alpha.balloo.su` → SSL handshake fail. Nginx (`nginx-production.conf:175-179`) уже маршрутизирует history/download — проблема ТОЛЬКО в сертификате.

**Шаг 0 — снять факты с сервера (владелец):**

```bash
# Посмотреть текущий конфиг host-nginx для ACME challenge:
sudo grep -n "acme\|well-known\|webroot" /etc/nginx/sites-enabled/balloo-docker.conf 2>/dev/null
# Или показать весь файл:
cat /etc/nginx/sites-enabled/balloo-docker.conf
```

**Шаг 1 — перевыпустить сертификат со всеми SAN (после шага 0):**
- Если host-nginx имеет `location /.well-known/acme-challenge/ { root ...; }` → `--webroot` метод:
  ```bash
  sudo certbot certonly --webroot -w /var/www/certbot \
    -d balloo.su -d app.balloo.su -d api.balloo.su -d admin.balloo.su \
    -d command.balloo.su -d blog.balloo.su -d docs.balloo.su \
    -d download.balloo.su -d history.balloo.su \
    --deploy-hook "sudo systemctl reload nginx"
  ```
- Если ACME location нет → `--standalone` метод (останавливает nginx на ~30 сек):
  ```bash
  sudo systemctl stop nginx

    -d balloo.su -d app.balloo.su -d api.balloo.su -d admin.balloo.su \
    -d command.balloo.su -d blog.balloo.su -d docs.balloo.su \
    -d download.balloo.su -d history.balloo.su \
    --deploy-hook "sudo systemctl start nginx"
  ```

#### 1.7.2 CDN — `cdn.balloo.su` (MinIO API не проброшен на хост)

**Факт 15.10.2026:** nginx-блок для cdn добавлен ✅, сертификат в SAN ✅, но `curl -I https://cdn.balloo.su` → `HTTP/2 502`.

**Причина:** в `docker-compose.local.yml` MinIO пробрасывает только консоль `:9001`, не API `:9000`. Nginx проксирует на `127.0.0.1:9000` — ничего не слушает → 502.

**Исправлено в репозитории** (коммит `c4a8a78`): добавлена публикация порта `127.0.0.1:9000:9000` в compose. `docker compose config` валиден.

### 5.1 SMTP — SPF/DKIM/DMARC (В-100)

**Что нужно (владелец):**
```bash
# Проверить текущие TXT-записи:
dig txt balloo.su
dig txt default._domainkey.balloo.su
dig txt _dmarc.balloo.su
```

## ЗАМЕЧАНИЯ ПО ПРИНЯТЫМ МАКЕТАМ MVP1

> Условия, зафиксированные при приёмке. Экран принят, но при реализации нужно учесть.

**`1_06_02` (downloads.html):**
1. Вверху страницы, над плитками — определение платформы пользователя (по User-Agent). Показать: «Вы используете: Windows 11» / «Вы используете: macOS» / «Вы используете: Linux» / «Вы используете: Android» / «Вы используете: iOS» / «Вы используете: браузер (PWA-совместим)».
