## Цель

При выборе «выборочный доступ» на экране создания истории (`1_01_41`,
`story-create.html`) появляется список контактов с чекбоксами для выборочной
аудитории. Когда будут реализованы **списки контактов (группы контактов)** —
использовать их в этом экране.

## Подзадачи

- [x] 1. UI: при выборе «выборочный доступ» — раскрывающийся список контактов
      с чекбоксами (галочками).
      **Сделано 16.11:** StoryCreateScreen — select visibility (all/friends/self/selective),
      при selective — загрузка контактов через api.getContacts() + чекбоксы.
- [!] 2. После реализации групп контактов: добавить переключатель «Контакты /
      Группы» и отображение групп в списке.
      **Блокировка:** группы контактов ещё не реализованы (отдельная задача).
- [x] 3. API: эндпоинт получения контактов/групп для выбора аудитории.
      **Сделано:** `api.getContacts()` → `GET /api/users/contacts` (уже существовал);
      `POST /api/stories` принимает `visibility` + `audienceUserIds`.
- [x] 4. Хранение: связь история ↔ выбранные контакты (audience list).
      **Сделано:** `StoryAudience` model + миграция `20261116000002_story_audience`;
      `createStory` создаёт audience rows; `getStories` фильтрует по visibility.
