**Исправлено:** `messagesRouter` монтировался на `/api/messages`, а его внутренние
пути уже содержали `/messages` → сервер слушал `/api/messages/messages/*`, клиент
звал `/api/messages/*`, REST сообщений целиком падал в 404. Фикс `f3dc21e` +
регресс-тесты (негативный контроль: на сломанном монтировании 13/13 тестов падают).

**20 расхождений метода** — вызовы клиента с методом, которого нет у пути
(`POST /api/users/me` при наличии GET,PUT; `DELETE /api/devices` при GET; и т.д.).
Вне экранов (мёртвый код в api.ts) → группа C тикета `1790707718`.
