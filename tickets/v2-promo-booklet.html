О проекте Balloo
🔒

Приватность

2FA через email-код, контроль устройств, шифрование TLS + bcrypt. Соответствие 152-ФЗ.

🇷🇺

Российская разработка

Self-hosted инфраструктура: PostgreSQL, MinIO, Redis. Все данные на серверах в РФ.

🌍

20 языков

Русский + 14 языков народов РФ + дружественные (ZH, HI, BE) + международные (EN, FR).

📱

Мультиплатформа

Web, Desktop (Electron), Mobile (Expo — Android). iOS в разработке.

Balloo — это не просто мессенджер. Это экосистема: основной мессенджер (balloo.su), админ-панель (admin.balloo.su), портал сотрудников (command.balloo.su), фич-реквесты (features.balloo.su), блог (blog.balloo.su) и другие узлы.

Архитектура монорепо: 6 пакетов (shared, server, web, desktop, mobile-android, mobile-ios) · 134 экрана · 11 узлов · 66 тикетов v1.0.0 реализовано.

Культура разработки

🎯 Макет → Код

Макеты (mockups/) — единственный источник правды. Код должен 100% соответствовать дизайну.

📦 Монорепо

pnpm workspaces, 6 пакетов, общий пакет shared с типами и утилитами.

🔄 Nумерация z_xx_yy

Уникальные ID: функция → экран → API → данные → компонент. Каждый объект пронумерован.

🇷🇺 152-ФЗ

Все данные в РФ, self-hosted, никаких зарубежных сервисов. Безопасность — приоритет.

v2+ задачи: TypeScript исправления, API-вызовы вместо mock, Service Worker, 40 тем, ИИ-перевод, 90 языков, пентест.

Сообщения v1
